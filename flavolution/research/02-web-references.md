| Serif ไทย (editorial) | **Pridi**, Maitree, Trirong, Taviraj | Pridi น้ำหนักครบ 200–700 อ่านบนจอดี; Trirong/Taviraj มีหัวโบราณกว่า |
| ลายมือ/วาด | **Sriracha**, Itim, Mali | Sriracha = ลายมือปากกาเมจิก มีจังหวะ ไม่เด็กเท่า Itim; **ใช้แค่ accent** ห้ามใช้ body |
| กลม-อบอุ่น | Mitr, K2D, Athiti | Mitr = Kanit เวอร์ชันนุ่ม — ดีสำหรับทาง A |

กติกาทุกทาง: ภาษาไทยเป็นหลัก → ฟอนต์หลักต้องเป็น **ฟอนต์ที่ออกแบบไทยก่อน** ไม่ใช่ละตินแล้วเติมไทย; ทดสอบ loanwords กับ Intl.Segmenter (ดู memory: มันหั่นคำทับศัพท์)

### ทาง A — **Kitchen Sketchbook** (สมุดสเก็ตช์หลังครัว)

**Mood:** เหมือนเพื่อนที่เคยเปิดร้านมาก่อนนั่งวาดแผนผังร้านคุณลงสมุดบนโต๊ะหลังครัวตอนปิดร้าน — เส้นปากกาบนกระดาษอุ่น มีคราบกาแฟนิดๆ ตลกได้แต่รู้เรื่องจริง ไม่ใช่การ์ตูนใสๆ แต่เป็น "ภาพประกอบเชิงบันทึก" แบบ Ottolenghi/Sweetgreen ที่ยังจริงจังกับธุรกิจ

**Palette**
| บทบาท | hex |
|---|---|
| กระดาษ (bg) | `#F6EFE3` |
| หมึก (text/line) | `#1F1B18` |
| มะเขือเทศ (accent/CTA) | `#D6452B` |
| น้ำมันมะกอก (secondary) | `#6F7A3C` |
| ไข่แดง (highlight) | `#F2B134` |
| ครีมเข้ม (card) | `#EADFCB` |
| น้ำเงินหมึกปากกา (link) | `#2F4A7A` |

**Typography:** Display = **Mitr** 600 (กลมแต่มีน้ำหนัก ไม่คมเหมือน Kanit เข้ากับเส้นวาด); Body = **Anuphan** 400/500 (สะอาด ไทย-ละตินสมดุล ทำให้ภาพวาดไม่พาไป "เด็ก"); Accent = **Sriracha** สำหรับ callout/ป้าย/คำตอบควิซที่ "เขียนด้วยมือ" เท่านั้น (≤ 5% ของข้อความ) — สูตร Ottolenghi: ภาพอุ่น × ฟอนต์เรียบ

**ภาพ:** ภาพประกอบเส้นเดียว (mono-line ink) สีเติมแบบ flat 2–3 สีไม่เต็มขอบ (offset print feel) — ฉากร้าน 6–7 ฉากตามช่วงเวลาในวัน, ตัวละคร: เจ้าของ, พนักงาน, ลูกค้า, ไรเดอร์; **ไม่ใช้ภาพถ่ายในควิซ** ใช้ภาพถ่ายจริงเฉพาะหน้า about (ทีม/งานที่ทำจริง) เพื่อยึดความน่าเชื่อถือ

**Motion:** เส้นวาด "เขียนตัวเอง" (SVG stroke-dashoffset) ตอนเข้าฉาก; หน้าต่าง/ไฟร้านสว่างทีละจุดตามเวลาในวัน (Frelsesarmeen); ตัวเลือกควิซ hover = ตัวหนังสือขยุกขยิกเล็กน้อย (Who's Guilty); progress = สมุดพลิกหน้า/นาฬิกาแขวนร้านเดินจาก 06:00 → 23:00; **ทุกอย่างช้า-นุ่ม ไม่เด้ง** (ไม่ใช่ Little Troop)

**Reference ที่ตรงที่สุด:** ottolenghi.co.uk · sweetgreen.com · hakubaku-zatsu.jp · ponpon-mania.com · Frelsesarmeen Julie (vev) · whoisguilty.com

**ความเสี่ยง / trade-off:**
- เจ้าของเชน 10 สาขาอาจอ่านว่า "น่ารัก = ไม่ serious" → **ต้องแก้ด้วยหน้าผลลัพธ์**: หน้า archetype ต้องดูเหมือนรายงานวิเคราะห์ (ตาราง, ตัวเลข, กราฟจุดแข็ง/จุดอ่อน) ไม่ใช่การ์ดน่ารัก; และ testimonial/logo ร้านจริงในหน้าแรก
- ต้องมีนักวาดหรือกำกับสไตล์ AI ให้นิ่งทั้ง 7 ฉาก — ถ้าเส้นไม่นิ่ง จะดูถูก
- ฟอนต์ลายมือไทย (Sriracha) ถ้าใช้เกิน จะพาไปโทนร้านขนม

### ทาง B — **Backstage Editorial** (นิตยสารครัวหลังบ้าน)

**Mood:** นิตยสารธุรกิจอาหารฉบับที่ถ่ายหลังครัว ไม่ใช่หน้าร้าน — โต๊ะสแตนเลส, บิลออเดอร์เสียบเรียง, มือที่กำลังทำงาน; ตัวหนังสือใหญ่ พูดตรง มีตัวเลข อบอุ่นเพราะ "จริง" ไม่ใช่เพราะ "หวาน" เหมือน Marugame/Noma แต่ลดความหรูลงมาให้ร้านตึกแถวรู้สึกว่านี่คือครัวเขา

**Palette**
| บทบาท | hex |
|---|---|
| กระดูก/กระดาษหนา (bg) | `#F2ECE2` |
| ถ่าน (text) | `#232323` |
| ดินเผา (accent) | `#B8532E` |
| เขียวป่า (secondary) | `#2E4A3A` |
| สแตนเลส (rule/meta) | `#9A9A94` |
| ครีมเข้ม (section alt) | `#E4DACA` |

**Typography:** Display = **Pridi** 500/600 (serif ไทยที่อ่านบนจอชัด ให้กลิ่นนิตยสาร ไม่โบราณ); Body = **IBM Plex Sans Thai** 400 (สมดุลกับ Pridi, ตัวเลข/ตาราง/label ดูเป็นระบบ); Meta/label = IBM Plex Sans Thai 500 ตัวพิมพ์เล็ก tracking กว้าง — สูตร Sweetgreen (serif Grenette × sans)

**ภาพ:** ภาพถ่ายจริงเป็นหลัก (ต้องยิงเอง 1–2 วันในร้านพาร์ทเนอร์ของเพื่อนอินฟลูฯ) โทนอุ่น ไม่ฟิลเตอร์จัด; ควิซใช้ **ภาพถ่ายตัดขอบ + ตัวหนังสือใหญ่** (typography scrollytelling แบบ savor.it) และ pictogram เส้นบางแทน illustration เต็มตัว

**Motion:** เรียบและมั่นใจ — ตัวหนังสือเผยทีละบรรทัดตาม scroll, ภาพแทรกกลางย่อหน้า (Momofuku), เลขนับ (KPI), hover เป็นภาพ gif เล็ก (Brand Bureau); ไม่มีตัวละครขยับ

**Reference ที่ตรงที่สุด:** marugame.com · momofuku.com · noma.dk · pasconet.co.jp/choujuku · koto.studio · allgoodnyc.com

**ความเสี่ยง / trade-off:**
- **พึ่งภาพถ่ายคุณภาพสูง** — ถ้าไม่มี จะพังทันที (สต็อกโฟโต้ทำให้เหมือน mazmaker)
- คาเฟ่เล็ก/ร้านรถเข็นอาจรู้สึกว่า "ไม่ใช่ระดับฉัน" (โทน fine dining)
- ควิซจะ "เล่า" ยากกว่า เพราะภาพถ่ายบังคับให้เป็นร้านใดร้านหนึ่ง ไม่ใช่ "ร้านของคุณ" — illustration ทำ universal ได้ดีกว่า

### ทาง C — **Service Counter Bold** (ป้ายเมนูตัวหนา)

**Mood:** เสียงของคนที่ยืนหน้าเคาน์เตอร์ตอน rush hour — สั้น ตรง ตัวหนา สีแบบป้ายเมนูไฟ; สนุกแบบ Nando's/Burrito Madre แต่วินัยแบบ Hey Studio (สีจัดแต่ระบบแน่น) พูดกับเจ้าของร้านเหมือนคนทำงานด้วยกัน ไม่ใช่ที่ปรึกษาใส่สูท

**Palette**
| บทบาท | hex |
|---|---|
| ครีมสว่าง (bg) | `#FFF4E0` |
| ดำเข้ม (text) | `#141414` |
| ส้มพริก (primary) | `#FF5A1F` |
| เขียวใบโหระพา (secondary) | `#1E7A4E` |
| เหลืองป้ายไฟ (highlight) | `#FFC531` |
| ชมพูน้ำแข็งไส (tertiary, ใช้น้อย) | `#F27BA9` |

**Typography:** Display = **Kanit** 700/800 (คม หนา ไทยเป็นระบบ line-height ≥ 1.35); Body = **Bai Jamjuree** 400/500 (เรขาคณิตกว่า Anuphan เข้ากับ Kanit และไม่ "โมโน" เกิน); Label/ตัวเลข = Chakra Petch 600 สำหรับ badge/ผลลัพธ์ (ให้ฟีล "ป้ายราคา/สกอร์")

**ภาพ:** flat illustration สีเต็ม รูปทรงหนาขอบมน (ทำ AI-consistent ได้ง่ายกว่าเส้นวาดมือ) + sticker/badge/ตราประทับ; ไอคอนวัตถุดิบ/อุปกรณ์เป็น mascot ชุด (Sweetgreen แต่หนากว่า); ภาพถ่ายใช้เฉพาะ case study แบบ duotone

**Motion:** เด้ง-ไว-snap (spring) — ปุ่มกด squash, การ์ดตัวเลือกควิซ stack เหมือนบิลออเดอร์, marquee ตัวหนังสือวิ่ง, sticker หมุนตอน hover; มิเตอร์ประจำแบรนด์แบบ PERi-ometer ("มิเตอร์ความวุ่นวาย")

**ความเสี่ยง / trade-off:**
- ดูเหมือน **แอปเดลิเวอรี่/แบรนด์ fast food** — ร้านอาหารระดับกลาง-บน หรือโอมากาเสะ จะรู้สึกว่าไม่ใช่กลุ่มตัวเอง
- สีจัดหลายสี + Kanit หนา = เหนื่อยตาใน 25 ข้อ ต้องมีหน้าพักสายตา
- บุคลิกแรงทำให้ "อบอุ่น" หายง่าย กลายเป็น "ตะโกน"
