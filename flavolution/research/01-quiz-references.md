## B. Synthesis

### (a) อะไรทำให้ควิซดู premium vs ดูถูก

| ดู premium | ดูถูก |
|---|---|
| **1 ข้อ = 1 จอ** พร้อม transition แบบเดียวตลอด (Awwwards cluster, Chekhov) | ลิสต์คำถามยาวเลื่อนลงเรื่อยๆ แบบ Google Form / uQuiz |
| **จานสี 2–3 สี + illustration ชุดเดียว** ที่วาดเพื่อควิซนี้โดยเฉพาะ (Chekhov: ดำ/coral/ขาว; ktestone; Poomang) | stock photo ผสม emoji ผสม clipart หลายสไตล์ |
| ตัวเลือกเป็น **สถานการณ์/การกระทำ** ("ลูกค้าโวยว่าช้า คุณ…") | ตัวเลือกเป็นประโยค trait ("ฉันเป็นคนใจเย็น") หรือ scale 1–5 ล้วน |
| **ทุกอย่างมีชื่อ** — archetype มีชื่อเล่น + code + สีประจำ (16P, Spotify) | ผลเป็น "Type A / Type B" หรือแค่ย่อหน้าบรรยาย |
| หน้าผลมี **โครงสร้างชัด** (avatar → ชื่อ → แถบ % → จุดแข็ง/จุดอ่อน → ขั้นต่อไป) | ผลเป็นข้อความก้อนเดียว + ปุ่มแชร์ |
| motion เบาแต่แม่น: ตัวเลือกกดแล้ว "ตอบสนอง" (scale/ติ๊ก/สี) ก่อนเปลี่ยนจอ 200–300ms | ไม่มี feedback หรือมี confetti/animation ทุกข้อจนเลี่ยน |
| ไม่มีโฆษณา, ไม่ gate ผลด้วยอีเมล (Yonder) | ต้องกรอกอีเมล/เบอร์ก่อนเห็นผล, มี banner ad |
| copy สั้นเป็นเสียงคนจริง มีอารมณ์ขันเล็กน้อย (ktestone, wine@) | copy แบบ HR/แบบสอบถามวิจัย |

### (b) โครงหน้าผล + CTA ของตัวที่ดีที่สุด

โครงที่เจอซ้ำในตัวอย่างชั้นนำ (16P, Pokémon, Airbnb, freee, wine@) เรียงจากบนลงล่าง:

1. **Hero card** (พอดี 1 จอมือถือ): illustration archetype + ชื่อไทยสั้น (+ code/ชื่ออังกฤษ) + tagline 1 บรรทัด + สีประจำ — นี่คือส่วนที่ถูก screenshot
2. **แถบมิติ** 4–5 แถบ % (จาก 16P/freee) — ทำให้ผลดู "วัดมา" ไม่ใช่ทาย; ใส่ archetype รองพร้อม % (Archetype Thailand, Refind Self)
3. **จุดแข็ง 3 ข้อ / จุดอ่อน 3 ข้อ** (Pokémon) — เขียนเป็นภาพในร้านจริง ไม่ใช่คำคุณศัพท์
4. **"pain point ที่ร้านแบบคุณมักเจอ"** 1–2 ข้อ + สัญญาณเตือน (freee's "ทำให้ปัญหาที่มองไม่เห็นเห็นได้")
5. **Compatibility** — "เข้ากับหุ้นส่วน/ทีม/ลูกค้าแบบไหน" (Teto-egen, ktestone) → เหตุผลให้ส่งต่อ
6. **Next step ที่จับต้องได้** — service 1–2 ตัวที่ตรงกับ archetype (Airbnb: เมือง+itinerary; wine@: ไวน์+ซื้อได้เลย) พร้อมเหตุผล 1 บรรทัดว่าทำไมตรง
7. **CTA เดี่ยว**: "รับแผน 3 ข้อสำหรับร้านแบบคุณทาง LINE" — deep-link เข้า LINE OA พร้อม payload archetype (โมเดล Krungsri) · ไม่มี CTA รอง ยกเว้นปุ่มแชร์
8. **แชร์**: ปุ่ม LINE เป็นอันดับหนึ่ง (Sales Animal Finder), รองด้วย save รูป + hashtag (Pokémon), แล้วค่อย FB/IG

หลักจาก quiz-funnel research: CTA ต้อง **ต่างกันตาม archetype** (ข้อความ + service) และหน้าผลไม่ควรยาวจนอ่าน 5 นาทีก่อนเจอ CTA — ให้ CTA โผล่ครั้งแรกใต้ hero card (sticky bottom bar) และซ้ำอีกครั้งท้ายหน้า

### (c) 20+ ข้อโดยไม่ drop-off

จาก NYT (25 ข้อ), Teto-egen (28), 志士 (24), freee (20), 16P (~60):

- **แบ่งเป็นบท (chapter) ตามเวลาในวัน** — 5 บท × 4–5 ข้อ: 06:30 เปิดร้าน / 11:30 พีคเที่ยง / 14:30 ช่วงเงียบ / 18:00 พีคเย็น / 22:00 ปิดร้าน-นับเงิน. แต่ละบทมี **title card เต็มจอ** (ภาพ+เวลา) เป็นจุดพักและเป็น progress ในตัว — คนจำ "เหลืออีก 2 บท" ได้ง่ายกว่า "ข้อ 14/23"
- **Progress แบบ fast-to-slow**: research พบ progress bar ที่วิ่งเร็วช่วงต้นแล้วช้าลงมี abandonment ต่ำสุด (~11%) เทียบกับแบบตรงไปตรงมา; ทำได้โดยให้บทแรกสั้น (3 ข้อ) และแสดง progress เป็น "เข็มนาฬิกา/ดวงอาทิตย์" ที่ขยับตามเวลาในเรื่อง ไม่ใช่ % ตรงๆ
- **Micro-reward ทุกข้อ** (NYT map): มิเตอร์เล็ก 2–3 ตัวบนจอ (เช่น 💰 ยอดขาย · 😮‍💨 พลังงานเจ้าของ · ⭐ รีวิว) ขยับตามตัวเลือก — ไม่ต้องบอกคะแนนจริง แค่ให้เห็นว่า "การเลือกมีผล"
- **Micro-reward ท้ายบท**: การ์ด 1 บรรทัดสรุปว่า "ช่วงเช้าคุณเป็นสาย ___" (ktestone-style tease) — เป็น partial result ที่ทำให้อยากรู้ผลเต็ม
- **สลับรูปแบบตัวเลือก**: ส่วนใหญ่เป็นการ์ดข้อความ 3 ใบ, แต่ 3–4 ข้อต่อควิซให้เลือกด้วย **รูป** (Airbnb swipe) หรือ **2 ตัวเลือกใหญ่ซ้าย/ขวา** (ktestone) เพื่อเปลี่ยนจังหวะ
- **ไม่มี scale**: ทุกข้อเลือก 1 ใน 3–4 (ตาม Brief) → tap เดียว ไม่ต้องคิดระดับ
- **ไม่มีข้อไหน "ถูก"**: ทุกตัวเลือกเป็นสิ่งที่เจ้าของร้านจริงทำ (รวม "ปล่อยผ่าน/ยังไม่ทำอะไร" — Refind Self) เพื่อไม่ให้รู้สึกถูกสอบ
- **Auto-advance** หลังเลือก 250ms + ปุ่มย้อนกลับเล็กๆ (16P มี, ควิซถูกๆ ไม่มี)
- **Save state ใน localStorage** — ปิดแอปแล้วกลับมาต่อได้ (5–7 นาทีบนมือถือมักถูกขัดจังหวะด้วย LINE เด้ง)

### (d) กลไกแชร์/viral

1. **การ์ดผล 9:16 ที่ save ได้** (Spotify, Pokémon) — สร้างด้วย canvas ฝั่ง client, ชื่อ archetype + illustration + 1 บรรทัดขำๆ + URL สั้น; นี่คือหน่วยที่วิ่งใน IG Story และกลุ่ม LINE
2. **ผลที่ "ขำตัวเอง" แชร์มากกว่าผลที่ชม** (ktestone "Worried old soul", wine@ ตัวละครคนเมา) — archetype ต้องมีจุดอ่อนที่คนยอมรับได้แบบยิ้มๆ
3. **Compatibility hook** (Teto-egen): "ส่งให้หุ้นส่วน/ผู้จัดการร้านทำ แล้วดูว่าเข้ากันไหม" — ทำให้ 1 ร้านทำหลายครั้ง
4. **Hashtag ไทยสั้น 1 ตัว** + ให้ Mat/เพื่อนอินฟลูฯ โพสต์ผลของตัวเองก่อนเป็น seed (Pokémon trend เกิดจากคนโพสต์รูปผล)
5. **OG image ต่อ archetype** — ลิงก์ผล `?r=ARCH` มี og:image ของแบบนั้นๆ (Poomang) เพื่อให้ preview ใน LINE/FB เป็นการ์ดของคน ไม่ใช่โลโก้เว็บ
6. **ไม่ gate ผล** (Yonder) — ทุกอย่างในหน้าเว็บฟรี; สิ่งที่ต้องทัก LINE คือ "แผน" ไม่ใช่ "ผล"
7. **ของแถมหลังผล** (Sales Animal Finder, 16 wine LINE sticker): sticker/wallpaper archetype ชุดเล็ก หรือ checklist PDF 1 หน้า — เป็นเหตุผลที่สองให้เข้า LINE

### (e) 5 ข้อเสนอสำหรับโครง "หนึ่งวันในร้านของคุณ"

1. **โครง 5 บท × 4–5 ข้อ = 22 ข้อ, แต่ละบทซ่อน pain point คนละกลุ่ม** (ตาม Brief):
   - 06:30 *เปิดร้าน* → ระบบ/SOP, การเตรียมของ, ต้นทุนวัตถุดิบ
   - 11:30 *พีคเที่ยง* → เมนู/hero product, การจัดคิว, ทีมงาน
   - 14:30 *ช่วงเงียบ* → การตลาด/social media, delivery, การมองเห็นจุดขายตัวเอง
   - 18:00 *พีคเย็น* → ประสบการณ์ลูกค้า, รีวิว, upsell
   - 22:00 *ปิดร้าน* → ตัวเลข, ความเหนื่อยของเจ้าของ, การมอบหมาย, แผนระยะยาว
   ทุกบทเปิดด้วย title card เต็มจอ (ภาพร้านในแสงของเวลานั้น + นาฬิกา) และปิดด้วย tease 1 บรรทัด
2. **Scoring 4 แกน → 8 archetype** (ไม่ใช่ 16): เจ้าของร้านต้องจำและเล่าต่อได้; ให้แต่ละตัวเลือกเพิ่มคะแนน 1–2 แกน (ไม่มีตัวเลือก "ไม่ให้คะแนน") และหน้าผลแสดงแถบ 4 แกน + archetype รองพร้อม % — สาย 03 (pain points) เป็นคนเสนอชื่อแกน/archetype
3. **HUD 3 มิเตอร์ที่ขยับทุกข้อ** (ยอดขาย · พลังงานเจ้าของ · รีวิว) + progress เป็นดวงอาทิตย์/นาฬิกา — นี่คือสิ่งเดียวที่ทำให้ควิซนี้ต่างจาก Archetype Thailand และควิซ template ทั้งหมด, และเป็นสิ่งที่ static HTML + CSS ทำได้โดยไม่ต้องใช้ WebGL
4. **หน้าผลตามโครง (b) 8 ส่วน** โดย CTA เดียวคือ deep-link LINE OA พร้อม `?arch=` (โมเดล Krungsri) และข้อความแรกใน LINE ถูก prefill ว่า "ร้านผมได้ผลเป็น [archetype] อยากได้แผน 3 ข้อ" → ทีมรู้ pain point ก่อนตอบ; ทุก archetype map กับ service แกน (SOP / social / hero product / จุดขายที่มองข้าม) อย่างน้อย 1 ตัว
5. **ชุด asset แชร์ต่อ archetype**: การ์ด 9:16 save ได้ + og:image + hashtag ไทย 1 ตัว + "ส่งให้หุ้นส่วนทำ ดูว่าเข้ากันไหม" (compatibility matrix 8×8 ง่ายๆ) — และ seed ด้วยโพสต์ผลของ Mat/เพื่อนอินฟลูฯ วันเปิดตัว

## C. สิ่งที่ยังไม่พบ / ข้อจำกัด
- ควิซบุคลิกของแบรนด์ไทยที่ **ทำเป็นเว็บ illustrated เต็มรูป** หาไม่เจอในการค้นครั้งนี้ (ที่พบส่วนใหญ่อยู่ใน LINE chatbot หรือเป็นบทความ + Google Form) — เป็นช่องว่างที่ Flavolution เข้าไปได้
