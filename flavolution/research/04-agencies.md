# 04 — เอเจนซี่/ที่ปรึกษาร้านอาหารในต่างประเทศ: ขายอะไร แพ็กยังไง หาลูกค้ายังไง และ Flavolution ควรลอก/เลี่ยงอะไร

วันที่: 2026-09-26 · แหล่ง: เว็บของเอเจนซี่โดยตรง + บทความราคาในแต่ละประเทศ (ลิงก์ในตาราง) · ราคาที่ระบุคือราคาที่เปิดเผยบนเว็บ ณ วันค้น ถ้าไม่มี = "ไม่เปิดเผย"

---

## 0. สรุปสั้น (อ่านก่อน)

1. **ทุกเจ้าขายของเหมือนกัน 80%**: opening support, menu development/engineering, ops audit, staff training, SNS/Instagram retainer, ads, review/Google management, delivery-platform management. ความต่างอยู่ที่ *ใครพูด* (เชฟ / อดีตเจ้าของร้าน / อดีตคนแพลตฟอร์ม / ครีเอเตอร์) และ *front door* (free call vs audit vs quiz)
2. **Front door ที่เห็นมากที่สุดคือ "free consultation/strategy call 30 นาที"** — เจ้าที่ทำ "diagnostic" จริง ๆ มีน้อย: America's Best Restaurants (WIN Audit → scorecard → นัดคุย), David Scott Peters ("Profit Finder Call" ที่วางตัวเป็นการวินิจฉัย ไม่ขาย), QMK (Free Financial Assessment), Collabopartner JP (無料診断) → **ควิซของเราจะโดดเด่นทันทีถ้าทำเป็น "ผลตรวจร้าน" ที่จบด้วยบริการที่ตรงกัน**
3. **โมเดลราคาหลัก 3 แบบ**: (ก) retainer รายเดือน (SNS/ads/delivery) (ข) project fixed-fee (opening, menu, brand, SOP) (ค) audit/inspection ราคาถูกเป็นตัวเปิดประตู (mystery diner $35–95/ครั้ง, Quick Inspection, 2–3 วัน ops audit). ญี่ปุ่นมีเมนูราคาแบบ "ใบเสนอราคาสาธารณะ" ละเอียดที่สุด (e-hanjyo, STAYDREAM) — น่าลอกวิธีแสดงราคา
4. **สิ่งที่ *ไม่มีใครขายเป็นชื่อบริการ*** (แต่ทำแฝงในงาน): "หา hero product", "ดึงจุดขายที่ร้านมองข้าม", "เล่าเรื่องร้านให้เป็นคอนเทนต์ซีรีส์", "ทำ SOP ให้เป็นคอนเทนต์/หลังบ้านที่ถ่ายได้" → ช่องว่างที่ Flavolution เป็นเจ้าของได้
5. เสนอเมนู 11 บริการ (4 แกน + 7 ต่อยอด) และ 3 บันเดิล อยู่ในข้อ 5–6

| **Platform ops** | delivery, Google, Naver | GBP $125–400/เดือน/สาขา · KR Naver Place ₩100–200만/เดือน · Savour ไม่เปิดเผย (บางเจ้าคิด % ยอด) | ฿5,000–15,000/เดือน/สาขา |

รูปแบบที่เห็นซ้ำและควรลอก: **(1) ราคาตั้งต้นแบบ "จาก ฿…" ทุกบริการ (JP)** (2) retainer ผูก 6 เดือนแต่มีชั้น entry ต่ำ (Storybox, e-hanjyo) (3) setup fee แยกจากรายเดือน (Dazy) (4) deliverable นับได้ (N Reels/N ภาพ/N creators) (5) ตั้งชื่อรูปแบบงานตามเวลา: audit (1 วัน) / sprint (2–6 สัปดาห์) / retainer (6 เดือน+)

### 2.4 ช่องว่างที่เอเจนซี่ไทยที่นำโดยอินฟลูเอนเซอร์ "เป็นเจ้าของ" ได้

| ช่องว่าง | หลักฐานจากต่างประเทศ | ทำไม Flavolution ได้เปรียบ |
|---|---|---|
| **1. "หา hero product" เป็นบริการชื่อเดียว** | ไม่มีใครขายตรง ๆ; ใกล้สุดคือ menu engineering (ตัวเลข) และ recipe dev (ครัว) | อินฟลูฯ รู้ว่า "อะไรถูกถ่าย/ถูกแชร์/ถูกสั่งซ้ำ" จากข้อมูลจริงหลายปี — รวมมุมครัว+มุมกล้อง+มุมกำไรในบริการเดียว |
| **2. จุดขายที่ร้านมองข้าม** | โผล่ในรีวิว kmong ("เห็นสิ่งที่มองข้าม") และ gap analysis ระดับเชน | สายตาคนนอกที่เคยรีวิวร้านมาหลายร้อยแห่ง = เครื่องมือหลัก; productize เป็น "Outsider's Eye Report" |
| **3. Storytelling → คอนเทนต์ซีรีส์** | เอเจนซี่ขาย "content day" (Velena) หรือ "โพสต์/เดือน" (ทุกเจ้า) ไม่มีใครขาย "เรื่องราวของร้าน" | ผู้ก่อตั้งทำ storytelling เป็นอาชีพ; ต่อยอดเป็น founder-led content coaching (สอนเจ้าของร้านออกกล้อง) |
| **4. SOP ที่มองเห็นได้** | SOP consultants ขายเอกสาร (US $5–25K) แยกจาก marketing สิ้นเชิง | รวม SOP + คอนเทนต์: SOP ที่ดีทำให้จานเหมือนเดิมทุกครั้ง = ถ่ายได้ทุกครั้ง = รีวิวไม่แกว่ง (ION Hospitality พูดถึงแต่ไม่ขาย) |
| **5. Creator seeding ที่ "คัดจากเพื่อนจริง"** | Storybox/Dazy/Foodie Tribe ขาย creator pool | เครือข่ายอินฟลูฯ ที่รู้จักกันจริง → คุณภาพ+ราคาต่อรองได้ + ผู้ก่อตั้งเป็นครีเอเตอร์เอง (ไม่ใช่นายหน้า) |
| **6. Delivery-platform ops สำหรับ Grab/LINE MAN/ShopeeFood** | Savour ทำ 12 ประเทศ ยังไม่มีในไทยแบบ productized | เมนู delivery, รูป, ชื่อเมนู, โปร — เป็นงาน "hero product + content" ในเวอร์ชันแพลตฟอร์ม |
| **7. Diagnostic ที่เป็นเรื่องเล่า** | ทุก audit เป็นฟอร์ม | ควิซ "หนึ่งวันในร้าน" + 1 หน้าโปรไฟล์ร้านที่แชร์ได้ |
| **8. ราคาโปร่งใสแบบญี่ปุ่น** | ไทย/สิงคโปร์/สหรัฐฯ ส่วนใหญ่ "ติดต่อสอบถาม" | ราคาตั้งต้น "จาก ฿…" ทุกบริการ + ROI calculator → ลดแรงเสียดทานสำหรับร้านเล็ก |

**สิ่งที่ควรเลี่ยง**: (ก) เป็น generalist ครบทุกอย่างแบบ QHMC/Protegie โดยไม่มีจุดต่าง — จะกลืนหาย (ข) ขาย "โพสต์ต่อเดือน" เป็นสินค้าหลัก — เป็น commodity ราคาตก (JP ต่ำสุด ¥11,000) (ค) รับ % ยอดขายตั้งแต่แรก — เสี่ยงและวัดยากในร้านเล็ก (ง) สัญญายาวโดยไม่มีชั้นเข้าถึงง่าย (จ) รับงานเปิดร้านเต็มรูปแบบ (interior/licensing) ที่ไม่ใช่จุดแข็ง — เป็นพาร์ตเนอร์แทน (แบบ Yellowfin)

### วิธีที่บริการอื่นเกาะแกน 4 ตัว

```
ควิซ (#0) ──► สายตาคนนอก (#1) ★ ──┬─► ฮีโร่โปรดักต์ (#2) ★ ──► ร้านบนแอป (#8), เพื่อนพารีวิว (#6)
                                   ├─► ระบบหลังบ้าน (#3) ★ ──► ลูกค้าลับ (#9), แผนที่และรีวิว (#7)
                                   └─► เล่าเรื่องร้าน (#4) ★ ──► เจ้าของออกกล้อง (#5), เพื่อนพารีวิว (#6)
ก่อนขยาย (#10) = #2+#3+#4 ในโหมดทำซ้ำได้ · เปิดร้านฯ (#11) = #2+#3+#4+#6 สำหรับร้านใหม่
```

- **#1 สายตาคนนอก** เป็น "audit ราคาเข้าถึงได้" ต่อจากควิซ (เลียนแบบ COCORO Quick Inspection / Pestle 2-day audit) และเป็นตัวบอกว่าควรซื้อแกนไหนก่อน → ลดการขายผิดของ
- **#2/#3/#4** คือ sprint/retainer หลักที่สร้างรายได้ — ทุก "ต่อยอด" (#5–#9) เป็นชิ้นเล็กที่ทำให้แกนวัดผลได้หรือขายต่อได้ (ลูกค้าลับตรวจ SOP, Maps ใช้สคริปต์จาก SOP, delivery ใช้ hero)
- **#10/#11** คือ premium ที่ห่อแกนทั้งสามในสถานการณ์เฉพาะ (ขยาย / เปิดใหม่)

### ทำไมถึงตัดบางอย่างออก
- **ads management** — เป็น commodity ที่เอเจนซี่ทั่วไปทำถูกกว่า; ให้เป็น add-on ผ่านพาร์ตเนอร์ในระดับ premium
- **interior / ใบอนุญาต / บัญชี** — ไม่ใช่จุดแข็ง; ทำแบบ Yellowfin คือมี "พาร์ตเนอร์แนะนำ"
- **โพสต์ต่อเดือนล้วน ๆ** — ราคาตก (JP ต่ำสุด ¥11,000); ต้องขายเป็น "เล่าเรื่องร้าน" ที่มี story bible เป็นทรัพย์สินเสมอ

## 4. บันเดิลที่เสนอ (3 ชื่อ)

| ชื่อบันเดิล | รวมอะไร | สำหรับ archetype/สถานการณ์ | ระยะ | ราคาแนว |

## 5. สิ่งที่ควรลอกตรง ๆ (checklist สำหรับหน้า services)

1. ราคา "จาก ฿…" ทุกบริการ + deliverable เป็นตัวเลข (N Reels, N วัน, N หน้า) — แบบ e-hanjyo / Velena / Foodie Calls
2. ตั้งชื่อ format ชัดบนการ์ด: **ตรวจ (audit) · สปรินต์ (sprint) · ดูแลรายเดือน (retainer)** — แบบ Aaron Allen
3. ลำดับ "ก้าว" ให้เห็นทางไปต่อ — แบบ CHEFIN Leap 0→6 (ของเรา: ควิซ → สายตาคนนอก → แกน → ต่อยอด → ขยาย)
4. ปลายทางควิซ = โปรไฟล์ร้าน 1 หน้าแชร์ได้ + "การตัดสินใจ 1 อย่างที่ควรทำก่อน" (DSP) + ตัวเลขช่องว่างยอด (ABR) + ปุ่มทัก LINE เดียว
5. ROI calculator เล็ก ๆ ในหน้าฮีโร่โปรดักต์ ("ขายเพิ่มวันละ 10 จาน × ฿… = เดือนละ ฿…") — แบบ Velena
6. เคสผลลัพธ์เป็นตัวเลขสั้น (Pestle: "$2.4M margin", Dazy: "+151%", Nouten: "1,000→7,000") — เก็บตั้งแต่ลูกค้ารายแรก
7. Setup fee แยกจากรายเดือน (Dazy) และ "จำกัดรับ N ร้าน/เดือน" สำหรับงานที่ผู้ก่อตั้งลงมือเอง (STAYDREAM)
8. LINE เป็นช่องหลักตั้งแต่หน้าแรก ไม่ใช่ฟอร์มยาว (Dazy/Nouten/Storybox)
