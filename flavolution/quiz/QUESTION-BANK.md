# คลังคำถาม "หนึ่งวันในร้านของคุณ" — ฉบับร่าง 1 (2026-09-26)

52 ข้อ 7 บท เขียนเกินไว้ให้คัด ควิซจริงใช้ 23–25 ข้อ หรือถ้าอยากละเอียดใช้ 30–35 ก็ได้

**วิธีอ่านป้ายท้ายตัวเลือก**
- ตัวอักษรในวงเล็บ = แกนที่ให้คะแนน · **S** ระบบ / **I** สัญชาตญาณ · **P** ของ / **V** เรื่อง · **G** โต / **K** มั่นคง · **ใจดี** = ตัวปรับ
- "เผย" = pain point ที่ตัวเลือกนี้เปิดโปง (รหัสอ้างอิงจาก research/03) · ขีด = ตัวเลือกนี้ไม่เผยปัญหา แค่บอกนิสัย
- ทุกข้อพยายามให้มีตัวเลือกที่ "ฟังดูดี" อย่างน้อยหนึ่งอัน ที่จริงแล้วเผยปัญหา นั่นคือหัวใจของควิซ
- ข้อที่มี 🏷️ = ใช้เฉพาะบาง segment โชว์ตามคำตอบข้อ 0

## บท 1 · 05:30 ตลาดยังไม่สว่าง

*ภาพ: ถนนยังมืด ไฟตลาดสว่างเป็นหย่อม เจ้าของร้านถือถุงเดินเข้าไป*

**1.1 เช้านี้คุณจะซื้อของเข้าร้านเท่าไร คุณรู้ได้ยังไง**
- ดูของหน้าแผงแล้วค่อยตัดสินใจ อยู่มานานพอที่จะรู้ว่าวันนี้ต้องใช้อะไร → [I] เผย A1 A10
- มีกระดาษแผ่นเดียวที่จดไว้ทุกคืนว่าพรุ่งนี้ต้องซื้ออะไร ตามยอดที่คาดไว้ → [S] —
- ซื้อเผื่อไว้ก่อน ของหมดกลางวันน่าอายกว่าของเหลือ → [I·ใจดี] เผย B5
- ไม่ได้ไปเอง ลูกน้องหรือซัพพลายเออร์จัดมาให้ ผมเช็กบิลทีหลัง → [S] เผย A4 (ถ้าไม่เคยเทียบเจ้า)

**1.2 ผักที่ใช้ประจำแพงขึ้นจากเดือนก่อนเกือบเท่าตัว วันนี้คุณทำยังไง**
- ซื้อเหมือนเดิม ราคาขายก็เหมือนเดิม เดี๋ยวมันก็ลง → [I·ใจดี] เผย A2 G12
- เปลี่ยนไปใช้ตัวที่ใกล้เคียง ลูกค้าไม่รู้หรอก → [I·P] เผย B2 A4
- ซื้อเหมือนเดิม แต่กลับไปคิดว่าเมนูไหนต้องขยับราคาหรือลดปริมาณ → [S] —
- ซื้อเหมือนเดิม แล้วเอาเรื่องผักแพงไปเล่าให้ลูกค้าฟังในเพจ → [V] —

**1.3 คุณซื้อของจากเจ้าเดิมมากี่ปีแล้ว**
- เจ้าเดียวตั้งแต่เปิดร้าน เขารู้ใจ ไม่เคยต้องเทียบ → [I·K] เผย A4
- มี 2–3 เจ้าสลับกัน ดูราคาและของทุกสัปดาห์ → [S] —
- เปลี่ยนบ่อย เจอที่ถูกกว่าก็ย้าย → [I·G] เผย B2 (รสแกว่งตามของ)
- ไม่รู้ ลูกน้องเป็นคนติดต่อ → [I] เผย B10 กลับด้าน (ปล่อยแบบไม่มีระบบ) หรือ G5

**1.4 ตี 5 ครึ่ง ไลน์กลุ่มพนักงานเด้ง "วันนี้ขอลาครับ ไม่สบาย" คนที่สองของสัปดาห์นี้**
- ไม่เป็นไร ผมทำแทนได้ทุกตำแหน่ง → [I] เผย A5 B10 G13
- โทรหาตัวสำรองที่มีชื่ออยู่ในลิสต์ → [S] —
- ลดเมนูวันนี้ลง ทำเท่าที่ทำไหว → [S·K] —
- โกรธแต่พูดอะไรไม่ได้ กลัวเขาลาออกแล้วหาคนไม่ได้ → [ใจดี] เผย A5 A6

**1.5 ค่าเช่าปีหน้าขึ้นอีก 15% เจ้าของที่บอกเมื่อวาน**
- ก็ต้องจ่าย ย้ายไม่ได้แล้ว ลูกค้าติดที่นี่ → [K] เผย A8
- เปิดสมุดดูว่าค่าเช่ากินยอดกี่เปอร์เซ็นต์แล้ว เกิน 15 เมื่อไรต้องคิดใหม่ → [S] —
- ต่อรอง ถ้าไม่ได้ก็หาที่ใหม่ ร้านอยู่ที่คน ไม่ได้อยู่ที่ตึก → [G] —
- ขึ้นราคาอาหารตาม ค่าเช่าขึ้นก็ต้องขึ้น → [I] — (อาจเผย E7 ถ้าขึ้นโดยไม่มีเหตุผลที่ลูกค้าเข้าใจ)

**1.6 🏷️แผง เทศกิจมาบอกว่าจุดนี้จะจัดระเบียบใหม่เดือนหน้า**
- รอดูก่อน ที่ผ่านมาก็พูดทุกปี → [I·K] เผย A9
- เริ่มถามลูกค้าประจำว่าถ้าย้ายไปตรงนั้นจะตามไหม → [V] —
- หาที่สำรองไว้เลย และเริ่มให้ลูกค้าแอด LINE ไว้ตามหาร้าน → [S·G] —
- คิดว่าถึงเวลาเช่าห้องแถวสักที → [G] — (ระวัง A7 ถ้าเลือกที่เพราะถูก)

**1.7 🏷️ใหม่ คุณเลือกทำเลร้านเพราะอะไรเป็นหลัก**
- ค่าเช่าถูก หรือเป็นที่ของครอบครัว → [I] เผย A7
- นั่งนับคนเดินผ่านมาแล้ว 3 วัน ต่างเวลากัน → [S] —
- ชอบบรรยากาศแถวนี้ อยากให้ร้านอยู่ตรงนี้ → [V] เผย A7 (ถ้าไม่มีข้อมูล)
- ใกล้กลุ่มลูกค้าที่ตั้งใจขาย แม้ค่าเช่าจะแพงกว่า → [S·G] —

## บท 2 · 08:00 ครัวเริ่มมีเสียง

*ภาพ: ครัวหลังร้าน กระทะเริ่มร้อน เสียงมีดสับบนเขียง*

**2.1 สูตรน้ำซุป (หรือสูตรกาแฟ) ที่ทำให้ร้านนี้เป็นร้านนี้ ตอนนี้อยู่ที่ไหน**
- อยู่ในหัวผม ทำมาสิบปีไม่เคยต้องจด → [I·P] เผย B1 G13
- จดไว้ในสมุดเล่มหนึ่ง แต่คนอื่นอ่านแล้วทำไม่เหมือน → [I] เผย B1 B2
- มีการ์ดสูตรติดผนัง ชั่งตวงทุกครั้ง ใครทำก็เหมือน → [S] —
- ลูกน้องคนหนึ่งทำเป็น ผมไม่ค่อยได้ลงมือแล้ว → [I] เผย B1 (สูตรอยู่กับคนคนเดียว)

**2.2 ตอนตักข้าวหรือตวงเนื้อลงจาน**
- ตักให้เต็ม ๆ ลูกค้าจะได้ประทับใจ ร้านผมไม่งก → [I·ใจดี] เผย B4 B3
- ใช้ทัพพีอันเดิม ตักเท่ากันทุกจาน → [S] —
- แล้วแต่ลูกค้า ขาประจำได้เยอะหน่อย → [ใจดี] เผย B4 F4 (รั่วทางญาติ/ขาประจำ)
- ชั่งเป็นกรัม ตั้งราคาจากตรงนั้น → [S·P] —

**2.3 คุณรู้ไหมว่าจานที่ขายดีที่สุด ต้นทุนจริง ๆ จานละกี่บาท**
- รู้คร่าว ๆ น่าจะสัก... ไม่แน่ใจ → [I] เผย B3
- รู้ตัวเลขทุกจาน อัปเดตทุกครั้งที่ของขึ้น → [S] —
- ไม่เคยคิด ขายได้กำไรอยู่แล้วเพราะเห็นเงินเข้าทุกวัน → [I] เผย B3 F2
- รู้ แต่ไม่กล้าขึ้นราคาตามต้นทุนอยู่ดี → [S·ใจดี] เผย G12 A2

**2.4 เมนูของร้านตอนนี้มีกี่รายการ**
- เยอะมาก ลูกค้าอยากกินอะไรเราต้องมี → [I·ใจดี] เผย B6 C1
- ประมาณ 15–25 รายการ ตัดทุกปี → [S] —
- ไม่กี่อย่าง ทำอย่างเดียวให้ดีที่สุด → [P·K] —
- เพิ่มเรื่อย ๆ ตามกระแส เมนูไหนคนพูดถึงก็ทำ → [V·G] เผย D14 B6

**2.5 มีจานหนึ่งที่รู้อยู่แล้วว่าขายแล้วแทบไม่ได้กำไร แต่ยังอยู่ในเมนู เพราะ**
- ลูกค้าประจำสั่งอยู่ ตัดไปเขาจะเสียใจ → [ใจดี·K] เผย B7
- ผมชอบทำ มันคือจานที่ผมภูมิใจ → [I·P] เผย B7 B8
- ไม่มี ตัดไปนานแล้ว → [S] —
- ไม่รู้ว่าจานไหนบ้างที่ไม่ได้กำไร → [I] เผย B3 D11

**2.6 ก่อนเปิดร้าน ใครเป็นคนเช็กว่าน้ำแข็งมี ถุงพร้อม เตาติด**
- ผมเดินดูเอง ทุกวัน → [I] เผย B9 B10
- มี checklist แปะไว้ ใครเปิดร้านต้องติ๊ก → [S] —
- ลูกน้องรู้กันเอง ทำมานานแล้ว → [I] เผย B9
- บางวันก็ลืม เปิดไปแล้วค่อยวิ่งซื้อ → [I] เผย B9

**2.7 วัตถุดิบตัวไหนที่ร้านคุณใช้ "ของดี" กว่าที่ลูกค้าจะสังเกตได้**
- หลายอย่าง ผมอยากให้ทุกจานดีที่สุด แม้ลูกค้าจะไม่รู้ → [P·ใจดี] เผย B8 (ถ้าไม่ได้บวกราคา)
- มีตัวเดียว และผมเล่าให้ลูกค้าฟังทุกครั้งว่ามันคืออะไร → [V] —
- ใช้ของที่ราคาสมเหตุสมผล ตัวเลขต้องคุ้มก่อน → [S·P] —
- ไม่มี ของเราเหมือนร้านทั่วไป → [K] เผย E8

**2.8 🏷️เชน วันนี้สาขา 2 โทรมาถามว่าน้ำซุปทำแบบไหน**
- อธิบายทางโทรศัพท์ เขาเคยดูผมทำแล้ว → [I] เผย B11 B1
- ส่งจากครัวกลางทุกเช้า ทุกสาขารสเดียวกัน → [S] —
- ให้แต่ละสาขาปรับตามลูกค้าแถวนั้น → [I·V] เผย B11 C10 กลับด้าน
- ผมขับไปทำเอง → [I] เผย G7 B11

## บท 3 · 12:00 คิวยาวถึงหน้าร้าน

*ภาพ: โต๊ะเต็ม ลูกค้ายืนรอ พนักงานเดินสวนกัน มีเสียงแอปเดลิเวอรีดังแทรก*

**3.1 ลูกค้าใหม่นั่งลงแล้วถามว่า "แนะนำอะไรดีคะ" คุณ (หรือพนักงาน) ตอบว่า**
- แล้วแต่ชอบเลยครับ ของเราอร่อยทุกอย่าง → [I·ใจดี] เผย C4 G11
- จานนี้ครับ ชี้จานเดียวไม่ต้องคิด → [P] —
- จานนี้ค่ะ แล้วเล่าให้ฟังว่าทำไมร้านนี้ต้องเริ่มจากจานนี้ → [V] —
- แล้วแต่วันค่ะ วันนี้อะไรสดก็แนะนำอันนั้น → [I·P] เผย C4 B2

**3.2 ถ้าถามพนักงาน 3 คนว่า "ร้านนี้เด็ดอะไร" คุณคิดว่าจะได้คำตอบ**
- เหมือนกันทุกคน เพราะเราซ้อมกันมา → [S·V] —
- น่าจะต่างกัน แต่ก็ถูกทุกคน → [I] เผย C4 E9
- ไม่แน่ใจ ไม่เคยถาม → [I] เผย C4 E9
- พนักงานไม่ต้องรู้ ผมเป็นคนแนะนำเอง → [I·P] เผย C8 E9

**3.3 คิวยาวออกไปนอกร้าน ครัวเริ่มช้า คุณทำอะไร**
- เข้าครัวช่วยเอง เร็วกว่าอธิบาย → [I] เผย C8 C1
- ไปหน้าร้าน บอกลูกค้าที่รอว่ารออีกกี่นาที แจกน้ำ → [V·S] —
- ตัดเมนูที่ทำช้าออกชั่วคราว บอกพนักงานให้เชียร์ตัวที่ทำเร็ว → [S] —
- ปล่อยไป คิวยาวคือของดี คนเห็นแล้วอยากมา → [I·V] เผย C2 C6

**3.4 บิลวันนี้ 100 ใบ 60 ใบเป็นจานที่ถูกที่สุดในร้าน คุณรู้สึกว่า**
- ดีแล้ว ขายดีคือดี → [I] เผย C5
- ต้องดูว่าจานนั้นกำไรเท่าไร ถ้าน้อยต้องหาทางให้คนสั่งอย่างอื่นคู่ → [S] —
- เป็นเพราะคนแถวนี้ไม่มีกำลังซื้อ → [I] เผย G10 C9
- ปกติของร้านราคานี้ → [K] เผย C5 E7

**3.5 ออร์เดอร์จากแอปเข้ามา 8 ออร์เดอร์พร้อมกัน ขณะที่หน้าร้านเต็ม**
- ทำแอปก่อน เขารีวิวได้ ลูกค้าหน้าร้านรอได้ → [I] เผย C3 C6
- ทำหน้าร้านก่อน คนตรงหน้าสำคัญกว่า → [I·ใจดี] เผย C3 (แอปโดนคะแนนตก)
- มีคนแยกทำแอปโดยเฉพาะ หรือมีเวลาปิดรับแอปตอนพีค → [S] —
- ปิดแอปไปเลยช่วงนี้ ยุ่ง → [I·K] เผย E2 กลับด้าน (ไม่คิดจะจัดการช่องทาง)

**3.6 พนักงานเสิร์ฟผิดโต๊ะ ทำใหม่ทั้งจาน เกิดขึ้นบ่อยแค่ไหน**
- ทุกวัน เป็นเรื่องปกติของร้านอาหาร → [I] เผย C7
- นาน ๆ ที เพราะเราจดผ่านเครื่อง ไม่จดมือ → [S] —
- บ่อย แต่ผมไม่ได้นับ → [I] เผย C7 F5
- แทบไม่มี เพราะเมนูน้อย → [S·P] —

**3.7 ลูกค้าสั่งข้าวจานเดียวแล้วไม่สั่งน้ำ พนักงานของคุณจะ**
- ปล่อย ไม่อยากยัดเยียด → [ใจดี] เผย C9
- ถามว่ารับน้ำอะไรดีคะ ทุกโต๊ะ ทุกครั้ง → [S] —
- บอกว่าวันนี้มีน้ำตัวนี้ที่เข้ากับจานนี้ → [V] —
- ไม่แน่ใจว่าพนักงานพูดอะไรบ้าง → [I] เผย C9 E9
