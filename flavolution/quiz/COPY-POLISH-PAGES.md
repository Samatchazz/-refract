# Copy polish — ภาษาไทยในหน้าเว็บ Flavolution

ต่อจาก `COPY-POLISH.md` (ควิซใน data.js) รอบนี้แก้ข้อความบนหน้าเว็บและ UI ของควิซ ไม่แตะโครงสร้าง HTML, class, id, href, ช่องเหลือง `[...]` ที่ Mat ต้องเติม หรือตัวเลขสถิติ ชื่อบริการ 8 ชื่อคงเดิมทุกตัว

## หลักที่ใช้

1. **พูดแบบเพื่อนที่รู้เรื่องร้าน ไม่ใช่ที่ปรึกษา** ตัดคำแปลและคำแข็ง (“แกน” “วิเคราะห์” “ผลิตให้” “ส่วนแบ่ง” “โฆษณา”) เป็นคำที่เจ้าของร้านพูดจริง (“งานหลัก” “ไล่ดู” “ทำให้เลย” “GP” “ยิงแอด”)
2. **ประโยคหนึ่งพูดเรื่องเดียว แล้วเว้นวรรคให้หายใจ** แตกประโยคยาวตรงจุดที่คนพูดจะหยุด ใช้ “เลย” “พอ” “แค่” แทน “จึง” “เมื่อ” และเลี่ยงประโยคถูกกระทำ (“ถูกคัดลอก” → “คัดลอกไว้ให้แล้ว”)
3. **พาดหัวต้องจำได้และยาวเท่าเดิม** เปลี่ยนเฉพาะที่ฟังเป็นคำแปล (“ร้านคุณคือแบบไหน” → “ร้านคุณเป็นแบบไหน”) หรือกำกวม (“ไปนั่งกินในร้านคุณมาแล้วหลายร้อยครั้ง” → “ในร้านแบบร้านคุณ”)
4. **ใช้ภาษาเดียวกับควิซ** ใช้คำและสำนวนเดียวกับ data.js (GP, ลูกน้อง, ใช้ความรู้สึก, “ร้านนี้ต่างจากร้านอื่นยังไง”) และข้อความเดียวกันที่อยู่หลายหน้า แก้ให้ตรงกันทุกที่
5. **คงข้อเท็จจริงทุกตัว** ตัวเลข ปี แหล่งอ้างอิง และสิ่งที่พูดถึงผู้ก่อตั้งไม่เพิ่มไม่ลด เครื่องหมายคำพูดใช้ “ ” ทั้งหมด
