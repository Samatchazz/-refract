## กำลังทำอะไรอยู่ — 4 เส้นที่วิ่งขนานกัน

**เส้น 1: เลือกทิศทางศิลป์ (รอ Mat — บล็อกทุกเส้นที่เหลือ)**
มีหน้าเทียบ 3 สไตล์ (ก Swiss / ข Riso / ค วาดมือ) ที่ `tools/style-ab.html`
ดูง่ายสุดจากภาพ `tools/style-compare.png` หรือวิดีโอ `tools/style-compare.mp4`
สไตล์ที่เลือกจะคุมทั้ง SVG ในเว็บและคำสั่ง Midjourney ทุกชิ้น

**เส้น 2: เจนภาพจาก Midjourney (พร้อมกดได้ทันทีที่เลือกสไตล์)**
คำสั่งฉบับก็อปวางอยู่ `docs/MJ-PROMPTS.md` (12 ชิ้นเจนได้เลย × 3 สไตล์ —
ทุก prompt มี DNA มาริโอฝังแล้ว) ฉบับตารางอ่านง่ายอยู่ `docs/MJ-ASSET-LIST.docx`
อีก 6 ชิ้นห้ามเจนจนกว่าผังด่านกับลิสต์บริการจะล็อก เหตุผลอยู่ `docs/MIDJOURNEY-BRIEF.md`
ภาพที่ได้ต้องผ่าน potrace เป็น SVG path ก่อนใช้เสมอ

**เส้น 3: ทดลองย้ายโครงไป GSAP (รอเอาพรอมป์ไปวางใน Claude Code)**
Mat อยากเห็นโครงบนมาตรฐานวงการ (GSAP ScrollTrigger + Lenis) เทียบกับ engine
ที่เขียนเอง พรอมป์พร้อมวางอยู่ `docs/PROMPT-CODE-GSAP.md` — งานแรกในพรอมป์คือ
`git init` ที่ planc-web ซึ่งค้างมานานและสำคัญมาก ผลลัพธ์ที่ต้องได้กลับมาคือ
proto หนึ่งไฟล์ + `compare.mp4` แล้ว Mat ตัดสินบนมือถือว่าเอาโครงไหน

**เส้น 4: เคาะเนื้อหาเว็บจาก BMC (รอทำ — Mat เพิ่งต่อโฟลเดอร์ `Z:\Claude Code\PlanCBIz`)**
Mat มี Business Model Canvas ของ Plan C อยู่ในโฟลเดอร์นั้น งานคืออ่าน BMC แล้วผลิต
`docs/CONTENT-MAP.md`: ลิสต์บริการตามลำดับ / แมปอุปสรรค→บริการ / สคริปต์ beat /
เมนูโครงสร้างด่าน **อย่างน้อย 6 แบบ รวมแบบหลายด่าน** (สเปกเต็มของงานนี้อยู่ในพรอมป์
ที่เคยส่งให้ Mat — ถ้าไม่มี ให้ยึดโครง 5 ส่วนที่เพิ่งพิมพ์ไป: services / obstacle-map /
beats / level-structure menu / questions) ห้ามแต่งบริการเพิ่มเอง อะไรที่เดาให้แปะ [เดา]
ไฟล์นี้คือกุญแจปลดล็อก: จำนวนบล็อก `?` = จำนวนบริการ → ความยาวด่าน → ผังด่าน
ที่ Mat จะออกแบบเอง (ของอ้างอิงเตรียมให้แล้วที่ `docs/MARIO-TEARDOWN.md`)

## รอ Mat ตัดสิน (ถามซ้ำได้ แต่อย่าตัดสินแทน)

1. สไตล์ ก / ข / ค — ดู `tools/style-compare.png` / `.mp4`
2. มีศัตรูให้เหยียบไหม ถ้ามีมันแทนปัญหาอะไรของลูกค้า
