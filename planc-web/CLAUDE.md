## สถาปัตยกรรม

สกรอลแนวตั้งคือ input อย่างเดียวของทั้งเว็บ ไม่มีอนิเมชั่นที่เดินด้วยตัวเอง
(ยกเว้นเมฆ) `main.js` แปลง `scrollY` เป็น progress `cur` 0..1 แล้วป้อนให้ทุกระบบ

```
scene.js   เลย์เอาต์ด่าน 4 ชั้นพารัลแลกซ์ พื้น จุดกระโดด แยกคำไทย
cat.js     ริกแมว — ท่าเดินปลอมที่คำนวณจากภาพนิ่งใบเดียว
ui.js      preloader / nav / เมนู / HUD เกม
main.js    ลูป rAF + กล้อง (look-ahead กับ shake ตอนลงพื้น)
```

ริกแมวคือ 3 โหนดซ้อนกัน แต่ละสัญญาณคุม transform ของตัวเอง ไม่แย่งเมทริกซ์กัน:
`#catWrap` (กระโดด+ก้าว translateY) → `#catLean` (เอียงตัว rotate) → `#catSq` (ยืด/ยุบ scale)

## กติกาที่ห้ามผิด

**ทุกตำแหน่งเป็น progress ไม่ใช่พิกเซล** — beat กับ prop ใช้ `data-p` 0..1
แล้ว `layout()` คูณด้วย `travel` ที่คำนวณจากความกว้างจอ ถ้าใส่ px ตายตัวเมื่อไหร่
จอ 390px จะเดินไม่ถึงเสาธง (บั๊กนี้เคยเกิดมาแล้วสองรอบ)

**ด่านมืดห้าม `invert` ตัวแมว** — พื้นก็ invert เป็นขาวด้วย ครึ่งล่างของแมวจะหาย
เข้าไปในพื้น ให้แมวดำไว้แล้วใส่ rim ขาวแทน (30 ก.ย.: rim อบเป็นภาพ `assets/cat-rim.png` วางใต้แมว — `drop-shadow` 4 ทิศแพงเกินบนมือถือ)
กติกาเดียวกันนี้ใช้กับของดำทุกชิ้นที่ต้องอยู่บนพื้นหลังมืด

**ทุกอย่างต้องเลื่อนกลับได้ (scrub-safe)** — เลื่อนขึ้นแล้วแมวต้องเดินถอยหลัง
ท่าเดินผูกกับ *ความเร็ว* สกรอล ไม่ใช่เวลา ห้ามใช้ CSS keyframes กับอะไรที่
ต้องย้อนได้ ห้ามใช้ trigger ที่ยิงครั้งเดียวแล้วไม่คืนสภาพ

**ค่าหน่วงต้องคูณ dt** — `x += (t-x) * (1 - Math.pow(1-k, dt))` ไม่ใช่ `x += (t-x)*k`
ไม่งั้นจอ 120Hz จะรู้สึกคนละเว็บกับ 60Hz

**ข้อความไทยห้ามตัดทีละตัวอักษร** — สระกับวรรณยุกต์จะหลุด ใช้
`Intl.Segmenter('th', {granularity:'word'})` และข้ามเซกเมนต์ที่เป็นช่องว่าง
(span ที่มีแต่ช่องว่างจะยุบ แล้วคำจะเชื่อมติดกัน)

**ทุกกฎ CSS ต้องบอกทั้งสองฝั่ง** — มีแค่ `--ink` กับ `--paper` และ `body.inverted`
สลับทั้งเว็บตอนด่านมืด เพิ่มสไตล์ใหม่ต้องเพิ่มคู่ inverted ด้วยเสมอ

**ห้ามใส่สี** ขาว-ดำล้วนคือคอนเซปต์ ไม่ใช่ placeholder

## แก้อะไรตรงไหน

| อยากแก้ | ไปที่ |
|---|---|
| ข้อความ / ชื่อฉากในเมนู | `index.html` — `data-name` กับเนื้อใน `.beat` |
| ตำแหน่งที่แต่ละฉากโผล่ | `data-p` ใน `index.html` |
| ความยาวด่าน / ความยาวสกรอล | `TRAVEL_MIN`, `SCROLL_LEN` ใน `scene.js` |
| ท่อ / จุดกระโดด | `PIPE_P` และอาเรย์ `jumps` ใน `scene.js` (หลุมถูกแทนด้วยท่อแล้ว) |
| ท่าเดินแรงแค่ไหน | `GAIT_RATE / BOB_PX / LEAN_DEG / SQUASH` ใน `cat.js` |
| ความลึกฉากหลัง | `data-f` ของ `.layer` ใน `index.html` |
| ช่วงด่านมืด | เงื่อนไข `inverted` ใน `main.js` |
| โลโก้ PlanC | `js/planc-rig.js` — เวกเตอร์ rig ได้ **โลโก้จริงคือแมวหลับตา**
  ตาเปิดเฉพาะตอนโต้ตอบ (คลิก/ตามเมาส์) ห้ามใช้ภาพแมวถือมือถือเป็นโลโก้
  มี PNG สำรองที่ `assets/logo-planc-calm.png` (หลับ) / `logo-planc.png` (ลืมตา) |
