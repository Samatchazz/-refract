# ถอดฉากมาริโอ — World 1-1 / 1-2 / 1-3

> ของอ้างอิงสำหรับ Mat ออกแบบภูมิทัศน์ด่านเอง ไม่ใช่ข้อเสนอว่าเราควรมีอะไร
> **ทุกการตัดสินใจด้านดีไซน์เป็นของ Mat อย่าเลือกแทน เสนอทางเลือกแล้วถาม**
> ตัวเลขทุกตัวในไฟล์นี้มาจากแหล่งอ้างอิงท้ายไฟล์ ไม่ได้เขียนจากความจำ
> บรรทัดที่ใส่ **(จำเอา)** ไว้ คือส่วนที่ผมยังหาแหล่งยืนยันไม่ได้ อย่าเชื่อ 100%

## 0. เกมมันไม่ได้คิดเป็น "ภาพฉาก" แต่คิดเป็น "ช่องให้เลือก"

ก่อนจะไล่ของทีละชิ้น อันนี้คือเรื่องที่มีประโยชน์กับเรามากที่สุด และไม่มีใครเห็น
ตอนเล่น — ทุกด่านใน Super Mario Bros. มีหัวข้อมูลอยู่ไม่กี่ไบต์ ที่บอกว่าด่านนี้
หน้าตาแบบไหน และแต่ละช่องเลือกได้แค่ **3–4 ตัวเลือก** เท่านั้น

| ช่อง | ตัวเลือกทั้งหมดที่เกมมี |
|---|---|
| ประเภทฉาก (area type) | พื้นปกติ · ใต้ดิน · ใต้น้ำ · ปราสาท |
| ของประดับหน้า (scenery) | ไม่มี · เมฆ · ภูเขา · รั้ว |
| ฉากหลัง (background) | ไม่มี · ใต้น้ำ · พื้นเหนือน้ำ/ลาวา · กลางคืน\* · หิมะ\* · กลางคืน+หิมะ\* · กำแพงปราสาท\* |
| ชนิดแท่นลอย (platform type) | แท่นต้นไม้เขียว · แท่นเห็ดส้ม · ปืน Bullet Bill · แท่นเมฆ |
| แบบพื้น (floor pattern) | ตั้งแต่ "ไม่มีพื้น" ไล่ไปจนถึง "ตันทั้งจอ" |

\* = มีในเกมแต่ไม่ได้ใช้จริงสักด่าน

**นี่คือบทเรียนข้อแรก** ทั้งเกม 32 ด่านสร้างจากตารางนี้ ไม่มีด่านไหนมีของประดับ
เฉพาะตัว ถ้าเราจะออกแบบภูมิทัศน์ด่านของเรา สิ่งที่ต้องตัดสินใจไม่ใช่ "ฉากนี้มี
อะไรบ้าง" แต่คือ **"เรามีชุดตัวเลือกกี่ชุด แล้วสลับมันเมื่อไหร่"** — ซึ่งตรงกับ
ข้อจำกัดของเราพอดี เพราะทุกชิ้นต้องผ่าน potrace แล้วกลับสีได้ในด่านมืด
ยิ่งมีชิ้นน้อยยิ่งคุมได้

## 1. World 1-1 — ด่านที่สอนทุกอย่างโดยไม่มีตัวหนังสือ

### 1.1 ชั้นฟ้า (ไม่มีอะไรเลย)

พื้นหลังเป็นสีฟ้าตันสีเดียว ไม่มีไล่เฉด ไม่มีลาย ไม่มีเส้นขอบฟ้า
ของทุกชิ้นที่เห็น "ในฟ้า" คือสไปรท์ที่วางทับลงไป ไม่ใช่ภาพพื้นหลัง

### 1.2 ชั้นประดับล้วน — ชนไม่ได้ เหยียบไม่ได้ ไม่มีผลกับเกมเลย

| ชิ้น | ตัวแปรที่มี | หมายเหตุ |
|---|---|---|
| เนินเขา | **2 ขนาด** เล็ก / ใหญ่ | ใหญ่คือทรงเดียวกันแต่กว้างขึ้น มีจุดเข้มบนตัวเนิน |
| พุ่มไม้ | **3 แบบ** 1 พู / 2 พู / 3 พู | ต่อกันเป็นแนวยาวได้ |
| เมฆ | **3 แบบ** 1 ก้อน / 2 ก้อน / 3 ก้อน | **รูปทรงเดียวกับพุ่มไม้เป๊ะ ต่างแค่สี** |
| ต้นไม้ | 2 ขนาด เล็ก / ใหญ่ | มีในชุดกราฟิก ด่าน 1-1 ไม่ได้ใช้ |
| รั้ว | ต่อกันเป็นแนว | มีในชุดกราฟิก ด่าน 1-1 ไม่ได้ใช้ |

**เมฆ = พุ่มไม้** คือทริกที่ดังที่สุดของเกมนี้ และมันไม่ใช่แค่ประหยัดหน่วยความจำ
มันทำให้ฉากดู "เป็นชุดเดียวกัน" ฟรีๆ ตาคนอ่านออกว่าฟ้ากับพื้นมาจากโลกเดียวกัน
โดยไม่ต้องมีใครอธิบาย

### 1.3 ชั้นพื้นและภูมิประเทศ

| ชิ้น | จำนวน / รายละเอียด |
|---|---|
| พื้น (ground tile) | ช่องเดียวปูซ้ำทั้งด่าน สองแถวเป็นมาตรฐาน |
| หลุม | **2 ช่วง** ทั้งคู่อยู่ครึ่งหลังของด่าน (คู่มือเรียก "หลุมแรก" กับ "หลุมที่สอง") |
| ท่อ | **4 ท่อ** เตี้ยไปสูง — **ท่อที่ 4 เข้าไปได้** พาไปห้องเหรียญลับ (ความสูงเป๊ะๆ ยังไม่ยืนยัน) |
| บันไดหิน (hard block) | 2 ชุดตอนท้าย มีช่องว่างคั่นให้ต้องกระโดด |

ท่อทั้งสี่ท่อคือ **ชิ้นส่วนสองชิ้น**: ปากท่อ 1 ชิ้น + ลำท่อ 1 ชิ้นที่ต่อลงไปเรื่อยๆ
บันไดก็เหมือนกัน — บล็อกสี่เหลี่ยมอันเดียว วางซ้อนเป็นสามเหลี่ยม

### 1.4 ชั้นของที่โต้ตอบได้

| ชิ้น | จำนวน | ให้อะไร |
|---|---|---|
| บล็อก `?` | หลายอัน วางเป็นทรงสามเหลี่ยม | เหรียญ 10 เหรียญรวม + ของขึ้นสถานะ 3 ชิ้น |
| อิฐ | หลายอัน | ส่วนใหญ่ว่าง ทุบแตก · มีอันหนึ่งซ่อนเหรียญ 10 เหรียญ · อีกอันซ่อนดาว |
| บล็อกล่องหน | อย่างน้อย 2 | อันหนึ่งมีเห็ด 1-Up |
| เหรียญ | **39 เหรียญทั้งด่าน** | 10 จากบล็อก `?` · สูงสุด 10 จากอิฐลับ · **19 อยู่ในห้องลับ** |
| ของขึ้นสถานะ | 3 | เห็ด หรือ ดอกไฟ (แล้วแต่สถานะผู้เล่น) |
| ดาว | 1 | ซ่อนในอิฐ |
| เห็ด 1-Up | 1 | ซ่อนในบล็อกล่องหน |

สังเกตว่า **เกือบครึ่งของเหรียญทั้งด่านอยู่ในห้องที่ผู้เล่นส่วนใหญ่ไม่เคยเข้า**
ด่านนี้ให้รางวัลกับคนที่ลองของมากกว่าคนที่เดินตรงไป

### 1.5 ศัตรู

| ตัว | จำนวน | บทบาท |
|---|---|---|
| กูมบา | **16 ตัว** | เดินสวนมาอย่างเดียว เหยียบตาย |
| เต่าเขียว (Koopa Troopa) | **1 ตัว** | เหยียบแล้วไม่ตาย กลายเป็นกระดอง = ของที่ผู้เล่นถือได้ |

16 ต่อ 1 คืออัตราส่วนที่ตั้งใจ — ด่านแรกไม่ได้สอนศัตรูหลายชนิด มันสอน
**ศัตรูชนิดเดียวในหลายบริบท** (ตัวเดียว, สองตัวพร้อมกัน, ตัวที่เดินอยู่ใต้ที่แคบ,
ตัวที่โผล่ตอนกำลังกระโดด) แล้วค่อยแนะนำเต่าตัวเดียวตอนท้ายเป็นของแถม

### 1.6 ปลายด่าน

| ชิ้น | หมายเหตุ |
|---|---|
| เสาธง | เสา + ลูกกลมบนยอด + ผ้าธงที่เลื่อนลงตามคะแนน |
| ปราสาทเล็ก | ประตู ป้อม หน้าต่าง + ธงที่ชูขึ้นตอนจบ |
| พลุ | 3 สไปรท์ ยิงเมื่อเลขวินาทีลงท้าย 1/3/6 |

### 1.7 ห้องลับใต้ดิน

เข้าจากท่อที่ 4 → ห้องสี่เหลี่ยมปิด พื้นหลังดำ ผนังอิฐ **มีเหรียญ 19 เหรียญ**
ไม่มีศัตรู ไม่มีของประดับ ออกทางท่อที่โผล่ใกล้ปลายด่าน

**นี่คือสิ่งที่ 1-1 ทำแล้วเราไม่มีเลย: ทางเลือกที่สอง** ด่านของเราตอนนี้เป็นเส้นตรง
เส้นเดียว สกรอลลงคือเดินหน้า จบ

### 1.8 ลำดับที่ของโผล่ (นี่คือหัวใจของ 1-1)

ทุกของใหม่ถูกแนะนำ **ตัวเดียว ในที่ปลอดภัย** ก่อนเสมอ แล้วค่อยเอาไปผสมกับของอื่น

```
กูมบาตัวเดียว (พื้นโล่ง ไม่มีอะไรเหนือหัว)
  → บล็อก ? ตัวเดียว
    → บล็อก ? + อิฐ เรียงกัน + กูมบาเดินอยู่ข้างล่าง
      → ท่อเตี้ย (กระโดดพลาดก็ไม่ตาย)
        → ท่อสูงขึ้นเรื่อยๆ
          → หลุม (พลาดแล้วตายจริง)
            → หลุม + ศัตรู พร้อมกัน
              → บันได + ช่องว่าง + เสาธง
```

ไม่มีตัวหนังสือสอนสักคำ ทั้งด่านยาวประมาณ 20–30 วินาทีในการเล่นปกติ

## 2. World 1-2 — ด่านที่เอา "ฟ้า" ออก

### 2.1 ชั้นประดับ

**ไม่มี** — นี่คือประเด็นทั้งหมดของด่านนี้ พื้นหลังเป็นสีดำตัน ไม่มีเมฆ ไม่มีเนิน
ไม่มีพุ่มไม้ ไม่มีอะไรเลย ของที่ทำหน้าที่ "ตกแต่ง" คือ **ตัวโครงสร้างเอง**:
เพดานอิฐที่ต่อยาวทั้งด่าน กับผนังอิฐสองข้าง

ผลคือความรู้สึกเปลี่ยนทันทีโดยไม่ต้องเพิ่มสไปรท์ใหม่แม้แต่ชิ้นเดียว —
**เอาของออก ไม่ใช่ใส่ของเพิ่ม**

### 2.2 ภูมิประเทศ

| ชิ้น | รายละเอียด |
|---|---|
| เพดานอิฐ | ต่อเนื่องเกือบทั้งด่าน — ตัวแปรใหม่ที่ 1-1 ไม่มี คือ "เพดานต่ำ" |
| ผนัง / เสาอิฐ | แบ่งด่านเป็นห้องๆ |
| พื้นอิฐ | ปูเป็นชั้น มีช่องหลุดตกได้ |
| หลุม / ช่องว่าง | หลายจุด |
| บันไดบล็อกแข็ง | ตอนใกล้ทางออก |
| ลิฟต์ | **2 ตัว หนึ่งขึ้น หนึ่งลง** วิ่งวนไม่หยุด |

**ลิฟต์คือของใหม่ชิ้นเดียวที่แนะนำในด่านนี้** และมันคือของชิ้นแรกในเกมที่
**เคลื่อนที่เองโดยไม่เกี่ยวกับผู้เล่น** (ก่อนหน้านี้มีแค่ศัตรู)

### 2.3 ของที่โต้ตอบได้

| ชิ้น | จำนวน |
|---|---|
| บล็อก `?` | 5 อัน (กระจุกอยู่ช่วงต้นด่าน) |
| อิฐ | หลายกลุ่ม รวมทั้งกองพีระมิด |
| อิฐซ่อนเหรียญ | มีถึง 30 เหรียญกระจายใน 3 บล็อก + อีกบล็อก 10 เหรียญ |
| เหรียญ | **68 เหรียญ** (เทียบ 1-1 ที่ 39) |
| ของขึ้นสถานะ | 3 |
| ดาว | 1 (ซ่อนในอิฐ) |
| เห็ด 1-Up | 1 (ซ่อนในอิฐบนเพดาน) |

### 2.4 ศัตรู — **22 ตัว**

| ตัว | จำนวน | ใหม่ไหม |
|---|---|---|
| กูมบา | 14 | เดิม |
| เต่าเขียว | 3 | เดิม |
| เต่าแดง | 1 | **ใหม่** — ไม่เดินตกขอบ |
| ต้นไม้กินคน (Piranha Plant) | 4 | **ใหม่** — โผล่จากท่อ ทำให้ "ท่อ" เปลี่ยนความหมาย |

Piranha Plant คือตัวอย่างการออกแบบที่ควรจำ: **ไม่ได้เพิ่มศัตรูใหม่เฉยๆ แต่เพิ่ม
ความหมายใหม่ให้ของเก่า** ท่อใน 1-1 เป็นแค่กำแพงให้กระโดดข้าม พอถึง 1-2 ท่อเดิม
กลายเป็นของที่ต้องระวัง โดยไม่ต้องวาดท่อใหม่

### 2.5 ปลายด่าน + Warp Zone

ทางออกปกติคือท่อที่พาขึ้นไปโผล่พื้นดินด้านนอก แล้วเดินไปเสาธง (มี Piranha Plant
เฝ้าท่อสุดท้าย)

แต่ถ้าขึ้นลิฟต์ไปจนถึงเพดานแล้วเดินต่อไปบนหลังคา จะเจอ **Warp Zone แรกของเกม**:
ห้องที่มีท่อ 3 ท่อไปโลก 2 / 3 / 4 พร้อมตัวหนังสือบอกบนหัวท่อ

จุดที่น่าสนใจสำหรับเรา: Warp Zone อยู่ **นอกด่าน** — มันคือรางวัลของการเดินไปใน
ที่ที่ดูเหมือนไม่ควรเดินได้ ไม่มีอะไรชี้บอกเลย

## 3. World 1-3 — ด่านที่เอา "พื้น" ออก

### 3.1 ชั้นประดับ

ฟ้ากลับมา เมฆกลับมา แต่ **เนินกับพุ่มไม้หายไป** เพราะไม่มีพื้นดินให้มันยืน
**(จำเอา — ยังไม่เจอแหล่งที่ระบุชัด)**

ของที่ทำหน้าที่ตกแต่งจริงๆ ในด่านนี้คือ **ตัวแท่นเอง** — ยอดต้นไม้สีเขียว
ที่มีลำต้นเข้มห้อยลงมา ("tree top world" ตามที่คู่มือเรียก) ซึ่งในหัวข้อมูลของเกม
คือค่า platform type ตัวแรกจากสี่ตัว (แท่นต้นไม้เขียว / แท่นเห็ดส้ม /
ปืน Bullet Bill / แท่นเมฆ)

### 3.2 ภูมิประเทศ

| ชิ้น | รายละเอียด |
|---|---|
| แท่นยอดไม้ | **ทั้งด่านคือแท่นลอย ไม่มีพื้นต่อเนื่องเลย** ตกคือตาย |
| ลิฟต์ | **2 ตัว เลื่อนแนวนอน** |
| บันไดหิน | ก่อนถึงเสาธง |
| เสาธง | ปลายด่าน |

**นี่คือด่านที่กลับกันกับ 1-1 อย่างสมบูรณ์** 1-1 คือพื้นต่อเนื่องที่มีหลุมแทรก 2 จุด
1-3 คือช่องว่างต่อเนื่องที่มีพื้นแทรกเป็นจุดๆ — ใช้กราฟิกชุดเดิมเกือบทั้งหมด
แต่รู้สึกคนละเกม

### 3.3 ของที่โต้ตอบได้ — น้อยมาก

| ชิ้น | จำนวน |
|---|---|
| บล็อก `?` | **1 อัน** (มีของขึ้นสถานะ 1 ชิ้น) |
| เหรียญ | **23 เหรียญ และทั้งหมดวางอยู่กลางอากาศ ไม่มีอันไหนอยู่ในกล่อง** |

นี่คือข้อที่ผมคิดว่ามีประโยชน์กับเรามากที่สุดในทั้งไฟล์นี้:
**พอด่านยากขึ้น เกมเลิกซ่อนของ** เพราะความยากย้ายไปอยู่ที่ "ไปถึงได้ไหม" แล้ว
ไม่ใช่ "รู้ไหมว่ามันอยู่ตรงไหน" เหรียญทุกเหรียญใน 1-3 คือ **ป้ายบอกทาง** —
มันวางเป็นเส้นโค้งตามวิถีกระโดดที่ถูกต้อง เหรียญไม่ได้เป็นรางวัล แต่เป็น**คำสั่ง**

### 3.4 ศัตรู — 8 ตัว

| ตัว | จำนวน | หมายเหตุ |
|---|---|---|
| กูมบา | 3 | |
| เต่าแดง | 3 | ไม่เดินตกขอบ = อยู่บนแท่นแคบได้ |
| เต่าแดงมีปีก (Paratroopa) | 2 | **ใหม่** — บินขึ้นลง |

ศัตรูลดจาก 22 เหลือ 8 เพราะ **ตัวด่านเองกลายเป็นศัตรูแล้ว**

## 4. สามด่านเทียบกัน

| | 1-1 | 1-2 | 1-3 |
|---|---|---|---|
| ฟ้า | มี | **ไม่มี (ดำ)** | มี |
| พื้นต่อเนื่อง | มี | มี (เป็นชั้น) | **ไม่มี** |
| ของประดับล้วน | เนิน พุ่ม เมฆ | **ไม่มีเลย** | เมฆ |
| ศัตรู | 17 | 22 | 8 |
| ชนิดศัตรู | 2 | 4 | 3 |
| เหรียญ | 39 (19 อยู่ในห้องลับ) | 68 | 23 (โล่งหมด) |
| บล็อก `?` | หลายอัน | 5 | **1** |
| ของใหม่ที่แนะนำ | ทุกอย่าง | ลิฟต์, Piranha, เต่าแดง | แท่นลอย, Paratroopa |
| ความรู้สึก | เรียนรู้ | อึดอัด / ลับ | เสี่ยง / แม่นยำ |

**สามด่านนี้ใช้ชิ้นส่วนกราฟิกชุดเดียวกันเกือบทั้งหมด** ของใหม่จริงๆ ที่วาดเพิ่ม
ตลอดโลกที่ 1 มีแค่ ลิฟต์ · Piranha Plant · ปีกเต่า · ยอดต้นไม้ ที่เหลือคือ
**การจัดวางของเดิมใหม่** และการ **เอาของออก**

## 5. ทริกใช้ซ้ำทั้งหมดที่เจอ

1. **เมฆ = พุ่มไม้** สไปรท์เดียวกัน คนละสี
2. **เนินใหญ่ = เนินเล็กขยาย** ทรงเดียวกัน
3. **เมฆ/พุ่มไม้มี 3 ขนาด แต่ไม่ใช่ 3 ภาพ** — มันคือหน่วยเดียวกันต่อกัน 1/2/3 หน่วย
4. **ท่อ = ปากท่อ + ลำท่อที่ต่อลงไป** สูงเท่าไหร่ก็ได้จากสองชิ้น
5. **บันได = บล็อกอันเดียววางซ้อน**
6. **เพดานใต้ดิน = พื้นกลับหัว** ใช้ tile เดียวกัน
7. **กระดองเต่า = ทั้งศัตรูและอาวุธ** ของชิ้นเดียวสองหน้าที่
8. **ท่อใน 1-1 เป็นกำแพง / ท่อใน 1-2 เป็นอันตราย** ภาพเดิม ความหมายใหม่

ถ้าจะเอาไปใช้กับ 16 ชิ้นใน `MIDJOURNEY-BRIEF.md` แปลว่าเราน่าจะ**เจนน้อยกว่า 16**
ได้ด้วยซ้ำ ถ้ายอมให้บางชิ้นทำสองหน้าที่

---

## 6. สัดส่วน "ประดับล้วน" ต่อ "โต้ตอบได้"

นับเฉพาะ 1-1: ของประดับล้วนมี **5 ชนิด** (เนิน พุ่ม เมฆ + ปราสาท + พลุ)
ของที่โต้ตอบได้มี **8 ชนิด** (พื้น ท่อ อิฐ บล็อก `?` บล็อกล่องหน เหรียญ ของขึ้นสถานะ เสาธง)
บวกศัตรู 2 ชนิด

**ประดับน้อยกว่าของที่ใช้งานได้** — และของประดับทั้งหมดอยู่ในชั้นที่ไกลกว่าตัวละคร
ไม่มีของประดับชิ้นไหนอยู่ในระนาบเดียวกับมาริโอเลยสักชิ้น
ถ้าเราจะใส่ของตกแต่งในระนาบพื้น (เช่นหญ้าที่แมวเบียดผ่าน) นั่นคือของที่มาริโอไม่มี
และมันจะทำงานคนละแบบ — ต้องเป็นโค้ด ไม่ใช่ภาพเจน (ตรงกับข้อ 3 ใน `MIDJOURNEY-BRIEF.md`)
