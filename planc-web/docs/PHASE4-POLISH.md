# เฟส 4 — อนิเมชั่นละเอียดขึ้น ฉากหลังสวยขึ้น ให้มันเป็นศิลปะ

> กติกาใน `CLAUDE.md` ยังใช้ทั้งหมด ไฟล์นี้เพิ่มเฉพาะของเฟสนี้
> **ทิศทางศิลป์เป็นการตัดสินใจของ Mat** ไฟล์นี้ไม่ได้บอกว่าต้องสวยแบบไหน
> มันบอกว่า *ตรงไหนยังบาง* กับ *ทำยังไงไม่ให้พัง* — ส่วนจะเอาแบบไหน ต้องถาม

## มีอะไรอยู่แล้วบ้าง (อย่าทำซ้ำ อย่ารื้อ)

- **แมว** เด้งตามก้าว เอียงตัว ยืด/ยุบ ยืดตอนพุ่งขึ้น หุบตอนตก แรงกระแทกตอนลงพื้น เงาย่อ-ขยายตามความสูง
- **กล้อง** look-ahead ตามทิศเดิน + สั่นตอนลงพื้น (คูณ depth factor ของแต่ละชั้น)
- **ฉากหลัง** 4 ชั้นพารัลแลกซ์ + เมฆที่ลอยด้วยนาฬิกาตัวเอง
- **DEADLINE** ตาเหลือบมองแมวตอนเข้าใกล้ แล้วยุบตอน `cur > 0.419`
- **block** เด้งตอน `cur > 0.611`
- **ด่านมืด** สลับ `--ink`/`--paper` ทั้งเว็บช่วง `cur` 0.69–0.86
- **ข้อความ** เข้าทีละคำ ตัดคำไทยถูกต้อง

## ตรงที่ยังบาง — นี่คืองานเฟส 4

### 1. ฉากกระโดด

ตอนนี้คือพาราโบลาเปล่าๆ ขึ้นแล้วลง จบ ไม่มีจังหวะก่อนและหลัง

ที่ขาด: **ย่อตัวก่อนถีบ** (anticipation), ฝุ่นตอนถีบพื้น, เส้นความเร็วตอนพุ่ง,
**ทรงตัวหลังลงพื้น** (recovery) ที่ยาวกว่าแรงกระแทกปัจจุบัน

**กับดัก:** anticipation ปกติผูกกับเวลา ("ก่อนกระโดด 0.15 วิ") แต่เว็บนี้ไม่มีเวลา
มีแต่ตำแหน่ง ต้องทำเป็น **ฟังก์ชันของระยะก่อนถึงจุดกระโดด** — เช่น
`const pre = clamp((j.p - cur) / j.w, 0, 1)` แล้วเอา `pre` ไปคุมการย่อ
ถ้าไปใช้ `setTimeout` หรือ flag ว่า "กระโดดไปแล้ว" เลื่อนถอยหลังจะพังทันที

### 2. ฉากเหยียบ

ตอนนี้คือสลับ class `.squashed` เฉยๆ อยู่บรรทัดเดียวใน `main.js`

ที่ขาด: แมว**เด้งขึ้นหลังเหยียบ** (นี่คือหัวใจของท่านี้ ตอนนี้ไม่มีเลย),
DEADLINE ยุบเป็นขั้นไม่ใช่หายวูบ, ฝุ่นกระจายด้านข้าง, กล้องกระตุกสั้นๆ,
ป้ายคำว่า DEADLINE ร่วงหล่น

**ต้องรื้อก่อน:** ตอนนี้เลข `0.419` กับ `0.611` ฝังตายอยู่ใน `main.js`
ย้ายไปเป็นอาเรย์ `stomps` ใน `scene.js` ให้เหมือน `jumps` เสียก่อน
ไม่งั้นพอเพิ่มจุดเหยียบจุดที่สอง จะต้องไปแก้ `main.js` ทุกครั้ง

### 3. ฉากหลัง

ตอนนี้เป็น SVG เรียบมาก เนินโค้ง 1 ชั้น + ตึกสี่เหลี่ยม 1 ชั้น + หญ้าแหลม
มันสะอาดแต่ยังไม่มีคาแรกเตอร์

ทางเลือกที่**เสนอให้ Mat เลือก** (อย่าเลือกเอง อย่าทำทั้งหมด):

- เพิ่มชั้นที่ 5 คั่นระหว่างตึกกับพื้น (เสาไฟ ป้าย สายไฟ)
- เปลี่ยนตึกเป็นซิลูเอทกรุงเทพจริง (ตึกใบหยก ตึกช้าง วัด รถเมล์)
- ใส่ texture — halftone dot / riso grain / เส้นแรเงาแบบภาพพิมพ์
- เปลี่ยนจากเส้นเรียบเป็นเส้นแบบวาดมือ (SVG path ที่สั่นเล็กน้อย)
- ดวงจันทร์/ดวงอาทิตย์ที่เลื่อนตำแหน่งตาม `cur` — ทำให้ทั้งด่านรู้สึกว่าเวลาผ่านไป
  และรับกับด่านมืดพอดี

**ข้อห้าม:** ห้ามใส่สี (ขาว-ดำคือคอนเซปต์ ไม่ใช่ placeholder)
และห้ามใช้ไฟล์ภาพ raster — ฉากหลังทุกชิ้นเป็น SVG ฝังใน CSS เป็น data URI
เพื่อให้ `build.py` รวมเป็นไฟล์เดียวได้

### 4. รายละเอียดเล็กๆ ที่ทำให้ดูแพงขึ้น

- motion blur ตอนเลื่อนเร็ว (ทำด้วยเงาซ้อนโปร่งจะถูกกว่า `filter:blur()` มาก)
- DEADLINE ขยับตอนยืนเฉยๆ — หายใจ / ป้ายแกว่ง
- ฝุ่นใต้เท้าตอนเดินเร็ว
- ธงบนเสาปลิวแรงขึ้นตอนแมวเข้าใกล้
- grain / noise บางๆ ทับทั้งจอ
- ตอนเข้า-ออกด่านมืด ตอนนี้เป็น fade ธรรมดา 0.6s — อาจทำเป็นกวาดเป็นแนวได้
- หน้า `#end` ตอนนี้เลื่อนขึ้นมาเฉยๆ ยังไม่มีอนิเมชั่นของตัวเอง

## กติกาที่ห้ามผิดในเฟสนี้

**1. ทุกเอฟเฟกต์ต้องเป็นฟังก์ชันของ `cur` ไม่ใช่ของเวลา**

นี่คือกฎที่จะโดนละเมิดบ่อยที่สุดในเฟสนี้ เพราะของสวยๆ ส่วนใหญ่
(ฝุ่น เส้นความเร็ว การเด้ง) โดยธรรมชาติมันผูกกับเวลา

อยากได้ particle ที่มีอายุ ให้คำนวณอายุจาก**ระยะ** `(cur - p)` ไม่ใช่จาก timestamp
ห้ามใช้ class ที่ยิงครั้งเดียวแล้วไม่คืนสภาพ ห้าม `setTimeout` ห้าม CSS keyframes
กับอะไรที่ต้องย้อนได้

ยกเว้นได้แค่สามอย่าง: เมฆ, grain, การหายใจตอนอยู่เฉยๆ —
พวกนี้มีนาฬิกาตัวเองได้ เพราะมันไม่มี "สถานะ" ที่ต้องย้อน

**2. เป้าหมายคือมือถือ 390px**

- ขยับได้แค่ `transform` กับ `opacity` เท่านั้น ห้าม animate `width/height/top/left`
- `filter:blur()` แพงมากบนมือถือ ถ้าจะใช้ต้องวัด fps จริง
- particle พร้อมกันไม่เกิน ~12 ชิ้น
- ใส่ตัวนับ fps ชั่วคราวแล้ว**วัดบนมือถือจริง** ไม่ใช่วัดบนเดสก์ท็อปแล้วเดา

**3. อ่านออกต้องมาก่อนสวย** ฉากหลังแน่นขึ้นเท่าไหร่ ตัวหนังสืออ่านยากขึ้นเท่านั้น
เพิ่มอะไรลงฉากหลังแล้วต้องเช็คทุก beat ว่ายังอ่านออกที่ 390px

## วิธีทำงาน — ทีละอย่าง

**อย่าทำรวดเดียวทั้งลิสต์** ทำทีละข้อ → `node tools/shots.mjs` และ `tools/rec.mjs`
→ ส่งให้ Mat ดู → ค่อยทำข้อถัดไป

เพราะทุกข้อในไฟล์นี้เป็นเรื่อง "รู้สึกยังไง" ตัดสินจากโค้ดไม่ได้เลย
และถ้าทำสิบอย่างพร้อมกันแล้วมันรู้สึกผิด จะแยกไม่ออกว่าอย่างไหนผิด

## ที่ Mat ต้องเป็นคนเลือก — อย่าตัดสินแทน

- **ทิศทางศิลป์รวม**: เกลี้ยงแบบ Swiss / หยาบแบบภาพพิมพ์ riso / ลายเส้นวาดมือ
- **แรงของอนิเมชั่น**: เนียนสุภาพ หรือ การ์ตูนเกินจริงแบบเกม
- **ฉากหลังจะแน่นขึ้นแค่ไหน** — แลกกับความอ่านง่าย
- **ใส่ grain ไหม** (ใส่แล้วอบอุ่นขึ้น แต่บนมือถือบางรุ่นจะเห็นเป็นจุดหยาบ)

เสนอเป็นตัวเลือกให้ดูก่อน ทำตัวอย่างสั้นๆ เทียบกันได้ยิ่งดี แล้วถาม
