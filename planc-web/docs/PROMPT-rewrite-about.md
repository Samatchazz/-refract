# Prompt ส่งให้แชทที่เรียน corpus งานเขียนของ Mat — เขียนข้อความหน้า "เกี่ยวกับเรา" ของ planc* ใหม่

(ก๊อปตั้งแต่บรรทัดถัดไปไปวางได้เลย)

---

งานนี้คือเขียนข้อความบนเว็บ planc* ใหม่ทั้งแผ่น ให้เป็นน้ำเสียงของเรา (Mat) ตาม corpus งานเขียนที่คุณเรียนไว้ ไม่ใช่แปลคำต่อคำ และไม่ใช่ภาษาโฆษณา

## planc* คืออะไร

บริการที่ปรึกษาสำหรับคนทำคอนเทนต์ / อินฟลูเอนเซอร์ คนทำคือเราเอง ทำคอนเทนต์เป็นอาชีพมาสิบกว่าปี คนตามรวมทุกแพลตฟอร์มราวสองล้าน มีบริษัทของตัวเองที่รับงานแบรนด์ใหญ่มาตลอด และเคยนั่งฝั่งที่เป็นคนจ่ายเงินจ้างด้วย

สิ่งที่ขายคือคำแนะนำ ไม่ใช่งาน: เราไม่หาดีลให้ ไม่อยู่ตรงกลางระหว่างครีเอเตอร์กับแบรนด์ ไม่หักเปอร์เซ็นต์ จุดยืนคือบอกความจริง แม้คำตอบจะเป็น "เลิกเถอะ" หรือ "ทำเป็นงานเสริมไปก่อน" ตอนนี้ยังไม่เปิดชื่อว่าเราเป็นใคร (ยังทำงานกับแบรนด์อยู่)

ราคามีสามแบบ: คุยครั้งแรกฟรี 30–45 นาที / เซสชันเดี่ยว ฿999 ต่อ 30 นาที / สมาชิก ฿2,000 ต่อเดือน

## เว็บหน้าตาเป็นยังไง

เว็บเป็นหน้าเดียว ครึ่งบนเป็นเกมเลื่อนจอ แมวดำ (ตัวแทนคนดู) เดินผ่านด่านแบบมาริโอ เจอป้ายคำถามที่คนทำคอนเทนต์ถามตัวเอง ("เดือนนี้จะมีงานไหม" "ทำไมยอดวิวลด") ฝนตก ฟ้ามืด ไปติดที่ขอบเหว มือถือแมวเด้งแชตจาก planc* ว่า "ให้ planc* ช่วยไหม / ไม่ต้องข้ามคนเดียวก็ได้นะ" กดตอบแล้วสะพานสายรุ้งมา มีพลุ แมวเกาะธง โลกขาวดำกลายเป็นสี

จากนั้นแผ่นที่คุณกำลังจะเขียนเลื่อนขึ้นมาทับฉากนั้น หน้าตาเป็นแบบ burocratik.com: ตัวอักษรใหญ่มาก พื้นขาว เส้นคั่นบาง ๆ ข้อความน้อยแต่ละบรรทัดต้องมีน้ำหนัก ลำดับคือ

1. คำประกาศ (ประโยคเปิดตัวใหญ่ประโยคเดียว)
2. ตัวเลข ~2 ล้าน ตัวยักษ์ + "เราเป็นใคร" + ตราเล็ก 4 ใบ
3. หลักที่เราถือ 5 ข้อ
4. ราคา (การ์ดสามใบ ใบฟรีอยู่กลาง)
5. คุยจบ คุณได้อะไร + ขั้นตอน 5 ข้อ
6. ถามตอบ 6 ข้อ
7. ติดต่อ (ทัก LINE / จองคุยครั้งแรก)
8. ท้ายเว็บ

คนอ่านคือคนทำคอนเทนต์ที่กำลังติด ยอดตก งานหาย ไม่รู้จะไปทางไหน เขาเพิ่งเล่นเกมแมวจบมา อารมณ์กำลังดี อย่าทำให้รู้สึกว่าโดนขาย

## สิ่งที่อยากได้

- เขียนคอลัมน์ F ให้ครบทุกแถวที่คิดว่าควรเปลี่ยน แถวไหนของเดิมดีอยู่แล้วเว้นว่างไว้ (ว่าง = ใช้ของเดิม)
- เขียนเป็นเสียงเรา ภาษาคนพูด เรียบ ตรง มีจังหวะ ไม่ใช่ภาษาการตลาด ไม่ใช่ภาษาแปล
- คิดทั้งแผ่นเป็นเรื่องเดียว อย่าเขียนทีละช่องแยกกัน บรรทัดบนควรส่งให้บรรทัดล่าง และอย่าพูดเรื่องเดิมซ้ำหลายที่ (ตอนนี้ "10 ปี / 2 ล้าน / ฟรี" ซ้ำหลายจุด ถ้าเห็นว่าควรตัดจุดไหน บอกได้)
- ถ้าเห็นว่าบรรทัดไหนควรตัดทิ้งทั้งบรรทัด ให้เขียนในคอลัมน์ F ว่า `[ตัด]` พร้อมเหตุผลสั้น ๆ
- ถ้าอยากเพิ่มบรรทัดที่ไม่มีในชีต เพิ่มแถวใหม่ท้ายส่วนนั้น ใส่รหัสว่า `ใหม่` และบอกในคอลัมน์ C ว่าอยากให้อยู่ตรงไหน

## กติกา

- สรรพนาม: planc* = **เรา** คนอ่าน = **คุณ** ทุกที่
- ไม่เรียกตัวเองว่าเอเจนซี
- ไม่สัญญาว่าใครจะได้งาน ได้ยอด หรือได้ดีล ส่วนประโยค "เราไม่รับประกันว่าคุณจะได้งาน" ที่มีอยู่ 3 จุด **ไม่ต้องคงไว้ตามตัวอักษร** เขียนใหม่ได้เต็มที่ จะพูดแบบไหน ตรงไหน กี่ครั้ง เสนอมาได้เลย
- ความยาว: ปุ่ม ป้าย ตรา และตัวยักษ์ต้องสั้นพอ ๆ กับของเดิม (ดูคอลัมน์ E) ย่อหน้ายืดหดได้ แต่ทั้งแผ่นไม่ควรยาวขึ้น
- `[รูปแมว]` กับ `*` ในประโยคเปิดคือไอคอนที่แทรกอยู่ในบรรทัด ย้ายตำแหน่งได้ อย่าลบ
- ช่องที่มี `[ร่าง]` คือรอข้อมูลจริง (LINE, ระบบจอง, ชื่อบริษัท, VAT, กติกาเลื่อนนัด) ข้ามได้
- แถว B5-02 ในเว็บมีบางท่อนเป็นสีเทา (ท่อนรอง) ถ้าเขียนใหม่ ใส่วงเล็บครอบท่อนที่อยากให้เป็นสีเทา
- ตัวเลขข้อเท็จจริง (10+ ปี, ราวสองล้าน, 0%, ฿999, ฿2,000, 30–45 นาที, เดือนละ 2 ครั้ง) อย่าเปลี่ยน ถ้าสงสัยตัวไหนให้ถาม

## ส่งงานกลับยังไง

เขียนลงคอลัมน์ F ในชีตโดยตรง ถ้าแก้ชีตไม่ได้ ให้ส่งกลับมาเป็นตาราง 2 คอลัมน์: รหัส | ข้อความใหม่ เรียงตามรหัส

ท้ายงานขอสรุปสั้น ๆ 3 อย่าง: (1) แถวที่เสนอให้ตัด (2) แถวที่เสนอเพิ่ม (3) จุดที่ต้องถามเราก่อนเพราะไม่แน่ใจข้อเท็จจริง
