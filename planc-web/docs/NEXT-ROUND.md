## B. ข้อเสนอ: ป้าย 4 ต้นต่างกันยังไง + ดราม่าที่มากับฝน (Mat เลือก)

หลักที่ใช้: **ป้ายละหนึ่งเหตุการณ์ ไล่ความหนักขึ้นทีละต้น** ฝนหนักขึ้นตาม ไม่ยัดทุกอย่างพร้อมกัน

| # | ป้าย | ป้ายต่างจากต้นก่อนยังไง | เหตุการณ์ที่มากับฝน |
|---|---|---|---|
| 1 | เดือนนี้จะมีงานไหม? | ป้ายไฟปกติ ยืนตรง (ของเดิม) | ฝนเริ่มตก ฟ้าร้องไกล ๆ |
| 2 | เมื่อไรจะได้เงิน? | **ป้ายเอียง** โดนลมพัด ไฟกะพริบ | **สายฟ้าผ่าลงป้าย** ตอนแมวเดินถึง — จอวาบ ไฟป้ายดับแล้วติดใหม่ (มี bolt/flash อยู่แล้ว แค่ผูกจังหวะกับตำแหน่งป้าย = scrub-safe ได้) |
| 3 | ทำไมยอดวิวน้อย? | ป้าย**จมน้ำครึ่งเสา** ตัวหนังสือสะท้อนน้ำ | **น้ำท่วม** ระดับน้ำสูงขึ้นจากพื้นทีละนิด แมวเดินลุยน้ำ มีวงคลื่น/น้ำกระเด็นตามก้าว |
| 4 | ทำไมยอดฟอลไม่ขึ้น? | ป้าย**ใหญ่สุด** ไฟช็อตกะพริบถี่ ๆ | ของหนักสุด เลือกหนึ่ง: **งูโผล่จากน้ำ** (ยืมโค้ด ambush ของฉลามมาใช้ — งูฉก แมวสะดุ้งถอย ไม่ต้องกัดจริง) / **แมลงฝูง** ล้อมป้าย / **ลมพัดของในมือแมวหลุด** (มือถือ/กล้องปลิว = เสียเครื่องมือทำมาหากิน) |

ข้อเสนอเพิ่ม (ถ้าอยากดราม่าสุด): หลังป้าย 4 มี**ตึกไฟดับทั้งแถบ** ก่อนถึงเหว — เมืองมืดสนิทเหลือแค่แมว
แล้ว The Wall โผล่ = จุดต่ำสุด → "แต่คุณไม่ได้อยู่คนเดียวนะ" ถึงจะพีค

สิ่งที่ผมไม่แนะนำ: ใส่ทั้งงู+แมลง+น้ำท่วม+สายฟ้าในป้ายเดียว — จะกลายเป็นตลกแทนที่จะดราม่า

## C. ข้อเสนอ: journey หลังสะพานสายรุ้ง (ให้สอดคล้องธีม "ไม่ได้อยู่คนเดียว")

ของที่มีแล้ว: ข้ามสะพาน → แมวโตกลับ → กระโดดเกาะเสาธง ไถลลง → จอดำ CTA

**C1. ฝนหยุด → ฟ้าเปิดทีละชั้น** (ต่อจาก A7): บนสะพานเมฆแตก แสงแรกส่อง นก 3 ตัว (ย้ายไปแล้ว)
บินสวนมา พระอาทิตย์ยิ้มกลับมา — "หลังฝน" อ่านออกโดยไม่ต้องมีตัวหนังสือ

**C2. แมว planc\* เดินข้างกัน (แนะนำสุด — ตรงธีมเป๊ะ)**: ตอนแตะโลโก้ แมวโลโก้ (rig) **กระโดดออกจาก nav**
ลงมาเดินคู่กับแมวของเรา ตั้งแต่กลางสะพานจนถึงเสาธง = "คุณไม่ได้อยู่คนเดียว" กลายเป็นภาพจริง
ไม่ใช่แค่ประโยค แล้วตอนเกาะเสาธง แมว planc* ยืนรอข้างล่าง

**C3. ป้ายฝั่งสว่าง** ตอบป้ายฝั่งมืด: ข้ามมาแล้วเจอป้าย 1–2 ต้นที่เป็น "คำตอบ" (เช่น "รู้แล้วว่าถูกเลือกเพราะอะไร"
/ "คิดเรทจากต้นทุนตัวเอง") — ป้ายฝั่งนี้ไม่ต้องมีไฟ เพราะสว่างแล้ว (และเป็นที่วางของขาย ดูข้อ D)

**C4. ตึก planc\* ไฟดวงเดียวหลังเสาธง** (บีท 29 ใน CONTENT-MAP): ปราสาทปิดด่านของเรา
แมวสองตัวเดินเข้าประตู → ตัดเข้าจอดำ "เราไม่ได้ขายความหวัง เราขายความชัดเจน"

ลำดับที่ผมเสนอ: A7 ฝนหยุด → C1 ฟ้าเปิด → C2 แมว planc* ลงมาเดินคู่ → C3 ป้ายคำตอบ+ของขาย → เสาธง → C4 ตึก → CTA
