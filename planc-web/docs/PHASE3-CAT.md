## ตัดเป็นกี่ชิ้น

5 ชิ้น: `head` `body` `legF` `legB` `tail`

ที่ตัดชิ้นได้ทั้งที่รอยต่อมักจะน่าเกลียด เพราะแมวตัวนี้เป็น**เงาดำทึบ**
รอยต่อดำบนดำมองไม่เห็น ดังนั้น**ให้ชิ้นส่วนซ้อนทับกันเยอะๆ ไปเลย** (อย่างน้อย 12px)
ซ้อนเยอะ = หมุนได้มากโดยไม่มีช่องโหว่โผล่

จุดหมุน (`transform-origin`) ของแต่ละชิ้น:

| ชิ้น | จุดหมุน | หมายเหตุ |
|---|---|---|
| `head` | โคนคอ | หมุนสวนทางตัวเล็กน้อย ให้หัวนิ่งกว่าลำตัว |
| `body` | สะโพก | แทบไม่ต้องหมุนเอง ปล่อยให้ `#catLean` ทำ |
| `legF` | หัวไหล่ | ขาหน้า |
| `legB` | สะโพก | ขาหลัง เฟสตรงข้ามขาหน้า |
| `tail` | โคนหาง | ตามหลังทุกอย่าง หน่วงที่สุด |

**ไฟล์ที่ต้องได้:** `assets/cat/head.png` `body.png` `legF.png` `legB.png` `tail.png`
ทุกใบต้อง **canvas ขนาดเท่ากันเป๊ะกับ `cat.png` เดิม** แล้ววางซ้อนที่ `0,0` ทั้งหมด
จะได้ไม่ต้องคำนวณ offset ทีละชิ้น (ถ้าครอปให้พอดีชิ้น จะเสียเวลาไล่หาตำแหน่งทั้งวัน)

ลำดับซ้อนจากหลังไปหน้า: `tail` → `legB` → `body` → `head` → `legF`

## ต่อเข้ากับริกเดิมยังไง

**อย่าแตะ 3 โหนดเดิม** เพิ่มชั้นที่ 4 ไว้ข้างใน `#catSq`:

```html
<div id="catSq">
  <div id="catRig">
    <img class="part" id="pTail" src="assets/cat/tail.png" alt="">
    <img class="part" id="pLegB" src="assets/cat/legB.png" alt="">
    <img class="part" id="pBody" src="assets/cat/body.png" alt="">
    <img class="part" id="pHead" src="assets/cat/head.png" alt="">
    <img class="part" id="pLegF" src="assets/cat/legF.png" alt="">
  </div>
</div>
```

`cat.js` มีสัญญาณครบอยู่แล้ว **ไม่ต้องสร้างใหม่** ใช้ของเดิม:
`phase` (เฟสก้าว) `v` (ความเร็ว 0..1) `dir` (ทิศ) `jy` (ความสูงกระโดด)
`air` (ลอยอยู่ไหม) `land` (แรงกระแทกตอนลง) `dt` (เฟรม @60Hz)

ค่าเริ่มต้นสำหรับแมป — **เป็นแค่จุดตั้งต้น ต้องปรับด้วยตาจริง**:

```js
const legF = Math.sin(phase)          * 26 * v;   // องศา
const legB = Math.sin(phase + Math.PI)* 26 * v;   // เฟสตรงข้าม
const head = -deg * 0.35;                          // สวนทางการเอียงตัว

// หางหน่วงตามทุกอย่าง — ต้องคูณ dt เหมือนค่าหน่วงอื่นทั้งหมด
const tTarget = -Math.sin(phase) * 10 - dir * 6 - jy * 0.05;
tail += (tTarget - tail) * (1 - Math.pow(1 - 0.12, dt));

// ตอนลอย: ขาเหยียดตอนพุ่งขึ้น หุบตอนตกลง
if (air){ /* ใช้ vy ที่คำนวณไว้แล้วในฟังก์ชัน */ }
```

## กับดักหลักของเฟสนี้ — อ่านก่อนเขียนโค้ด

**rim ตอนด่านมืดจะพัง** ตอนนี้ `body.inverted #catSq img` ใส่ `drop-shadow` 4 ทิศ
ทำขอบขาวรอบแมว ถ้าปล่อยกฎนี้ไว้เฉยๆ แล้วเปลี่ยนเป็น 5 `<img>`
**แต่ละชิ้นจะได้ขอบขาวของตัวเอง** กลายเป็นเส้นขาวคั่นกลางลำตัวแมวเต็มไปหมด

วิธีแก้: ย้าย `filter` ไปไว้ที่ `#catRig` (ตัวห่อรวม) ไม่ใช่ที่ `img`
แล้วเช็คด้วย `node tools/shots.mjs` ที่จุด `.715` และ `.80` ว่าไม่มีเส้นขาวโผล่กลางตัว

**และห้าม invert ตัวแมวเด็ดขาด** พื้นก็ invert เป็นขาวด้วย ครึ่งล่างของแมวจะหายเข้าไปในพื้น

**fallback ต้องมี** ถ้าโหลดชิ้นส่วนไม่ครบ ให้ถอยกลับไปใช้ `cat.png` ใบเดียว
อย่าปล่อยให้แมวหายไปจากจอ

**`build.py` ต้องอัปเดตด้วย** ตอนนี้มันฝัง base64 แค่ `assets/cat.png` กับ `favicon.svg`
ถ้าเพิ่มชิ้นส่วนแล้วไม่แก้ ไฟล์เดียวใน `dist/` จะไม่มีแมว

ดูเฉพาะ 4 ข้อนี้ — ตัดสินจากภาพที่เรนเดอร์จริงเท่านั้น อย่าตัดสินจากโค้ด:

1. เลื่อน**ช้าๆ** ขาต้องขยับให้เห็น (นี่คือเหตุผลทั้งหมดของเฟสนี้)
2. เลื่อน**ถอยหลัง** ขาต้องเดินถอย ไม่ใช่เดินหน้าต่อ
3. **ด่านมืด** (`cur` 0.69–0.86) ต้องไม่มีเส้นขาวคั่นกลางตัวแมว
4. **ตอนกระโดด** หางต้องตามหลังลำตัว ไม่ใช่ขยับพร้อมกัน

## ที่ Mat ต้องเป็นคนตัดสิน — อย่าเลือกแทน

- ขาแบบไหน: 2 ชิ้นแบบ side-view (ง่าย ดูเป็นการ์ตูน) หรือ 4 ชิ้น (ดูเป็นแมวจริงกว่า แต่รอยต่อเยอะ)
- หางเด่นแค่ไหน: สะบัดชัดๆ ให้มีชีวิต หรือขยับน้อยๆ ให้ดูนิ่ง
- ท่าเดิน: การ์ตูนเกินจริง (เด้งเยอะ) หรือแมวจริง (ลื่น เรียบ)

เสนอเป็นตัวเลือกให้ดู แล้วถาม อย่าตัดสินใจให้
