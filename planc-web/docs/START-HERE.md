## 2. เรื่องที่ใหญ่กว่าอนิเมชั่น — เนื้อหายังไม่มี

ทุก beat ตอนนี้เป็นข้อความสมมติ และยังไม่ได้ตัดสินว่าอุปสรรคแต่ละตัว
(หลุม / DEADLINE / บล็อก / ด่านมืด) แทนปัญหาอะไร และ planc\* แก้ด้วยบริการอะไร

**นี่คือความเสี่ยงที่แพงที่สุดในโปรเจกต์นี้ตอนนี้** เพราะถ้าสคริปต์เปลี่ยน
สิ่งที่เปลี่ยนตามคือ จำนวน beat, ค่า `data-p` ของทุกอัน, จำนวนและตำแหน่งอุปสรรค,
ความยาวด่าน (`TRAVEL_MIN` / `SCROLL_LEN`) — งานขัดเงาที่ผูกกับตำแหน่งพวกนี้
จะต้องรื้อทำใหม่เกือบทั้งหมด

**ทางที่ปลอดภัย:** ล็อกสคริปต์กับลิสต์บริการก่อน แล้วค่อยลงทุนกับความสวย

**ถ้าอยากเห็นของสวยก่อนเพื่อเอาไปขายไอเดีย** ก็ทำได้ แต่ให้ทำเฉพาะ
ข้อ 0–3 ในคิวข้างล่าง เพราะสามข้อนั้นเป็นเรื่องของ *พื้นผิวโลก* (หญ้า ลม ฝุ่น)
ไม่ได้ผูกกับว่าข้อความเขียนว่าอะไรหรืออุปสรรคอยู่ตรงไหน

## 4. หนี้ทางเทคนิคที่ควรเก็บก่อนเริ่มขัดเงา

**ฟอนต์ยังโหลดจากเน็ต — แต่ไฟล์พร้อมแล้ว** `index.html` ยังดึง Prompt + Sarabun
จาก Google Fonts และ `build.py` ฝังแค่ `cat.png` กับ favicon แปลว่า
`dist/planc-demo3.html` **ไม่ใช่ไฟล์เดียวจบจริง** — เปิดตอนไม่มีเน็ต ตัวหนังสือจะเด้ง

ตอนนี้ subset ไทย+ละตินอยู่ใน **`assets/fonts/`** แล้ว (8 ไฟล์ woff2 รวม 124KB)
และ `tools/lab-build.py` มีฟังก์ชัน `font_css()` ที่ทำ `@font-face` แบบ base64
พร้อม `unicode-range` แยกไทย/ละตินไว้ให้ **ยกไปใช้ใน `build.py` ได้เลย**
ที่ยังไม่ทำเพราะข้อนี้เป็นคำถามที่รอ Mat ตอบอยู่ (ตาราง ง. ข้อ 2) —
ฝังแล้วไฟล์ใหญ่ขึ้นราว 170KB แลกกับเปิดออฟไลน์ได้และตัวหนังสือไม่เด้ง

**ไม่มีตัววัด fps** `PHASE4-POLISH.md` เขียนว่า "ต้องวัดบนมือถือจริง"
แต่ในโค้ดไม่มีตัวนับ และไม่เคยจดตัวเลขตั้งต้นไว้ แปลว่า "ห้ามช้าลง" วัดไม่ได้
ควรใส่ตัวนับแบบเปิดด้วย `?fps` แล้ววัดค่าตั้งต้นจดไว้ **ก่อน** เพิ่มอะไร

**`tools/shots.mjs` ถ่ายอย่างเดียว ไม่เทียบ** ถ่าย 14 จุดแล้วต้องเปิดดูเองทุกใบ
ถ้าเพิ่ม grain แล้วด่านมืดพัง จะไม่มีอะไรเตือน ควรมีสคริปต์ diff กับรอบก่อน
แล้วรายงานเฉพาะใบที่ต่างเกินเกณฑ์

**ผมเขียนผิดในเอกสารเอง** `PHASE3-CAT.md` อ้างไฟล์สำรอง
`assets/source/cat-idle-full.png` — **ไฟล์นั้นไม่มีอยู่จริง** ในโปรเจกต์
ตอนนี้มีแค่ `assets/cat.png` (560×617) แผนสำรองของเฟส 3 จึงต้องตัดจากใบนี้แทน
(แก้ในเอกสารแล้ว)
