# บรีฟเจนภาพ Midjourney — เทียบกับมาริโอด่าน 1-1

> อ่าน `CLAUDE.md` ก่อน กติกาทุกข้อในนั้นยังใช้ ไฟล์นี้เพิ่มเฉพาะเรื่องงานภาพ
> **ทุกการตัดสินใจด้านดีไซน์เป็นของ Mat อย่าเลือกแทน เสนอทางเลือกแล้วถาม**

## 1. มาริโอ 1-1 มีของกี่ชิ้นจริงๆ

ทั้งด่านแรกของ Super Mario Bros. ใช้ของประมาณ **15 ชิ้น** เท่านั้น
ไม่ใช่ภาพวาดฉากยาวๆ แต่เป็นชิ้นเล็กๆ ไม่กี่ชิ้นที่เอามาวางซ้ำ

และมีทริกที่สำคัญมากสำหรับเรา: **เมฆกับพุ่มไม้คือสไปรท์ใบเดียวกัน**
ต่างกันแค่สี ภูเขาสองลูกก็ใช้ทรงเดียวกันย่อ/ขยาย ท่อสามความสูงคือ
ท่อนบนอันเดียวกันต่อท่อนกลางเพิ่ม

**บทเรียนสำหรับเรา:** อย่าสั่ง Midjourney วาดฉากกรุงเทพสวยๆ ยาวๆ มาหนึ่งใบ
เพราะมันจะเลื่อนไม่ได้ ซ้ำไม่ได้ แก้ไม่ได้ และพอถึงด่านมืดจะพังทั้งใบ
ให้เจน **ชิ้นส่วน 14–16 ชิ้น** แล้วให้โค้ดเป็นคนวาง

## 2. ตารางเทียบ — มาริโอมีอะไร เรามีอะไร ขาดอะไร

| ของในมาริโอ | หน้าที่จริงในด่าน | ของเราตอนนี้ | ต้องเจนไหม |
|---|---|---|---|
| ท้องฟ้า | พื้นหลังเปล่า ให้ตาพัก | `--paper` ใน CSS | **ไม่ต้อง** |
| เมฆ 3 ขนาด | บอกว่าโลกนี้เลื่อนอยู่ | วงกลม SVG | **เจน** 3 ขนาด |
| พุ่มไม้ | ประดับระนาบพื้น (สไปรท์เดียวกับเมฆ) | ไม่มี | **เจน** — ใช้ทรงเดียวกับเมฆ แต่ทึบ |
| ภูเขา 2 ขนาด | ชั้นลึกที่ไกลสุด | path เส้นเดียว | **เจน** 2 ขนาด |
| ตึก/กำแพงพื้นหลัง | ความลึกชั้นกลาง | สี่เหลี่ยม 10 อัน | **เจน** เป็นแถบต่อได้ |
| พื้น (ground tile) | ระนาบที่เดิน | `<rect>` ดำ | **เจน** 1 tile |
| อิฐ | ของที่ทุบได้ | ไม่มี | **เจน** |
| บล็อก `?` | รางวัล — จุดที่ด่านให้ของ | ไม่มี | **เจน** ← จุดเผยบริการ |
| ท่อ 3 ความสูง | อุปสรรคที่ต้องกระโดดข้าม | ไม่มี | **เจน** |
| หลุม | ความเสี่ยง ตกแล้วจบ | `PIT` ใน `scene.js` มีแล้ว | **เจน** เฉพาะขอบหลุม |
| กูมบา | ศัตรูที่เดินสวนมา | ไม่มี | **เจน** 2 เฟรม + ท่าโดนเหยียบ |
| เต่า | ศัตรูที่ยากขึ้น | ไม่มี | ยังไม่ต้อง — เอาไว้รอบสอง |
| บันได | เร่งจังหวะก่อนถึงเส้นชัย | ไม่มี | **เจน** 1 บล็อก แล้วซ้อนเอา |
| เสาธง | เส้นชัย จุดที่ผู้เล่นเล็งไว้ตลอด | `<div>` เปล่า | **เจน** |
| ปราสาท | ปลายทาง รางวัลจริง | ไม่มี | **เจน** ← จุดที่เป็น CTA |
| เหรียญ | รางวัลเล็กระหว่างทาง | ไม่มี | **เจน** |

**สิ่งที่ขาดหนักที่สุดเมื่อเทียบกับ 1-1 ไม่ใช่ความสวย แต่คือ "ของที่ตอบสนอง"**
ด่านของเราตอนนี้มีแค่หลุมกับป้าย แมวเดินผ่านฉากไปเฉยๆ
1-1 มีของให้ชนสี่แบบ (ทุบ / เก็บ / กระโดดข้าม / เหยียบ) ตั้งแต่ 20 วินาทีแรก
**บล็อก `?` กับศัตรู คือสองชิ้นที่เปลี่ยนเว็บนี้จาก "ฉากเลื่อน" เป็น "ด่าน"**

## 3. ของที่ห้ามเจน — ต้องเป็นโค้ดเท่านั้น

| ชิ้น | ทำไมเจนไม่ได้ |
|---|---|
| หญ้าที่แมวเบียดผ่าน | ต้องบิดตัวตามระยะห่างของแมว ภาพนิ่งบิดไม่ได้ |
| ผ้าธงที่ปลิว | ต้องเปลี่ยนรูปทรงทุกเฟรมตามลม |
| ฝุ่นใต้เท้า / รอยเท้า | เกิดและหายตามตำแหน่งสกรอล |
| สายไฟที่แกว่ง | เส้นโค้งที่คำนวณสด |
| **ตัวหนังสือทุกตัว** | MJ สะกดไทยไม่ได้ และต้องเลือกได้/อ่านออกด้วยสกรีนรีดเดอร์ |
| ชิ้นส่วนแมว | มีสเปกแยกที่ `PHASE3-CAT.md` ต้องตัดจากคลิปตัวเดิม ห้ามเจนใหม่ |

**กฎง่ายๆ:** ถ้ามัน**เปลี่ยนรูปทรง**ตามสกรอล = โค้ด · ถ้ามันแค่**เลื่อนไปมา** = เจนได้

## 4. กติกาการเจน — ข้อนี้สำคัญกว่าตัวคำสั่ง

**1. พื้นหลังขาวล้วน ไม่มีเงาตกพื้น** ถ้า MJ ใส่เงาหรือใส่พื้นให้ ตัดออกไม่ได้
ซิลูเอทจะเสีย ต้องย้ำในคำสั่งทุกครั้ง

**2. ห้ามไล่เฉดเทา — เอาแค่ทึบหรือเส้น** นี่คือข้อที่พังง่ายที่สุด
เพราะครึ่งหลังของเว็บเป็น**ด่านมืด** ที่ทุกอย่างกลับสี ภาพ PNG ที่มีเทาอบมาแล้ว
กลับสีไม่ได้ จะกลายเป็นรอยเปื้อนกลางจอ

**3. เจนมาแล้วต้องแปลงเป็นเส้น SVG ก่อนใช้** ไม่เอา PNG ไปแปะตรงๆ:

```bash
convert in.png -colorspace gray -threshold 55% -negate out.pbm   # ปรับ 55% ตามภาพ
potrace out.pbm -s -o out.svg --turdsize 8 --alphamax 1
```

ได้ `<path>` ที่ใส่ `fill="currentColor"` ได้ → **ด่านมืดกลับสีให้เองฟรี**
ไฟล์เล็กลงมาก ขยายไม่แตก และเอาไปใส่ในไฟล์เดียวของ `build.py` ได้ด้วย
(ถ้าชิ้นไหนรายละเอียดเยอะจน potrace ออกมาเละ แปลว่าชิ้นนั้นเจนละเอียดเกินไป — เจนใหม่ให้เรียบลง)

**4. หนึ่งภาพหนึ่งชิ้น** อย่าสั่ง "sprite sheet" MJ จะวางไม่เป็นตาราง ตัดยากกว่าเจนทีละใบ

**5. ให้เข้าชุดกันด้วย `--sref`** เจนชิ้นแรกให้ได้ก่อน ชอบใบไหนก็อป URL ของใบนั้น
แล้วต่อท้ายทุกคำสั่งที่เหลือด้วย `--sref <url> --sw 100`
ถ้าไม่ทำ 15 ชิ้นจะเหมือนมาจาก 15 คนวาด

**6. ขนาดใหญ่ไว้ก่อน** ย่อทีหลังได้ ขยายไม่ได้

## 5. คำสั่งเจน — ก็อปวางได้เลย

### ท่อนที่ใช้ร่วมกันทุกคำสั่ง

```
BASE:  flat 2D side-scrolling platformer game asset, pure black and white,
       orthographic side view, no perspective, no cast shadow,
       isolated on plain white background, thick readable silhouette

NEG:   --no color, colour, grey gradient, shading, text, letters, numbers,
       watermark, 3d render, drop shadow, ground plane, frame, border
```

### ท่อนสไตล์ — เลือกอันเดียว แล้วใช้อันนั้นทั้ง 15 ชิ้น

| | ใส่ในคำสั่งว่า |
|---|---|
| **ก Swiss** | `swiss graphic design, flat geometric vector shapes, hard edges, uniform stroke weight, bauhaus poster` |
| **ข Riso** | `risograph print, halftone dot shading, coarse screenprint grain, slightly misregistered ink` |
| **ค วาดมือ** | `hand-inked linocut, uneven wobbly ink line, crosshatch shading, woodblock print` |
