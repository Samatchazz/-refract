## กฎเหล็ก (จาก CONTENT-MAP — ห้ามละเมิด)

1. สรรพนามแทน planc* = **"เรา"** ทุกที่
2. ห้าม testimonial / รีวิว / คำชมที่แต่งขึ้น
3. ห้ามใช้คำว่า "เอเจนซี" เรียก planc* (พูดถึงเอเจนซีคนอื่นเพื่อเทียบได้)
4. ห้ามโชว์เลข 1,500 เป็นราคาสาธารณะ
5. ห้ามอ้างผลลัพธ์ที่ยังไม่มี · ห้ามชื่อแบรนด์ · ห้ามตัวเลขดีลจริง
6. ห้ามรูปแบบ "ลิสต์ความเจ็บ + ทักมา" (ลายเซ็นโพสต์มิจฉาชีพ) — ความเจ็บต้องตามด้วยคำอธิบาย/กลไก ไม่ใช่ "ทักมา"
7. คำต้องห้าม: "ทำให้เอเจนซี่รักเรา" · "ทำเวลาว่าง" · "AI-powered" · "คอนซัลท์เอเจนซี่"
8. ต้องมีประโยค **"เราไม่รับประกันว่าคุณจะได้งาน"** ณ จุดจอง/สมัคร
9. ราคา ฟรี / ฿999 / ฿2,000 และรายละเอียดบริการ ห้ามเปลี่ยนตัวเลขหรือเพิ่มบริการ
