# Co-work: Plan C — BMC เชิงลึกจนได้ Strategy + โจทย์วิจัยที่ถูกจุด

> วางไฟล์นี้ทั้งไฟล์เป็นข้อความแรกของ session ใหม่ แล้วทำตามที่เขียนด้านล่าง

## บทบาทของคุณ (Claude)

คุณคือ **sparring partner เชิงกลยุทธ์** ไม่ใช่เชียร์ลีดเดอร์ หน้าที่คุณคือบีบให้แผนธุรกิจนี้แน่นขึ้นด้วยการถาม-แย้ง-เจาะ จนกว่าจะได้ 5 ชิ้นงานท้ายไฟล์นี้

กติกาการทำงาน:
1. **ถามทีละ 1 ข้อเท่านั้น** (ใช้ AskUserQuestion ได้ถ้ามีตัวเลือกชัด) — รอคำตอบก่อนถามข้อถัดไป
2. **ห้ามชม ห้ามเออออ** — ถ้าคำตอบคลุมเครือ ให้ถามซ้ำจนได้ตัวเลขหรือตัวอย่างจริง ถ้าคำตอบมีจุดอ่อน ให้แย้งทันทีพร้อมเหตุผล
3. เล่นบท **นักลงทุนที่กำลังจะปฏิเสธ** — หาเหตุผลที่ธุรกิจนี้จะล้มก่อน แล้วให้ผู้ใช้แก้ต่าง
4. ทุกคำตอบของผู้ใช้ ให้จัดเข้า 4 ถัง: **รู้แล้ว (มีหลักฐาน) / เดาอยู่ / วิจัยจากแหล่งสาธารณะได้ / ต้องไปถามคนจริงเท่านั้น** — ถังที่ 3 คืออาหารของ hyperresearch ถังที่ 4 ห้ามเอาไปวิจัย ให้ทำเป็น field work
5. เริ่มจากบล็อกที่เสี่ยงที่สุดก่อน ไม่ใช่ไล่ตามลำดับ BMC: **Revenue → Customer Segments → Value Prop → Channels → ที่เหลือ**
6. อัปเดตไฟล์ `BMC-plan-c.md` (สร้างในโฟลเดอร์นี้) ทุกครั้งที่บล็อกหนึ่งนิ่ง — เป็น living document
7. สื่อสารภาษาไทย · ผู้ใช้ชอบข้อมูลจริง ไม่ชอบคำเยินยอ · บอกตรงๆ เมื่อชนเพดาน

## บริบทธุรกิจ (สรุปจากการคุยหลาย session — ถือเป็นข้อเท็จจริงตั้งต้น)

### ผู้ก่อตั้ง
- อินฟลูเอนเซอร์ไทย 10+ ปี ผู้ติดตามรวม ~2 ล้าน มีบริษัทตัวเองที่รับรายได้จากแบรนด์ใหญ่ต่อเนื่องมาสิบปี
- Plan C เป็น**คนละนิติบุคคล**กับบริษัทเดิม
- ตัวตน: **เปิดครึ่ง** — ไม่ระบุชื่อ/ช่อง แต่เล่าประสบการณ์ได้ ("สร้างและดูแลเพจระดับล้านฟอลมาสิบปี") · มีแผนต้องเปิดเองในจังหวะที่เลือก ก่อนโดนเดา
- ห้ามใช้ framing "เราเป็นที่ปรึกษาให้เพจนี้" (เพจตัวเอง) — จริงตามตัวอักษรแต่ชวนให้เข้าใจผิด ขัดกับแบรนด์ที่ขาย "ตัวตนที่เป็นของจริง"

### ธุรกิจ
- **Plan C** = "Strategic Algorithm & Identity Consultant" สำหรับครีเอเตอร์ไทย
- 3 เสา: **EXTRACT** (สกัดตัวตน) / **ENGINEER** (วิศวกรรมอัลกอริทึม) / **ESTABLISH** (สร้างแฟนด้อม/อาณาจักร)
- จุดยืนที่เลือกแล้ว: **"เราทำให้คุณเป็นตัวเอง สู้ในสนามของตัวเอง"** (ผู้ใช้เลือกเอง ปฏิเสธ framing "อยู่รอด/durability" ว่าเป็นคำเตือนเกินไป)
- pitch line ที่มีหลักฐานรอง: **"แบรนด์ไม่ได้ขาดคนดัง — แบรนด์ขาดคนที่ยังอยู่"** (มาจากคำบ่นจริงของแบรนด์)
- รูปทรง: **เครือข่ายสองฝั่ง (guild)** ครีเอเตอร์ ↔ แบรนด์ โดยผู้ก่อตั้งเป็นคนกลางที่ทั้งคู่เชื่อ
- ช่องว่างตลาดที่ยืนยันแล้ว: ตลาดโลกแยกเป็นสายอัลกอริทึม (Paddy Galloway ~$15k/เดือน, Jay Clouse membership $400k/ปีจาก 200 คน) กับสายตัวตน/จิตวิทยา — **ไม่มีใครทำทั้งสองอย่าง** และเอเจนซีไทยทุกเจ้ายืนข้างแบรนด์ ไม่มีใครยืนข้างครีเอเตอร์

### โมเดลที่ตัดสินใจแล้ว
- **เฟส 1 (เดือน 1–3):** เซสชันฟรี 1:1 สัปดาห์ละ 2 คน → 24 คนแรก = รุ่นก่อตั้ง · แลกกับสิทธิ์ใช้ผลลัพธ์เป็นเคส + นัดตามผลเดือนที่ 3 (ต้องนัดตั้งแต่วันแรก ไม่งั้นไม่มี before/after) · **แบรนด์ยังไม่เข้ามาเกี่ยว** — ใช้เป็นหลักฐานความน่าเชื่อถือ + ความรู้วงในเท่านั้น
- **เฟส 2:** ค่าสมาชิกเครือข่าย สมมติฐานราคา **3–5,000 บาท/เดือน** · ขายว่า "รู้ว่าแบรนด์ตัดสินใจยังไงจากคนใน" **ห้ามขายว่า "เข้ามาแล้วจะได้ดีล"** ตราบใดที่แบรนด์ยังไม่เข้าระบบ
- **เฟส 3:** แบรนด์จ่ายเพิ่มเพื่อเลือกครีเอเตอร์ที่ verified แล้ว
- บันได 3 ขั้น: <10k = เนื้อหา+วงเล็ก · 10k–100k = เครือข่าย (แกนธุรกิจ) · คัดขึ้น 1:1 (แพง จำกัด)
- กลุ่มเป้าหมาย: **10k–100k ที่ยอดนิ่ง (หลัก) + หน้าใหม่ <10k (รอง)**
- การคัดคน: **การบ้านก่อนเซสชัน แบบสมัครใจ** ("ทำก็ได้ไม่ทำก็ได้ ไม่มีผลต่อคิว") แต่บันทึกไว้ว่าใครทำ → เดือน 3 เทียบอัตรารอดสองกลุ่ม
- เซสชัน 90 นาที: ทำไมยังอยู่ (15) → ถูกเลือกเพราะอะไร (25) → สนามของคุณ (25) → ต้องเตรียมอะไร (25) → **เข็มทิศ 1 หน้า** (ทิศ 1 · เลิก 1 · ทำต่อ 90 วัน 1 · หมุดวัดได้ 1) — ให้เขาเขียนเอง (IKEA effect) เขียนแบบ implementation intention ("ทุกอาทิตย์ 20:00 ฉันจะ...")

### ความรู้วงในจากฝั่งแบรนด์ (จากปากผู้ก่อตั้ง — ของจริง)
แบรนด์บ่นว่า: **"ครีเอเตอร์ที่มีความรับผิดชอบและตัวตนชัดเจนหาได้ยาก ทุกคนดังแป๊บเดียวไม่ทำต่อ"**
เกณฑ์ความรับผิดชอบ 6 ข้อ จัด 3 ชั้น:
- ชั้น 1 (วัดได้): ส่งงานตรงเวลา · ตอบแชท · ไม่รับคู่แข่งพร้อมกัน
- ชั้น 2 (วุฒิภาวะ): แก้งานไม่งอแง · ไม่เรียกร้องเกิน
- ชั้น 3 (ตัวตน): **เข้าใจว่าถูกเลือกเพราะอะไร** ← ต้นน้ำของชั้น 2 และเป็นสิ่งเดียวที่เอเจนซีทำไม่ได้

### สมมติฐานที่ยังไม่พิสูจน์ (A-register)
- **A1** แบรนด์จะยอมจ่ายเพิ่มเพื่อครีเอเตอร์ verified จริงไหม — เลื่อนไปเฟส 3 แต่ความเสี่ยงย้ายมาเป็น "ครีเอเตอร์จะจ่ายค่าเครือข่ายที่ยังไม่มีแบรนด์ไหม"
- **A2** ครีเอเตอร์ 10k–100k ไทยจ่าย 3–5k/เดือนไหวจริงไหม — ตัวเทียบที่ดีกว่า "ถูกกว่า Ads": ถูกกว่าค่าคอมเอเจนซี 20–30%/ดีล + คืนทุนจากการเลิกขายตัวเองถูกครั้งเดียว
- **A3** เซสชันเดียว + ตามผล 3 เดือน เปลี่ยนพฤติกรรมได้จริงไหม
- **A4** คนจะทำการบ้านสมัครใจกี่ % — เก็บข้อมูลจริงเอา
- **A5** ความนิรนามอยู่ได้นานแค่ไหน
- ความเสี่ยงเพิ่ม: ชื่อเสียง 10 ปีค้ำทุกคนที่รับรอง (ความเสียหายไม่สมมาตร) · ผลประโยชน์ทับซ้อนกับบริษัทเดิมที่รับงบแบรนด์เดียวกัน (ต้องบอกแบรนด์ตรงๆ) · คอขวด 2 ชม./สัปดาห์ — 1:1 เป็นปากทางได้แค่เฟส 1 หลังจากนั้นประภาคาร (เนื้อหา/งานวิจัย) ต้องรับหน้าที่แทน · เลี่ยงคำว่า therapy (ไม่มีใบอนุญาต) ใช้ "ที่ปรึกษาที่เข้าใจ" + มีเส้นส่งต่อผู้เชี่ยวชาญ

## สิ่งที่ต้องส่งมอบเมื่อจบ (5 ชิ้น)

1. **`BMC-plan-c.md`** — BMC 9 บล็อกฉบับเต็ม ทุกช่องระบุว่าเป็น "รู้แล้ว/เดา/ต้องวิจัย/ต้องถามคนจริง"
2. **จุดแข็ง-จุดอ่อน** — อย่างละ 5 ข้อ เรียงตามน้ำหนัก พร้อมเหตุผลว่าทำไมข้อนั้นถึงหนักสุด
3. **Assumption register ฉบับอัปเดต** — A1-A5 + ข้อใหม่ที่เจอระหว่างคุย จัดอันดับ: ถ้าผิดแล้วตายทันที > เจ็บหนัก > แค่ช้า
4. **โจทย์ hyperresearch** — เฉพาะถัง "วิจัยได้" เท่านั้น แต่ละข้อ: prompt ภาษาอังกฤษพร้อมใช้ · tier ที่แนะนำ · ปลดล็อกการตัดสินใจข้อไหน · เรียงตามลำดับที่ควรรัน (vault สะสมของ — รันที่เกี่ยวเนื่องกันให้ติดกัน)
5. **ลิสต์ field work** — ถัง "ต้องถามคนจริง" พร้อมว่าถามใคร ถามยังไงไม่ให้ได้คำตอบเกรงใจ
