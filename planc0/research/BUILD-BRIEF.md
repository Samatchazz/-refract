## 3 · MOTION GRAMMAR (บังคับทั้งเว็บ)
ทุก component ใช้ได้แค่ token ชุดนี้ — นี่คือเครื่องจักรของความสมูท: ฟิสิกส์ชุดเดียวทุกที่

### 3.1 Easing
| Token | ค่า | ใช้ตอน |
|---|---|---|
| `--ease-glide` | `cubic-bezier(0.25,0.1,0.25,1)` | การเคลื่อนไหวปกติในหน้า |
| `--ease-settle` | `cubic-bezier(0.22,1,0.36,1)` | เข้า/เผย (fast-out settle) — ตัวหลัก |
| `--ease-spring` | `cubic-bezier(0.34,1.56,0.64,1)` | overshoot — **งบจำกัด** (§3.3) |
| `--ease-sym` | `cubic-bezier(0.6,0,0.4,1)` | ปิด-เปิดสมมาตร (ม่าน เมนู) |
| `--steps-q` | `steps(5,end)` | จังหวะ quantized (GAME) — **≤3 จุดทั้งเว็บ** |
| `linear` | — | marquee เท่านั้น |

### 3.2 Duration & stagger
`--t-micro 150ms` (hover, cursor, tick) · `--t-base 400ms` (เข้า/เผย) · `--t-slow 800ms` (รอยต่อ section) · `--t-epic 1200ms` (**≤2 ครั้ง**: preloader→hero และตอนจบ)
`--stagger-word 40ms` (ระดับคำ) · `--stagger-row 60ms` (แถว/เมนู) · **ห้าม stagger ระดับตัวอักษรกับข้อความไทยเด็ดขาด** (§7)

### 3.3 งบ motion (คอนโซลนับให้อัตโนมัติ)
| งบ | เพดาน | เหตุผล |
|---|---|---|
| จุด quantized/HUD (GAME) | 3 | เกมเป็น accent ไม่ใช่ธีม |
| `--ease-spring` ที่รอยต่อ | 2 | เด้งบ่อย = เลี่ยน |
| `--ease-spring` ตอน interact | 2 | เหมือนกัน |
| `--t-epic` | 2 | จังหวะยาวต้องหายาก |
| section ที่ pin | 2 | 390px กินจอทั้งหมด + ชนกับ momentum scroll |
| ของที่พึ่ง hover | 2 | มือถือจะได้เว็บที่ตายไปครึ่ง |

### 3.4 เข้า / เคลื่อน / ออก
- **เข้า:** translateY 24px→0 + opacity 0→1 · `--t-base --ease-settle` · stagger ระดับคำ
  ⚠ **ห้าม fade-in เหมือนกันหมดทุก element** — ปี 2026 นับเป็นสัญญาณของงาน AI สำเร็จรูป ต้องมีการเข้าที่ต่างกันตามบทบาทของ element
- **เคลื่อน:** transform/opacity เท่านั้น · parallax ไม่เกิน ±8% และเฉพาะเลเยอร์ตกแต่ง
- **ออก:** element ไม่ fade หายกลางจอ — ให้รอยต่อพาออก (§5) หรือเลื่อนออกไปเอง
- **reduced-motion:** ปิด smooth scroll แบบ JS · reveal เป็น opacity ทันที · marquee หยุด · preloader เป็น fade 200ms · **ปิด JS ทั้งหมดแล้วต้องอ่านเว็บได้ครบ**

### 3.5 กลไกเปลี่ยนสีที่รอยต่อ (เปิดใช้ตามโลกสีที่เลือก)
รอยต่อเปลี่ยนพื้นได้ตามสเปกของโลกสีนั้น วิธีทำคงที่ไม่ว่าโลกไหน: **สองเลเยอร์ `position:fixed` หลัง `<main>` แล้ว crossfade ด้วย opacity** (`--t-slow`) — **ห้าม animate `background-color` ตรงๆ** สีตัวหนังสือสลับด้วย attribute `data-world` ที่จุดกลางของ crossfade (ซ่อนอยู่ใต้ element ที่กำลังเคลื่อน) ในโลกที่ไม่มีการสลับพื้น กลไกนี้ไม่ทำงานและไม่มีต้นทุน

### 3.6 สแตกที่แนะนำ (ตามสภาพจริงของเบราว์เซอร์ ก.ค. 2026)
- **การ interpolate ตาม scroll ตรงๆ → CSS `animation-timeline: view()`** เพราะรันบน compositor ไม่แย่ง main thread
  ⚠ **Firefox ยังไม่รองรับจนถึง v155 (กำหนด 1 ก.ย. 2026)** — ก่อนหน้านั้นผู้ใช้ Firefox เห็นสถานะสุดท้ายแบบนิ่ง ต้องเช็คว่าทุก section "อ่านรู้เรื่อง" ในสถานะนิ่ง
  ⚠ **ห้ามใช้ `overflow:hidden` เป็น wrapper** — มันสร้าง scroll container ทำให้ timeline พัง ต้องใช้ **`overflow:clip`**
- **choreography จริงๆ (หลาย element สัมพันธ์กัน) → GSAP** · **ความรู้สึกของ scroll → Lenis** (ถ้าเลือก B1)
  ⚠ Lenis (จาก README ของตัวเอง): จำกัด 60fps บน Safari / 30fps ตอน low power · ชนกับ CSS `scroll-snap` · **ไม่มี prefers-reduced-motion ให้ ต้องต่อเอง**
- **แทน IntersectionObserver sentinel → `container-type: scroll-state`** (Chrome 133+, progressive enhancement)
- **morph รูปทรง → `clip-path: shape()`** (Baseline ก.พ. 2026, ไม่ต้องมี SVG/ปลั๊กอิน)
- **`@property`** ใช้เพื่อความถูกต้องของการ interpolate ไม่ใช่เพื่อความเร็ว — CSS variable ทำให้เกิด paint และถ้า inherit ทั่ว subtree จะทำ style recalc หนัก **ใช้เฉพาะค่าที่เป็น driver ไม่กี่ตัว**
- **`text-wrap: balance`** ใส่ทุกหัวเรื่อง (มีค่ากับไทยเพราะไทยไม่มีเว้นวรรค การตัดบรรทัดเริ่มต้นมักน่าเกลียด) · `will-change` ใส่ตอนเริ่ม เอาออกตอนจบเสมอ

**รอยต่อ:** ไม่มีรอยตัด — การเลื่อนของคำสุดท้าย *คือ* รอยต่อ

### 1 · เราคือใคร → 2
3 บรรทัดซ้อนเต็ม ~70vh (13vw desktop / 17vw @390px) · คำกลางไล่ขีดฆ่าคำของครีเอเตอร์คนอื่น 2 รอบ (~2.4 วิ) แล้ว settle ที่ **ตัวตน** · ข้ามทันทีถ้าผู้ใช้ scroll ก่อน · sub ซ้ายล่าง · `EN:` mono 12px ขวาล่าง · **ไม่มีปุ่ม**
**รอยต่อ:** เส้นนำสายตา (§5) ออกจากปลายอักษรสุดท้าย โค้งลงขอบขวา · หัวเรื่อง section 2 เริ่มเข้าก่อน section 1 ออกจากจอหมด (ซ้อน 30% — ห้ามมีช่องว่างเปล่า)

### 2 · ทำไมต้องเรา → 3
คอลัมน์เดียว max 32ch · ทุกคำเริ่มที่ wght 200 + blur 0.4px + `--fg` 35% แล้ว fill ทีละคำเป็น wght 600 + `--fg` เต็ม ตาม scroll (snap ล่วงหน้า 1 คำ) · `EN: trends expire. you don't.` แทรกกลาง
**รอยต่อ:** เส้นใต้คำสุดท้ายยืดออกไปเป็นเส้นบนของแถบตัวเลข section 3 · แถบเลื่อนเข้ามาแบบ "กำลังเคลื่อนอยู่แล้ว" ไม่ใช่เริ่มจากหยุด

### 3 · เราทำอะไรมา → 4
ตัวเลขขนาด headline + ประโยคที่มาใต้ทุกตัว (ห้ามมีตัวเลขลอย) · นับขึ้นด้วย IntersectionObserver + tween ~1KB โดย**ค่าจริงต้องอยู่ใน DOM ตั้งแต่ต้น** (no-JS อ่านได้) · `font-variant-numeric: tabular-nums` + ความกว้าง `ch` คงที่ กันเลขกระตุกดันของข้างๆ · @390px เป็น 2×2 ไม่ใช่ 1 ต่อแถว
**รอยต่อ:** เส้นของแถวสุดท้ายลากต่อไปเป็นเส้นแรกของ ledger section 4

### 4 · ประสบการณ์ของเรา → 5

**รอยต่อ:** เส้นแถวสุดท้ายยืดเลย 100% แล้วหนาขึ้นเป็นเส้นบนของแถบพาร์ทเนอร์

### 5 · พาร์ทเนอร์ของเรา → 6
ชื่อพาร์ทเนอร์เป็น**ตัวหนังสือในฟอนต์ของเว็บเอง** (ไม่ใช่ไฟล์โลโก้) ขนาด optical เดียวทั้งแถว · ป้ายกลุ่มเหนือแถว · ถ้าเป็น marquee: ทำซ้ำ track มากพอที่รอบวนอ่านไม่ออกว่าซ้ำ + **ปุ่ม Pause จริง** (WCAG 2.2.2 บังคับสำหรับอะไรที่วิ่งเองเกิน 5 วิ) + clone ใส่ `aria-hidden="true"`
**รอยต่อ:** เส้นล่างของแถบดิ่งลงเป็นเส้น depth marker `00m` ของเสาแรก

### 6 · เราช่วยคุณได้ยังไง → 7

**รอยต่อ:** พอเสา 3 หุบ เส้นวิ่งขึ้นจาก `-30m` ไปขีดใต้หัวเรื่อง section 7 — ส่งไม้จาก "จุดที่ลึกสุด" ไปยัง "แล้วคุณจะเป็นใคร"

### 7 · อะไรทำให้คุณต่าง → 8
สองคอลัมน์แชร์เส้นแกนกลาง จัดคู่ให้ตรงกันทุกแถว · stagger รายคู่ (ซ้ายเข้า ขวาตามใน 120ms) · @390px เส้นแกนหมุนเป็นแนวนอน แต่ละคู่ซ้อนกัน (ก่อน/เส้น/หลัง) · ถ้าใช้ Q2 (pin) ต้อง `matchMedia` และลดเป็นสลับคำครั้งเดียวบนมือถือ
**รอยต่อ:** เส้นแกนกลางหนาขึ้นเป็นขอบบนของแผ่นที่ section 8 ยกออก · `<main>` เริ่ม `will-change: transform` ที่จุดนี้

### 8 · จองเลย (ปิดท้าย)
`--t-epic` ครั้งที่ 2 · headline 15vw · **ประตูสองบานไม่เท่ากัน**: "จองคุยฟรี 30 นาที" ขนาด display (รับ `--ac1` ตามกติกาโลกสี) + "แอดไลน์มาถามก่อนได้" ขนาดเนื้อความใต้ลงมา

## 5 · เส้นนำสายตา (ด้ายที่ร้อยทั้งหน้า — ส่วนของ D1)
SVG เลเยอร์เดียว `position:fixed` เต็มความสูง `pointer-events:none` มีพาธเดียวที่: ออกจากอักษรสุดท้ายของ hero → วิ่งขอบขวา → เป็นเส้นใต้ manifesto → เส้นบนแถบตัวเลข → เส้น ledger → เส้น depth ของเสา → แกนกลาง section 7 → ขอบบนแผ่นที่ยกออกใน section 8
ทำโดย precompute `d` ต่อ breakpoint แล้วให้ scroll progress ขับ `stroke-dashoffset` (ถ้าเฟรมตกให้ fallback เป็น SVG แยก section แล้ว crossfade opacity) · ใช้ตระกูลเส้นโค้งเดียวทั้งเว็บ (นิยาม `--thread-curve` ครั้งเดียว) · ที่ 2 จุดที่มีงบ spring ให้ปลายเส้นทำ anticipation dip แล้วสปริง

## 7 · THAI-SAFE WHITELIST (อ่านให้จบก่อนเขียนโค้ดบรรทัดแรก)
ภาษาไทยไม่มีเว้นวรรคระหว่างคำ และมี **4 ชั้นแนวตั้ง** (สระล่าง / พยัญชนะ / สระบน / วรรณยุกต์) ขณะที่ละตินมี 2 — ข้อเท็จจริงข้อนี้ทำให้เกิดทุกปัญหาข้างล่าง

### ⚠ กับดักที่ทำให้พังแบบไม่มี error (สำคัญที่สุดในไฟล์นี้)
**GSAP SplitText โหมด `lines` และ `words` พังเงียบๆ กับภาษาไทย** — มันตัดคำด้วยช่องว่าง แล้วเดาบรรทัดจาก `offsetTop` ของคำ ภาษาไทยไม่มีช่องว่าง ⇒ **ทั้งย่อหน้ากลายเป็น "คำเดียว บรรทัดเดียว"** โดยไม่ throw error อะไรเลย stagger ที่คุณเขียนจะ render เป็น fade ก้อนเดียวแบนๆ
SplitText v3.13 แก้เรื่อง grapheme cluster แล้ว (ใช้ `Intl.Segmenter`) ดังนั้นโหมด `chars` จะไม่ทำให้สระหลุดจากพยัญชนะ **แต่ยังห้ามใช้อยู่** เพราะการครอบทุก cluster ด้วย inline element ทำให้เบราว์เซอร์ได้จุดตัดบรรทัดกลางคำ และทำลายการวางตำแหน่งวรรณยุกต์ข้าม cluster

**ทางแก้ที่ปลดล็อกทุกอย่าง (เขียนครั้งเดียว ใช้ทั้งเว็บ):**
```js
const seg = new Intl.Segmenter('th', { granularity: 'word' });
// ครอบทุกคำด้วย <span style="display:inline-block">
// แล้วป้อน span ชุดนี้ให้ SplitText เป็น words ที่ทำไว้แล้ว หรือไม่ใช้ SplitText เลย
```
`inline-block` ปิดจุดตัดบรรทัดกลางคำแต่ยังตัดระหว่างคำได้ · แต่ละ span เป็น shaping run สมบูรณ์ ⇒ สระวรรณยุกต์ render ถูก · `Intl.Segmenter` เป็น Baseline ตั้งแต่ 16 เม.ย. 2024 (Chrome 87+, Firefox 125+, Safari 14.1+)
**ต้องมี override list สำหรับคำยืม** — ทดสอบแล้วพบว่า `เทรนด์` ถูกตัดเป็น `เท|รนด์` เพิ่มคำเหล่านี้เข้า list: เทรนด์ · คอนเทนต์ · อัลกอริทึม · ครีเอเตอร์ · อินฟลูเอนเซอร์ · แพลตฟอร์ม

### ✅ ปลอดภัยกับไทย
1. **ระดับคำ** — reveal / stagger / fill / swap / ขีดฆ่า (ตัดด้วย Segmenter ก่อน)
2. **ระดับบรรทัด** — mask-wipe / slide / blur→sharp (ใช้ Range API หลัง layout หรือกำหนด `<br>` มือในหัวเรื่อง — แนะนำวิธีหลังสำหรับ hero เพราะไม่ต้องวัด)
3. **สลับคำทั้งคำ** — hero A1, สองเสียง C1 (ไม่แตะโครงตัวอักษรเลย = ปลอดภัย 100%)
4. **แกน variable font** (wght/wdth) บนคำหรือบรรทัดทั้งก้อน — ไม่ยุ่งกับ shaping
5. **`ease:"steps()"`** ⭐ **นี่คือคำตอบของไทยแทนเอฟเฟกต์พิมพ์ดีดทีละตัวอักษร** — ได้อารมณ์เครื่องจักรโดยไม่แตะตัวอักษรเลย
6. **mask / clip-path / clip-path:shape() / aperture ที่วิ่งผ่านข้อความที่ยังสมบูรณ์** — ตัวหนังสือไม่ถูก split
7. **grapheme scramble** (เฉพาะ C2) — `granularity:'grapheme'` เท่านั้น ห้าม emit วรรณยุกต์เดี่ยว

### ❌ ห้ามกับข้อความไทย (ใช้กับ EN accent ได้)
per-letter stagger/FLIP · `SplitText type:"chars"` · animate `letter-spacing` · หมุน/สเกลรายตัวอักษร · `scaleX` บีบคำ · typewriter รายตัวอักษร (ใช้ batch ระดับคำแทน) · **SVG `<text>` หนึ่งตัวต่อ `<clipPath>` วางด้วย `x="Nch"`** (สระซ้อนมี advance width = 0 และพยัญชนะไทยไม่ monospace ⇒ ได้ขยะ) · **line-draw ตัวอักษรไทย** (ต้อง outline เป็น path แล้วเสียการวางวรรณยุกต์ทั้งหมด — ให้ draw เส้น กรอบ ขีดใต้ แทน)

### ค่าที่ต้องตั้งให้ถูก
- `line-height`: เนื้อความไทย **≥1.6** · display **≥1.1 พร้อม `overflow: visible`** ที่ span ที่ครอบ (สระบน-ล่างโดนตัดคือบั๊กคลาสสิกที่สุด)
- ⚠ **metadata `lineHeight` ของ Google Fonts ต่างกันมาก**: Bai Jamjuree 1.25 · Noto Sans Thai 1.511 · Sarabun ~1.6 · Taviraj 1.706 · Trirong 1.734 — **เทียบฟอนต์ที่ line-height เดียวคือการเทียบที่ไม่แฟร์** FONT-LAB.html มีสไลเดอร์ให้ปรับแล้ว
- `word-break: normal` + `line-break: strict` · `<html lang="th">` · EN accent ครอบ `lang="en"`
- **ทดสอบที่น้ำหนักหนาสุด** เพราะวรรณยุกต์ยิ่งหนายิ่งชนกัน
- **คำทดสอบบังคับ** (ครบชุด 12 คำพร้อมคำอธิบายอยู่ใน FONT-LAB.html): `เปี่ยม` (ตัวตัดสิน — ป หางสูงแบกสระซ้อน) · `ปุ๋ย` (ครบ 4 ชั้น) · `หญิง` (หาง ญ ต้องหาย) · `ปฏิญาณ` (สองกฎหางพร้อมกัน) · `ฟื้นฟู` · `เรื่อง` · `ที่` · `กุ๊กกิ๊ก`

## 9 · กฎเหล็ก
1. โค้ดเขียนใหม่ 100% — ยืมแพตเทิร์น ไม่ยืมพิกเซล ไม่ก็อป asset ไม่ hotlink
2. ฟอนต์จากแหล่งที่มีสิทธิ์ใช้จริงเท่านั้น (ตามข้อ 8)
3. รวมทั้งหน้า **≤1.5MB** (รวมฟอนต์) · ไม่มีวิดีโอ · รูป lazy-load
4. animate **transform/opacity เท่านั้น** — ข้อยกเว้นที่อนุญาต: `stroke-dashoffset` ของเส้นนำสายตา · `font-variation-settings` (wght) · opacity ของ bg layer §3.5 · ทั้งหมดต้องยัง 60fps บนมือถือกลางๆ
5. **390px มาก่อน** — desktop คือส่วนขยาย
6. ข้อความเป็น HTML จริงทุกที่ · ไม่มี text-as-image · ไม่มี canvas text
7. reduced-motion ครบ (§3.4) · ปิด JS แล้วอ่านได้ครบ
8. dependency ที่อนุญาต: Lenis + GSAP core + ScrollTrigger (+ SplitText/DrawSVG ถ้าจำเป็น — ตอนนี้ฟรีทั้งหมดแล้ว) · ไม่มี framework · ไฟล์เดียวได้ยิ่งดี
9. **ห้าม:** WebGL/Spline hero (800KB–2MB = งบทั้งหน้า) · `backdrop-filter` (เฟรมตกบน Android, glassmorphism วัดได้ว่าลด FPS 15–30%) · fade-in เหมือนกันหมดทุก element (สัญญาณงาน AI สำเร็จรูปปี 2026) · bento grid การ์ดมุมโค้งเหมือนกันหมด · localStorage/sessionStorage · carousel/slider · autoplay video
10. **ห้าม scroll-jack เต็มรูปแบบ** — ปี 2026 นี่คือแพตเทิร์นที่ถูกวิจารณ์มากที่สุด เพราะทุกเฟรมแย่ง main thread กับการตอบสนองการแตะ ทำลาย INP (เกณฑ์ 200ms ซึ่ง 43% ของเว็บทำไม่ผ่านอยู่แล้ว) — pin ได้ไม่เกิน 2 จุดและต้อง `matchMedia` gate
11. a11y: keyboard เข้าถึงได้ทุกที่ · accordion เป็น `<button aria-expanded>` · overlay trap focus แล้วคืนที่เดิม · cursor layer `aria-hidden` · marquee เกิน 5 วิต้องมีปุ่มหยุด (WCAG 2.2.2) · `<h1>` เดียวเป็นข้อความจริง — ถ้า split span เพื่อ animation ต้องใส่ `aria-label` ที่ตัวครอบ
12. ไม่มี motion นอก grammar §3
