## สิ่งที่ผมตัดสินใจเชิงวิธี (ไม่ใช่เชิงดีไซน์) — vetoได้ทุกข้อ
1. **แทนเลนส์ CAT ด้วย 2 เลนส์ใหม่** — เดิมเลนส์มาสคอตเป็นตัวที่ใช้เยอะสุด พอตัดออกต้องมีอะไรมาแทน ผมตั้ง **SMOOTH** (ความเนียนคือลายเซ็น) และ **WOW** (จุดว้าวที่จำได้) โดยยังบังคับ **IDENTITY** เป็นแกนความหมาย และเก็บ GAME/POKER ไว้ · ตรวจด้วยสคริปต์แล้วว่า **ไม่มีการอ้างถึงแมวเหลืออยู่ใน 94 ตัวเลือกเลย** และการกระจายเลนส์คือ IDENTITY 37 · SMOOTH 25 · WOW 19 · GAME 8 · POKER 5
2. **ถอด CTA กลางหน้าออกทั้งหมด** — v1 มี CTA 4 จุด (hero + 3 เสา) ซึ่งขัดกับคำว่า "บิ้ว" ตรงๆ ถ้าปล่อยให้กดออกกลางทาง แรงที่สะสมมาจะรั่ว เหลือแค่ป้ายบอกทาง
3. **generate component-map.md และ SELECTION.md จากข้อมูลชุดเดียวกับคอนโซล** (`console2-data.js` + `gen-docs.mjs`) — เพื่อให้เอกสารกับเครื่องมือขัดกันไม่ได้เลย ถ้าจะแก้ข้อมูล แก้ที่ `console2-data.js` แล้วรัน `node gen-docs.mjs` ใหม่
4. **ระบบงบ motion ขยายเป็น 6 ตัว** เพิ่ม `pin ≤2` และ `พึ่ง hover ≤2` เพราะ research รอบนี้ชี้ชัดว่าสองอย่างนี้คือจุดที่เว็บ award พังบนมือถือ
5. **ค่า default ของระบบจอง** = ปุ่มลิงก์ออกแท็บใหม่ (คุณไม่ได้ตอบข้อนี้) — เพราะ Calendly `booking.css` หนัก 464 KB แบบ render-blocking = ~31% ของงบทั้งหน้า และ ad blocker บล็อก scheduler script ได้ ซึ่งจะลบเส้นทางปิดการขายแบบเงียบๆ ทางเลือก facade อยู่เป็น H2 ใน ballot
6. **โลกสี M0 (พาเลตต์เดิม) ยังอยู่ในลิสต์** แม้คุณบอกว่าเปิดกว้าง — เพราะการมีตัวเทียบทำให้การเลือกมีความหมาย และผมประเมินตรงๆ ว่ามันคือ EVOLVE ไม่ใช่ทิ้ง

## สิ่งที่ค้นเจอแล้วเปลี่ยนสเปกจริง (ของสำคัญ)
1. **⚠ GSAP SplitText โหมด `lines`/`words` พังเงียบๆ กับภาษาไทย** — ตัดคำด้วยช่องว่าง ไทยไม่มีช่องว่าง ⇒ ทั้งย่อหน้ากลายเป็น "คำเดียว บรรทัดเดียว" **โดยไม่มี error** stagger จะ render เป็น fade ก้อนเดียวแบนๆ · ทางแก้อยู่ใน BUILD-BRIEF §7 (Intl.Segmenter + `inline-block` span) · นี่คือสิ่งเดียวที่ถ้าไม่รู้ล่วงหน้า จะเสียเวลาดีบั๊กเป็นวัน
2. **Google Fonts มีฟอนต์ไทยที่เป็น variable แค่ 5 ตัว** (Noto Sans Thai / Noto Sans Thai Looped / Noto Serif Thai / Anuphan / Playpen Sans Thai) — ที่เหลือ static ทั้งหมดรวม Kanit, Prompt, Sarabun, Chakra Petch ⇒ ถ้าเลือก component ที่ต้อง animate น้ำหนักแต่เลือกฟอนต์ static = ขัดกันเอง คอนโซลเตือนอัตโนมัติแล้ว
3. **Chakra Petch เป็นฟอนต์ "มีหัว" ไม่ใช่ไม่มีหัว** (คนเข้าใจผิดบ่อยเพราะหน้าตาเหลี่ยมเทคโน) เช่นเดียวกับ K2D — อย่าเดาจากรูปทรง
4. **CSS scroll-driven animations ยังไม่รองรับใน Firefox** จนถึง v155 (กำหนด 1 ก.ย. 2026) — Firefox stable ตอนนี้คือ 153 ⇒ ถ้าปล่อยเว็บเดือน ส.ค. ผู้ใช้ Firefox เห็นสถานะนิ่ง (ยอมรับได้ แต่ต้องเช็คว่ายังอ่านรู้เรื่อง)
5. **`overflow:hidden` ทำให้ scroll-driven animation พังเงียบ** เพราะมันสร้าง scroll container — ต้องใช้ `overflow:clip` ซึ่งไม่สร้าง ⇒ จะเจอกับ wrapper ของ text mask ทุกตัว
6. **`clip-path: shape()` เป็น Baseline ก.พ. 2026** — morph รูปทรงได้ด้วย CSS ล้วน ไม่ต้องมี SVG หรือปลั๊กอิน (ของใหม่จริงที่เพิ่งใช้ได้ปีนี้)
7. **metadata `lineHeight` ของฟอนต์ไทยต่างกันมาก** (Bai Jamjuree 1.25 ↔ Trirong 1.734) ⇒ **การเทียบฟอนต์ที่ line-height เดียวคือการเทียบที่ไม่แฟร์** FONT-LAB จึงมีสไลเดอร์
8. **ประตู LINE ต้องแตกสองทาง** — URL scheme ของ LINE **ไม่ทำงานบนเดสก์ท็อปเลย** (เอกสาร LINE ระบุเอง) ⇒ มือถือใช้ deep link, เดสก์ท็อปต้องมี QR · และ `line://` เลิกใช้แล้วเพราะปัญหาความปลอดภัย
9. **"fade-in เหมือนกันหมดทุก element" กลายเป็นสัญญาณของงาน AI สำเร็จรูปในปี 2026** ⇒ ใส่เป็นข้อห้ามใน BUILD-BRIEF §9 ตรงๆ

## สิ่งที่ยืนยันไม่ได้ / ต้องระวัง
- **ไม่มี hex ทางการ** สำหรับ Pantone Cloud Dancer, WGSN Transformative Teal, Behr Hidden Gem, Benjamin Moore Silhouette, Sherwin-Williams Universal Khaki — ทุกค่าที่ลอยอยู่ในเน็ตเป็นการแปลงของบุคคลที่สาม ผมกำกับไว้ในทุกการ์ดที่เกี่ยวข้อง · **Universal Khaki มีสองค่าที่ขัดกันชัดเจน** (#B8A992 vs #CBBBA1) จึงไม่เอาเข้าลิสต์เลย
- **โลกสีที่มีเว็บจริงยืนยันได้มีแค่ M6** (ting.in, daoism.systems — ตรวจจาก `theme-color`) ที่เหลือคือเทรนด์ที่มีเอกสารแต่ยังไม่เห็นใครใช้ครบระบบ
- **M5 (Plum Noir × Wasabi) เป็นการจับคู่ของผมเอง** จากพาเลตต์ Pinterest 2026 — Pinterest เผยแพร่ 5 สี ไม่ได้จับคู่แบบนี้ไว้ (แต่ hex เป็นของจริงจาก Pinterest ที่ระบุวิธีการมาจากพฤติกรรมผู้ใช้ 600M คน = แหล่งที่มีหลักฐานเชิงประจักษ์ที่สุดในรอบนี้)
- **แกน variable ของฟอนต์พรีเมียมไม่ประกาศตัวเลข** (Aperçu Thai, Taksin, Kohinoor) — MyFonts บอกแค่ว่ามีแกนน้ำหนัก ต้องเปิดตาราง `fvar` ในไฟล์เองหลังซื้อ หรือถามโรงหล่อ
- **DB Fonts ยังไม่ยืนยันสิทธิ์เว็บฟอนต์** — หน้าเว็บอัปเดตล่าสุด ก.ย. 2017 และไม่พูดถึง WOFF2 เลย ทั้งที่เป็นโรงหล่อไทยที่ใหญ่สุด
- **Q4 (clip wipe) กลไกยังไม่ยืนยัน** — บทความ Codrops ที่เกี่ยวข้องถูก robots บล็อก ผมอธิบายตามที่แพตเทิร์นนี้ทำกันทั่วไป ไม่ใช่จากซอร์สจริง · **Q1 และ Q5 ไม่มีเว็บ award อ้างอิง** เป็นแพตเทิร์นพื้นฐานที่ผมแนะนำเอง กำกับไว้ในการ์ดแล้ว
- **เว็บที่บล็อกบอท** (dennissnellenberg, kprverse, montone.studio, daiki-design, pendragoncycle) และ **JS shell** (igloo.inc, zajno, aristidebenoist, deso.studio, jungheonlee, shining.302chanwoo, 15th.plus-ex, izanami) — ข้อมูล motion ทั้งหมดมาจากหน้ารางวัลที่เปิดได้ กำกับไว้ทุกการ์ด
- **Awwwards ประเทศไทยมีแค่ 7 รายการทั้งหมด** — ไม่มีคลังเว็บไทยระดับรางวัลให้ดูลึก ⇒ การไปดูเว็บญี่ปุ่น/เกาหลีไม่ใช่ทางเลือก แต่เป็นทางเดียวที่มีตัวอย่างงานสองสคริปต์จริง
- **Typewolf feed ดูค้าง** — SOTD ใหม่สุดที่เข้าถึงได้คือ 14 ธ.ค. 2025 · **bestwebsite.gallery ค้างตั้งแต่ พ.ย. 2024** อย่าใช้เป็นแหล่งปัจจุบัน

## ช่องว่างที่ยอมรับตรงๆ
- **ผมไม่เคยเห็นเว็บไหนขยับเลย** — เครื่องมือดึงหน้าเว็บตัด `<script>` ออก ทุกคำอธิบาย motion มาจาก (ก) หน้ารางวัล (ข) case study ของผู้สร้าง (ค) **source code จริงจาก GitHub ของ Codrops** (ทางนี้เวิร์ก ใช้จริง) หรือ (ง) เบาะแสในมาร์กอัป — **ควรมีคนเปิดเบราว์เซอร์ตรวจ ★ ทั้ง 16 ตัวหนึ่งรอบ**
- **ไม่มีภาพ screenshot ในแพ็กนี้** — แซนด์บ็อกซ์เข้าเว็บทั่วไปไม่ได้ (allowlist proxy) และ Chrome bridge ไม่ได้ต่อ
- **คะแนนต้นทุนเป็นการประเมินเชิงวิศวกรรมของผม** ไม่ได้ prototype จริง
- **ยังไม่ได้สแกนตลาดเว็บครีเอเตอร์/โค้ชไทย** ว่าใช้อะไรกันอยู่ — ถ้าอยากเลี่ยงให้ตรงจุด ต้องทำอีกรอบ (มี prompt ให้ใน RESEARCH-PROMPTS 1A)
- **FONT-LAB ไม่มีฟอนต์พรีเมียมให้ดู** (ลิขสิทธิ์) — ต้องลากไฟล์ trial เข้าไปเอง หรือใช้ Fontstand ลองฟรี 3 ชม./ฟอนต์
- **ยังไม่ได้ทดสอบ FONT-LAB บนเครื่องจริงที่ต่อเน็ต** — ผมตรวจ syntax, ตรวจว่า URL ของ Google Fonts ทุกตัวถูกรูปแบบ, และตรวจข้อมูลฟอนต์ 22 ตัวจาก endpoint จริงแล้ว แต่การ render จริงต้องคุณเปิดดู ถ้าฟอนต์ไหนไม่ขึ้นบอกได้ ผมแก้ให้

## Finalize protocol (รออยู่)
ส่ง PICKSET code (หรือ SELECTION.md ที่ติ๊กแล้ว) กลับมา → ผม apply ลง BUILD-BRIEF รวมใส่ hex + กติกาการใช้สี + ตาราง WCAG ของโลกที่เลือกลง THEME block → รัน coherence pass บนชุดของคุณ (จุดที่ต้องจับตาถูกโค้ดไว้ในคอนโซลแล้ว: B4+D1 แย่งเส้นนำสายตา · C1+L2 กลไกซ้ำ · A4+preloader สองด่าน · ฟอนต์ static + component ที่ต้อง variable · โลกสีไม่มี accent + ตัวเลือกที่พึ่งสี · งบ pin/hover เกิน) → ออก **BUILD-BRIEF-FINAL.md** ไฟล์เดียวที่ส่งให้คนบิลด์
