# planc-arcade — เว็บเกม (คนละเว็บกับ planc-web)

เว็บใหม่ แยกจาก `planc-web` (เว็บ Mario scrollytelling) เด็ดขาด — **คนละเว็บกัน
ห้ามเอางานที่นี่ไปแก้อะไรใน planc-web และห้ามลบอะไรใน planc-web**
ไฟล์ตั้งต้นทั้งหมดก๊อปมาจาก planc-web เมื่อ 17 ส.ค. 2026 (ต้นฉบับยังอยู่ที่เดิมครบ)

โครงเว็บ: เกมยิงอวกาศแบบ Galaga เป็นหัวใจ + หน้าเว็บปกติธีมเดียวกับเกม
(home / services / who we are / contact — ทุกหน้าอ่านเป็น "ตู้เกมเดียวกัน")

## กติกาที่ยกมาจาก planc-web (ยังบังคับใช้ทุกข้อ)

- **ขาว-ดำล้วน ห้ามใส่สี** — มีแค่ `--ink` / `--paper` เอฟเฟกต์ CRT ทำได้เฉพาะเทา/ขาว
- **แมวดำห้าม invert บนพื้นมืด** — ใส่ rim `drop-shadow` 4 ทิศด้วย --ink แทน
  `assets/cat.png` คือภาพแมวที่อนุมัติแล้วตัวเดียว **ห้ามเจนแมวใหม่เด็ดขาด**
- **ไทยนำ อังกฤษเป็นป้ายเล็ก** · mobile-first ออกแบบที่ 390px ก่อนเสมอ
- **ข้อความไทยห้ามตัดทีละตัวอักษร** — ใช้ `Intl.Segmenter('th',{granularity:'word'})`
- **ค่าหน่วงต้องคูณ dt** — `x += (t-x)*(1-Math.pow(1-k, dt*60))`
- **ของที่ผูกกับสกรอลต้อง scrub-safe** — เลื่อนถอยแล้วต้องย้อนได้ (เกม Phaser จริง
  มีเวลา/input ของตัวเอง ไม่เข้าข่ายข้อนี้ แต่หน้าเว็บรอบๆ เข้า)
- **ตรวจงานด้วยการเรนเดอร์จริงเท่านั้น** ห้ามตัดสินจากโค้ด และส่ง mp4 ให้ Mat เสมอ
  (Mat ดูบนมือถือ) — Playwright ในแซนด์บ็อกซ์ต้องระบุ executablePath:
  `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`
- **ทุกการตัดสินใจด้านดีไซน์เป็นของ Mat** เสนอทางเลือกแล้วถามเป็นข้อความธรรมดาในแชท
  **ห้ามใช้ AskUserQuestion tool** · ตัวเลขทุกตัวต้องมาจากการวัด ไม่นั่งเทียน

## โครงไฟล์

```
assets/cat.png + fonts/     แมว + ฟอนต์ไทย subsets (Prompt 600/800, Sarabun 400/600)
docs/GAME-REFERENCES.md     เรฟ 2024–2026 ที่ verify แล้ว 28 รายการ — อ่านก่อนออกแบบ
game/galaga.src.html        โปรโตแบบสกรอล (scrub-safe ทุกอย่างเป็นฟังก์ชันของ progress)
game/play.src.html          เกมเล่นจริงบน Phaser 3 (ลากนิ้วบิน ยิงออโต้)
game/build.py               ประกอบสองตัวบนจาก src (ฝังฟอนต์+แมว) — python3 build.py
game/galaga-*.html/.mp4     ไฟล์ built เปิดได้เลย + วิดีโอเดโม
game/gshots.mjs grec.mjs playtest.mjs   สกรีนช็อต / อัดวิดีโอ / บอทเล่นทดสอบ
```

ตัวเกมต้องมี `phaser.min.js` ใน `game/` ก่อน build:
`npm pack phaser@3 && tar xzf phaser-3.*.tgz && cp package/dist/phaser.min.js game/`
(ไฟล์นี้ไม่ได้ก๊อปมา — โหลดใหม่ได้เสมอ)

## โครงเกมที่คุยไว้แล้ว (รอเคาะรายละเอียด — อย่าเริ่มสร้างเอง)

1. จอโหลด = โลโก้ + motto ของ agency → PRESS START
2. จอเลือกยาน = เลือกสายอินฟลูเอนเซอร์ (กิมมิคมีผลในด่าน)
3. ศัตรู "แมงหวี่" มาเป็นเวฟ — แต่ละเวฟแปลงจากประโยคปัญหาจริงของอินฟลู
4. อัตราโผล่ (λ) ไต่จนเกินเพดานเคลียร์ของยานเดียว (μ วัดด้วยบอท playtest.mjs
   ห้ามตั้งจากความรู้สึก) → เกือบแพ้ → Plan C เข้าประกบเป็น 2 แล้ว 3 ลำ
   หลักคณิต: ตั้ง λ ให้ μ < λ < 2μ ยานเดียวจมแบบพิสูจน์ได้ สองลำเคลียร์ทัน

## รอ Mat ตัดสิน (ถามซ้ำได้ อย่าตัดสินแทน)

1. แบรนด์ของเว็บนี้: planc*/Plan C เว็บที่สอง หรือคนละแบรนด์ — คำตอบคุมโลโก้/ก็อปปี้/กติกาสี
2. สายอินฟลูมีกี่สาย ชื่ออะไร · กิมมิคเปลี่ยนแค่หน้าตา+ประโยค หรือเปลี่ยนกลไกด้วย
3. ประโยคปัญหาต่อเวฟ — Mat พิมพ์เอง หรือ placeholder [เดา] รอเนื้อหาจริง
4. ยืนยัน "ไม่มีแพ้จริง" (จุดต่ำสุดคือเกือบแพ้ แล้ว Plan C มาช่วยเสมอ)
5. ผิวเกม: เวกเตอร์เส้นขาว (ปัจจุบัน) / พิกเซล 1-bit / พิกเซล 4 เฉดแบบเกมบอย
6. เมนูแพ็คอัพเกรดความสวย (CRT / dither / arcade ritual / juice / decode text /
   phosphor / pixel-perfect) — เสนอไว้ในแชทแล้ว ยังไม่เลือก
7. ชื่อเว็บ/โฟลเดอร์ — ตอนนี้ใช้ `planc-arcade` ชั่วคราว เปลี่ยนได้ทุกเมื่อ

## ยังไม่มี / ยังไม่ทำ

- โลโก้จริง (เวิร์ดมาร์ก P หน้าแมว) ยังไม่มีไฟล์ในโฟลเดอร์นี้ — ขอจาก Mat
- หน้าเว็บ home/services/who-are-we ยังไม่เริ่ม (รอเคาะแบรนด์ + โครงเกม)
- ฟอนต์พิกเซลสำหรับ HUD อังกฤษ · เสียงอาร์เคด CC0 (ปิดเป็นค่าเริ่มต้น)
- ฉาก tractor-beam (บอสจับยานแมว → Plan C ช่วย → ยานคู่) — ออกแบบค้าง รอไฟเขียว
- `git init` โฟลเดอร์นี้ — ยังไม่ได้ทำ
