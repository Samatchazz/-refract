## ข้อสรุปภาพรวม (อ่านอันนี้ก่อน)

1. **ยังไม่มีใครทำขาว-ดำล้วนเลย** — ผู้ชนะรางวัลปี 2024–2026 ทุกรายใช้ "สองสีเคร่งครัด"
   (Lacoste เขียว/เหลือง · Cdiscount น้ำเงิน/ชมพู · Gucci ครีม/ทอง) ขาว-ดำล้วนของ planc*
   จึงเป็นช่องว่างที่ยังไม่มีใครยึด และเรฟสองสีทั้งหมดพิสูจน์แล้วว่า "สองหมึกพอ"
2. **เกมทั้งหน้าชนะ SOTD ได้จริงในปี 2025–2026** (Darkstar Fury, Lacoste, Sephora, XOX)
   — เกมไม่ใช่ของเล่นแปะเว็บอีกแล้ว มันเป็นตัวเว็บได้เลย
3. **จุดขายอยู่ที่จอ game-over** — เรฟแบรนด์ทุกตัวปี 2026 วาง CTA/รางวัลตรงจอจบเกม
   (คะแนน → โค้ดส่วนลด / จองคิว / ฟอร์มติดต่อ) ไม่ใช่ซ่อนไว้ใน easter egg
4. **Easter egg สายยิงอวกาศ "ว่างอยู่"** — ตรวจแล้วไม่พบแบรนด์ไหนทำ konami-code /
   ยานยิงแอบซ่อนในช่วง 2024–2026 เลย ของดังๆ เป็นของก่อน 2024 ทั้งหมด
5. **มือถือมาก่อนเป็นมาตรฐาน** — Sephora ออกแบบชุดปุ่มจอสัมผัสแยกจากเดสก์ท็อป,
   Cdiscount เป็น web-app แนวตั้งเต็มรูปแบบ ตรงกับกติกา 390px ของเราอยู่แล้ว

## ง. เทคนิค/บทความ/ไลบรารี (2024–2026) — คู่มือลงมือ

### 22. The Art of Dithering and Retro Shading (Maxime Heckel) ★ ไบเบิลของงานนี้
- **ลิงก์:** https://blog.maximeheckel.com/posts/the-art-of-dithering-and-retro-shading-web/ · ส.ค. 2024
- ทัวร์ GLSL ครบ: Bayer 2x2/4x4/8x8, blue-noise, CRT (scanline โค้งจอ shadow-mask bloom)
- **บทเรียน:** เมทริกซ์ Bayer 4x4 เป็น const จิ๋วใน fragment shader เดียว quantize เป็น
  ขาว/ดำแท้ + ยัด scanline ใน pass เดียวกัน — "รวม pass เดียว" คือกุญแจ perf ที่ 390px/60fps

### 23. Game feel on the web (valdemird.com) — 2026
- **ลิงก์:** https://valdemird.com/blog/game-feel-on-the-web/
- squash/stretch · hitstop · screen shake ("translate อย่างเดียวดูเหมือน glitch —
  ต้องแถม rotate ~0.3°ถึงอ่านเป็นแรง") · particle เป็น DOM div ใช้แล้วทิ้ง
- **บทเรียน:** เอฟเฟกต์ทั้งชุดไร้สีโดยธรรมชาติ + ต้อง gate ด้วย prefers-reduced-motion

### 24. CRTFilter (WebGL, MIT) — มี.ค. 2025
- **ลิงก์:** https://www.cssscript.com/retro-crt-filter-webgl/
- ฟิลเตอร์ทับ canvas เดิม: scanline, dot mask, barrel, flicker, jitter, retrace, glow, noise
  (~15 ปุ่มปรับ) แถมส่งต่อ input event ให้ canvas ต้นทาง
- **บทเรียน:** ปิด chromatic aberration/dot mask · เปิดแค่ barrel + scanline + flicker จาง
