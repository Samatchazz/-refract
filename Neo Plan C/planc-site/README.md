# planc* — scroll-driven site

หน้าเดียว เลื่อนลงแล้วแมวเดินไปทางขวา ผ่านด่านแบบ Mario 1-1
ขาว-ดำล้วน ไทย+อังกฤษ mobile-first (390px)

## เปิดดูยังไง

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องลง node ไม่ต้อง build
ถ้าจะดูบนมือถือหรือส่งให้คนอื่นไฟล์เดียว ใช้ `dist/planc-demo3.html`

## โครงไฟล์

```
index.html        โครงหน้า + เนื้อหาทุก beat (แก้ข้อความที่นี่ที่เดียว)
css/site.css      สไตล์ทั้งหมด รวมฉากหลัง SVG ที่ฝังเป็น data URI
js/scene.js       เลย์เอาต์ด่าน ชั้นพารัลแลกซ์ พื้น จุดกระโดด แยกคำไทย
js/cat.js         ริกแมว — ท่าเดินปลอมที่สร้างจากภาพนิ่งใบเดียว
js/ui.js          preloader / nav / เมนู / HUD เกม
js/main.js        ลูป rAF ที่ผูกสกรอลเข้ากับทุกอย่าง + กล้อง
assets/cat.png    แมวตัดพื้นหลังแล้ว 560px quantize 32 สี (17KB)
build.py          รวมทุกอย่างเป็นไฟล์เดียว → dist/planc-demo3.html
tools/            สคริปต์ตรวจงาน: shots.mjs (สกรีนช็อต) rec.mjs (อัดวิดีโอ)
```

## แก้อะไรตรงไหน

| อยากแก้ | ไปที่ |
|---|---|
| ข้อความ / ชื่อฉากในเมนู | `index.html` — `data-name` กับเนื้อใน `.beat` |
| ตำแหน่งที่แต่ละฉากโผล่ | `data-p` (0..1) ใน `index.html` |
| ความยาวด่าน / ความยาวสกรอล | `TRAVEL_MIN`, `SCROLL_LEN` ใน `scene.js` |
| หลุมพื้น | `PIT` ใน `scene.js` |
| จุดกระโดด | อาเรย์ `jumps` ท้ายฟังก์ชัน `layout()` |
| ท่าเดินแรงแค่ไหน | `GAIT_RATE / BOB_PX / LEAN_DEG / SQUASH` ใน `cat.js` |
| ความลึกของฉากหลัง | `data-f` ของ `.layer` ใน `index.html` (0.12 / 0.35 / 1 / 1.25) |
| ช่วงด่านมืด | เงื่อนไข `inverted` ใน `main.js` |

## กติกาที่ต้องรู้ก่อนแก้

- **ทุกตำแหน่งเป็น progress ไม่ใช่พิกเซล** ถ้าใส่ px ตายตัว จอ 390px จะเดินไม่ถึงเสาธง
- **ด่านมืดห้าม invert ตัวแมว** พื้นก็ invert เป็นขาวด้วย ครึ่งล่างของแมวจะหายเข้าไปในพื้น
  ให้แมวดำไว้แล้วใส่ rim ด้วย `drop-shadow` 4 ทิศแทน
- **ทุกอย่างต้องเลื่อนกลับได้** ไม่มีอนิเมชั่นที่ผูกกับเวลาเดินหน้าอย่างเดียว
  ยกเว้นเมฆที่ตั้งใจให้ลอยตามนาฬิกาตัวเอง
- **ค่าหน่วง (smoothing) คูณด้วย dt หมดแล้ว** จอ 120Hz กับ 60Hz จะรู้สึกเหมือนกัน
