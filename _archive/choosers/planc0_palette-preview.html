ทุกช่องคือ เนื้อหาชุดเดียวกัน (hero → manifesto → 3 pillars → ledger → CTA) ต่างกันแค่สี — เพื่อให้ตัดสินด้วยตาไม่ใช่ด้วยตาราง hex. สังเกต 3 อย่าง: 1) แมวดำอ่านออกไหมบนพื้นนั้น (พื้นมืดต้องมี rim — เห็นได้ในช่อง M0/M2/M3) 2) เส้น thread ระหว่าง band คือเครื่องมือ “ไร้รอยต่อ” สีไหนทำให้มันเด่นพอ 3) accent โผล่กี่จุด — เกิน ~5% ของจอเมื่อไหร่ ความ “คม” จะหาย. กดปุ่มล่างการ์ดเพื่อจดตัวเลือก แล้วก๊อปบรรทัดที่ขึ้นมาไปวางในแชท

อ่านตัวเลขยังไง: ✓ = ผ่าน WCAG AA (≥4.5:1 สำหรับ body text) · ✗ = ห้ามใช้เป็นตัวหนังสือ ใช้เป็นกราฟิกได้ · large only = ใช้ได้เฉพาะตัวใหญ่ ≥24px
