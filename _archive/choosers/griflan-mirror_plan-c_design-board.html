รายละเอียด

การ์ด = แผ่นแผนที่

เส้นขอบ 1px เท่านั้น ไม่มีเงา — แผนที่ไม่มีเงา ความลึกมาจากหมอกกับการซ้อนชั้น
มุมมีขีดพิกัด ยืดออกตอนชี้เมาส์ (ลองชี้ที่การ์ดซ้ายดู)
มุมโค้งไม่เกิน 0–2px ของเอกสารสำรวจต้องคม
ป้ายบนสุดเป็นโมโนเสมอ ทำหน้าที่เหมือนเลขระวางแผนที่
← ปุ่มใช้โมโน ตัวพิมพ์ใหญ่ ระยะห่างกว้าง

สิ่งที่เปลี่ยนไปจากตอนนี้

ตารางหมากรุกพื้นหลัง → เส้นชั้นความสูง (contour) ที่ถี่ขึ้นตอนชันขึ้น
ชิป/ไพ่โป๊กเกอร์ → หมอกที่บังทางข้างหน้า แล้วเปิดออกเมื่อเดินถึง
เส้นกราฟยอดวิว → เส้นสันเขาบนแผนที่ (ความหมายเดิม ภาพใหม่)
เสาหลัก 3 ต้น → หมุดสำรวจปักดิน มีเลขระวางกำกับ
ธงปลายทาง → เส้นประล้อมอาณาเขต + หมุดมุม = ที่ดินที่อ้างสิทธิ์แล้ว
ตัวหมากรุกล้ม → ยังเก็บไว้ได้ แต่ย้ายไปอยู่แค่ด่านเดียวที่พูดถึงมันตรงๆ
แมวคือตัวถ่วงสำคัญ — ธีมนี้เสี่ยงจะเนี้ยบจนเย็นชา สิ่งที่กันไม่ให้เป็นแบบนั้นคือแมวที่เดินอยู่กลางแผนที่ ยิ่งฉากรอบตัวแม่นยำเป็นระเบียบเท่าไหร่ แมวยิ่งดูมีชีวิตขึ้นเท่านั้น เพราะฉะนั้นห้ามทำแมวให้เนี้ยบตาม — ให้มันกลม นุ่ม เคลื่อนไหวแบบสปริง ตัดกับเส้น 1px รอบตัว
