# Hyper Gummy — Brief สำหรับแชตที่จะทำ Midjourney concept art

> วางไฟล์นี้ทั้งไฟล์ในแชตใหม่ แล้วสั่งว่า "อ่าน brief นี้ ทำตามลำดับงาน 1 → 2 → 3 ส่งผลลัพธ์ตามฟอร์แมตในข้อ 4"

---

## 0. บริบท (อ่านก่อน)

**Hyper Gummy** คือเอเจนซี่คอนเทนต์สำหรับแบรนด์ จุดขายคือ "เราทำให้โปรดักต์แมส ตั้งแต่ยังไม่เกิด"
เข้าไปนั่งกับทีมโปรดักต์ตั้งแต่ของยังเป็นแค่ส่วนผสม ไม่ใช่ตอนเสร็จแล้วค่อยหาเรื่องเล่า

เว็บไซต์ทำเสร็จแล้ว (Three.js + WebGL) มาสคอตคือ **หมีกัมมี่สีชมพูโปร่งแสง เงาวาว นั่งกอดหัวใจ**
สิ่งที่ยังขาดคือ **รูปประกอบในหน้าเคส** ซึ่งตอนนี้เป็น placeholder ก้อนสีที่โค้ดวาดเอง

**ข้อจำกัดสำคัญที่สุด:** โปรดักต์ของลูกค้าทุกตัวเป็นความลับ ทั้งก่อนและหลังเปิดตัว
**ห้ามใช้รูปโปรดักต์จริง** รูปทุกใบต้องเป็น **concept art** ที่สื่อ "ไอเดีย" ของเคส ไม่ใช่ตัวสินค้า
ห้ามมีโลโก้ ห้ามมีแบรนด์จริง ห้ามมีตัวหนังสือในภาพ (Midjourney เขียนไทยไม่ได้อยู่แล้ว และเราไม่ต้องการ)

---

## 1. งานที่ 1 — ศึกษาและตั้งชื่อสไตล์ของเว็บเรา

เว็บมีลักษณะภาพแบบนี้ (ดูให้ครบแล้วค่อยสรุปว่าในโลก Midjourney/3D art เรียกว่าอะไร):

- **วัสดุหลัก:** เยลลี่/กัมมี่โปร่งแสง เงาวาวแบบเปียก แสงทะลุตัว สีเข้มตรงส่วนหนา ซีดตรงขอบบาง (subsurface scattering / transmission)
- **รูปทรง:** กลม ป่อง มน ไม่มีเหลี่ยม ทุกอย่างดูนุ่มและเด้งได้ (blobby, puffy, inflated)
- **พาเลต:** ครีมวานิลลา `#FFF4E8` เป็นพื้น, พลัมเข้ม `#2B1735` เป็นตัวหนังสือ, สตรอว์เบอร์รี `#FF3D8F` เป็นสีหลัก
  เสริมด้วย องุ่น `#8A5CFF`, มะนาว `#A6E85C`, ส้ม `#FF8A3D`, ฟ้า `#5CCBFF`, เลมอน `#FFD23F`
- **พื้นหลัง:** ไล่สีลูกกวาดนุ่มๆ ก้อนสีพีช ชมพู ม่วงอ่อน มินต์ ลอยเบลอๆ มีเกรนบางๆ
- **แสง:** สตูดิโอนุ่ม ไฮไลต์ขาวชัดหนึ่งจุดบนทุกผิว เงาอ่อน ไม่มีเงาดำแข็ง
- **อารมณ์:** สดใส ขี้เล่น น่ารักแบบผู้ใหญ่ (ไม่ใช่เด็ก) มีความ "ของเล่นระดับพรีเมียม"
- **พร็อพที่มีอยู่แล้วในเว็บ:** หมีกัมมี่จิ๋ว, หัวใจเยลลี่, ขวดโคล่ากัมมี่, กลีบส้ม/มะนาว, สายรุ้งเคลือบน้ำตาล, ดาว, โบว์, แก้วน้ำมีหลอด, ไอติมโคน, โดนัท

**สิ่งที่ต้องส่งกลับจากงานที่ 1:**
- ชื่อสไตล์ที่คนในวงการใช้ 3-5 ชื่อ (เช่น กลุ่มคำอย่าง glossy 3D render, jelly/gummy material, claymorphism, inflatable 3D, candy-core, soft 3D illustration, blender/octane render, Y2K blobby) พร้อมอธิบายสั้นๆ ว่าแต่ละคำให้ผลต่างกันยังไงใน Midjourney
- คำที่ **ควรใส่** และ **ไม่ควรใส่** ใน prompt เพื่อให้ได้ผิวกัมมี่โปร่งแสง (ไม่ใช่พลาสติกทึบ ไม่ใช่แก้ว)
- พารามิเตอร์ Midjourney ที่เหมาะ (เวอร์ชันล่าสุด, `--style raw` หรือไม่, ค่า `--s`, `--chaos`, ใช้ `--sref` / `--cref` ยังไงให้ทุกภาพเป็นชุดเดียวกัน)
- วิธีทำ **style reference ชุดเดียว** ให้ทุกภาพในเว็บดูเป็นครอบครัวเดียวกัน (แนะนำให้ gen ภาพ "anchor" 1 ใบก่อน แล้วใช้เป็น `--sref` ทุกภาพที่เหลือ)

## 2. งานที่ 2 — รายการภาพที่ต้องการ

ภาพทั้งหมดเป็น **concept ของไอเดีย** ไม่ใช่สินค้า วิธีคิด: หยิบ "สิ่งที่เราปรับ" ในเคสมาทำเป็นวัตถุกัมมี่หรือฉากเยลลี่เชิงสัญลักษณ์

### เคสทั้ง 4 (แต่ละเคสต้องการ 5 ภาพ) — จากงานจริง แต่ต้องเป็นคอนเซปต์ ห้ามระบุแบรนด์

| เคส (slug) | แก่นของภาพ | วัตถุกัมมี่ที่ใช้แทน | สีประจำเคส |
|---|---|---|---|
| เมนูลับที่ไม่ได้ลับ (`secret-menu`) | เมนูพิเศษของเชนกาแฟที่ถูกออกแบบไว้ล่วงหน้า รอคนโพสต์คนแรก ไม่ได้รอคนค้นเจอ | แก้วเยลลี่มีหลอด, ชั้นขนมทีรามิสุเป็นเยลลี่, ก้อนเจลลี่สตรอว์เบอร์รีลอย, "ประตูลับ" เยลลี่แง้มอยู่ | เขียวมะนาว/มัทฉะ `#A6E85C` |
| เมนู DIY ที่ไม่ได้มิกซ์มั่วๆ (`diy-menu`) | สูตรจากของในร้านสะดวกซื้อ 5 อย่างที่ถูกเลือกไว้แล้ว ทำตามได้เป๊ะ | ดาวเยลลี่, ของ 5 ชิ้นเรียงเป็นแถวบนชั้นวางเยลลี่, ชามสลัดเยลลี่ | ฟ้า `#5CCBFF` |
| สตอรี่ที่ไม่ใช่เทรนด์ (`story-not-trend`) | คอลเลกชันขนมอบ 3 รสเบอร์รีที่ตั้งชื่อก่อนสั่งวัตถุดิบ เรื่องเล่ามาก่อนของ | โดนัทเยลลี่ 3 ชิ้น 3 สี, ผลเบอร์รีเยลลี่, ป้ายชื่อว่างเปล่าลอยเหนือแต่ละชิ้น | ชมพู `#FF3D8F` (+ ม่วง/แดง/ฟ้าอ่อนของเบอร์รี) |
| ของที่ขายอยู่ดีๆ กลายเป็นเมนูไวรัล (`viral-ingredient`) | บิสกิตกับสเปรดบนชั้นเดิม กลายเป็นพระเอกของชีสเค้กไม่ง้อเตาอบ เพราะวางแผนไว้ | ชีสเค้กเยลลี่ 3 ชั้น, บิสกิตเยลลี่สีคาราเมล, สเปรดไหลเป็นเยลลี่, หัวใจ | ส้มคาราเมล `#FF8A3D` |

**5 ภาพต่อเคส (ตำแหน่งในหน้าเว็บ + สัดส่วน):**

1. `cover` — ภาพหลักบนสุด **16:9** ฉากรวมของเคส วัตถุหลักอยู่กลาง มีพื้นที่ว่างรอบๆ
2. `media-1` — **4:3** โคลสอัปวัตถุหลัก ใกล้มากจนเห็นแสงทะลุเยลลี่
3. `media-2` — **3:4** แนวตั้ง วัตถุหลักกับพร็อพเสริม 2-3 ชิ้นลอยอยู่
4. `wide` — **21:9** แบนเนอร์กว้างเต็มจอ ฉากกว้าง วัตถุกระจายเป็นจังหวะ เว้นที่ว่างกลางภาพได้
5. `media-3` — **4:3** ภาพ "ก่อน/หลัง" เชิงสัญลักษณ์ เช่น ก้อนเยลลี่ไร้สีทางซ้าย กลายเป็นสีสดทางขวา

### ภาพส่วนกลาง (ไม่ผูกกับเคส)

6. `about-anchor` — **1:1** ภาพ anchor ของสไตล์ทั้งหมด: หมีกัมมี่ชมพูนั่งกอดหัวใจฟ้า พื้นหลังครีมไล่สี (ใช้เป็น `--sref` ให้ภาพอื่น)
7. `about-grey` — **16:9** ก้อนเยลลี่สีเทาไร้สี ดูเหมือนโปรดักต์ที่ยังไม่มีใครใส่ใจ (ใช้ในหน้า About บทแรก)
8. `about-crowd` — **21:9** หมีกัมมี่จิ๋วหลากสีนับสิบตัวถือของคนละอย่าง (ปิดท้ายหน้า About)
9. `og-image` — **1.91:1** ภาพสำหรับแชร์ลิงก์ หมีกับหัวใจ พื้นที่ว่างด้านซ้ายไว้ใส่ตัวหนังสือทีหลัง

รวม **4 × 5 + 4 = 24 ภาพ**

## 3. งานที่ 3 — เขียน prompt

กติกาการเขียน:
- ภาษาอังกฤษทั้งหมด
- ทุก prompt ต้องมี **บล็อกสไตล์เดียวกัน** ต่อท้าย (ที่ได้จากงานที่ 1) เพื่อให้ 24 ภาพเป็นชุดเดียวกัน
- ใส่สีประจำเคสเป็นคำบรรยายสี ไม่ต้องใส่โค้ดสี hex (Midjourney ไม่เข้าใจ hex)
- ระบุ **สัดส่วนด้วย `--ar`** ให้ตรงตามตาราง
- **ห้าม** มีตัวหนังสือ โลโก้ แบรนด์ คน (ยกเว้นมือเด็กในเคสขนม ถ้าจำเป็น) และห้ามเป็นสินค้าจริงที่จำแบรนด์ได้
- ถ้าภาพไหนเสี่ยงได้ผลเป็นพลาสติกทึบ ให้เติมคำกันไว้ (เช่น translucent, light passing through, subsurface scattering, jelly)
- ทำ prompt สำรอง 1 แบบต่อภาพ (variant) เผื่อแบบแรกไม่ได้

## 4. ฟอร์แมตผลลัพธ์ที่ต้องส่งกลับ

ส่งเป็น **ตาราง Markdown เดียว** คอลัมน์ตามนี้ เพื่อให้เอาไปวางลงเว็บได้ทันที:

| ไฟล์ปลายทาง | สัดส่วน | prompt หลัก | prompt สำรอง |
|---|---|---|---|
| `cases/secret-menu/cover.jpg` | 16:9 | ... | ... |
| `cases/secret-menu/media-1.jpg` | 4:3 | ... | ... |
| ... | | | |
| `about/anchor.jpg` | 1:1 | ... | ... |
| `share/og.jpg` | 1.91:1 | ... | ... |

**slug ของเคส (ใช้ตั้งชื่อโฟลเดอร์):** `secret-menu`, `diy-menu`, `story-not-trend`, `viral-ingredient`

ก่อนตาราง ให้สรุป **บล็อกสไตล์กลาง** (ประโยคที่ต่อท้ายทุก prompt + พารามิเตอร์) ไว้หนึ่งย่อหน้า
และ **ลำดับการ gen ที่แนะนำ** (anchor ก่อน → ใช้ `--sref` → เคสละชุด)

## 5. ที่จะเกิดขึ้นหลังจากนั้น (ไม่ต้องทำในแชตนั้น)

พอได้ภาพจริง จะวางไว้ที่ `hyper-gummy/public/assets/<ไฟล์ปลายทาง>` ตามชื่อในตาราง
แล้ว Claude Code จะเปลี่ยนบล็อก `media-art` ในหน้าเคสให้โหลดรูปตามชื่อไฟล์อัตโนมัติ
ภาพควรเป็น JPG ความกว้างอย่างน้อย 1600 พิกเซล (cover / wide อย่างน้อย 2400)
