# แบบประเมิน Plan C — เกณฑ์ 6 ข้อ 3 ชั้น (ร่างที่ 1)

> **สิ่งนี้คืออะไร:** เครื่องมือให้คะแนนที่แปลง "คำบ่นของแบรนด์" ให้เป็นตัวเลขที่ทำซ้ำได้
> **ใช้ตอนไหน:** นาทีที่ 60 ของเซสชัน 90 นาที — **ให้เจ้าตัวให้คะแนนตัวเอง** แล้ว Plan C ให้คะแนนเทียบทีหลัง
> **ทำไมต้องให้เขาให้คะแนนเอง:** เพราะคำวินิจฉัยนี้เป็นคำติเรื่องนิสัย (A13) คนจะยอมรับเลขที่ตัวเองเขียนมากกว่าเลขที่ถูกบอก
>
> **สิ่งที่มันปลดล็อกให้ 4 อย่างในครั้งเดียว:** audit ที่ทำซ้ำได้ · ตัวเลข before/after สำหรับเคส · เหตุผลให้ทำใหม่ทุกไตรมาส · นิยาม "verified" สำหรับเฟส 3

---

## กฎก่อนใช้ — อ่านก่อนทุกครั้ง

**เกณฑ์นี้มาจากฝั่งแบรนด์ ซึ่งเป็นฝั่งที่มีผลประโยชน์ตรงข้ามกับผู้ถูกประเมิน** ถ้าใช้โดยไม่กรอง เครื่องมือนี้จะกลายเป็นเครื่องฝึกคนให้เชื่อฟัง (A14) จึงมีกฎ 2 ข้อ:

1. **หมวด "ขอบเขตที่ห้ามหักคะแนน" (ท้ายเอกสาร) มีอำนาจเหนือทุกข้อ** — ถ้าพฤติกรรมหนึ่งเข้าข่ายนั้น ห้ามให้คะแนนต่ำ แม้แบรนด์จะบ่น
2. **ให้คะแนนจากพฤติกรรมที่เกิดขึ้นแล้ว ไม่ใช่ความรู้สึก** — ทุกข้อต้องอ้างเหตุการณ์จริงในดีล 3 ดีลล่าสุด ถ้าอ้างไม่ได้ ให้เว้นว่าง ห้ามเดา

---

## ชั้น 1 — วัดได้ (คะแนนเต็ม 9)

พฤติกรรมที่มีหลักฐานในแชทและไฟล์ ไม่ต้องตีความ

### 1.1 ส่งงานตรงเวลา
| คะแนน | เกณฑ์ (อ้างจาก 3 ดีลล่าสุด) |
|---|---|
| 0 | เลยกำหนดโดยไม่แจ้งล่วงหน้า ≥1 ครั้ง |
| 1 | ส่งทันแต่ต้องถูกตามทุกครั้ง |
| 2 | ส่งทันเอง แจ้งล่วงหน้าเมื่อจะช้า |
| 3 | ส่งก่อนกำหนด + แจ้งความคืบหน้าโดยไม่ถูกถาม |

### 1.2 เวลาตอบกลับ
| คะแนน | เกณฑ์ |
|---|---|
| 0 | หายเกิน 48 ชม. ในช่วงงานเดิน |
| 1 | ตอบภายใน 24–48 ชม. |
| 2 | ตอบภายในวันทำการเดียวกันเสมอ |
| 3 | ตอบเร็ว + ถ้ายังตอบเนื้อหาไม่ได้ ก็ยังตอบรับว่าเห็นแล้วและจะกลับมาเมื่อไหร่ |

### 1.3 ความชัดเจนเรื่องคู่แข่ง / ช่วงห้ามซ้อน
| คะแนน | เกณฑ์ |
|---|---|
| 0 | รับแบรนด์คู่แข่งซ้อนช่วง โดยไม่แจ้ง |
| 1 | ไม่ซ้อน แต่ไม่รู้ว่าสัญญาระบุช่วงห้ามซ้อนไว้กี่วัน |
| 2 | รู้เงื่อนไขทุกฉบับที่เซ็น และเช็กก่อนรับงานใหม่ |
| 3 | มีตารางของตัวเองที่ไล่ดูได้ทันทีว่าช่วงไหนติดใครอยู่ |

## ชั้น 2 — วุฒิภาวะในการทำงาน (คะแนนเต็ม 6)

### 2.1 การรับการแก้งาน
| คะแนน | เกณฑ์ |
|---|---|
| 0 | โต้กลับด้วยอารมณ์ / เงียบหาย / แก้แบบขอไปที |
| 1 | แก้ให้แต่ไม่ถามว่าทำไม |
| 2 | ถามเหตุผลก่อน แก้ตามที่ตกลง ครั้งเดียวจบ |
| 3 | ถามเหตุผล + เสนอทางเลือกที่ตอบโจทย์เขาและรักษาสิ่งที่ตัวเองต้องรักษาไว้ได้ |

### 2.2 ความสมเหตุสมผลของข้อเรียกร้อง (ดูคู่กับ "ขอบเขตที่ห้ามหักคะแนน")
| คะแนน | เกณฑ์ |
|---|---|
| 0 | เรียกร้องโดยไม่มีเหตุผลอธิบาย และเปลี่ยนไปเรื่อยๆ |
| 1 | มีเงื่อนไขแต่บอกทีหลัง หลังตกลงราคาแล้ว |
| 2 | **บอกเงื่อนไขทั้งหมดล่วงหน้าเป็นลายลักษณ์อักษร พร้อมเหตุผล** |
| 3 | มีเอกสารเงื่อนไขมาตรฐานของตัวเอง ส่งให้ดูตั้งแต่คุยราคา |

> ⚠️ **การมีเงื่อนไขไม่ใช่ความผิด — การมีเงื่อนไขที่โผล่มาทีหลังคือความผิด** ข้อนี้วัดจังหวะและความชัดเจน ไม่ได้วัดจำนวนเงื่อนไข

## ชั้น 3 — ตัวตน (คะแนนเต็ม 6) ← ต้นน้ำของทั้งสองชั้นบน

นี่คือชั้นที่เอเจนซีทำไม่ได้ และเป็นชั้นที่กำหนดราคาที่เรียกได้

### 3.1 รู้ว่าถูกเลือกเพราะอะไร
| คะแนน | เกณฑ์ |
|---|---|
| 0 | ตอบว่า "เพราะยอด" หรือ "ไม่รู้" |
| 1 | ตอบเป็นหมวดกว้างๆ เช่น "สายกิน" "สายรีวิว" |
| 2 | ระบุได้ว่าคนดูของตัวเอง**ทำอะไร**หลังดู และเชื่ออะไรจากตัวเขา |
| 3 | อธิบายได้ว่าแบรนด์ประเภทไหน**ไม่ควร**จ้างเขา และเพราะอะไร |

> ข้อ 3.1 คะแนน 3 คือตัวชี้วัดเดียวที่สัมพันธ์กับราคาที่เรียกได้ **คนที่ตอบได้ว่าใครไม่ควรจ้างตัวเอง คือคนที่วัดผลได้ และคนที่วัดผลได้คือคนที่จ่ายแพงได้**

### 3.2 ความสอดคล้องของงานที่รับกับตัวตน
| คะแนน | เกณฑ์ (ดูดีลจริง 6 เดือนล่าสุด) |
|---|---|
| 0 | รับทุกอย่างที่เข้ามา รวมทั้งของที่ขัดกับที่เคยพูดไว้เอง |
| 1 | รับเกือบทุกอย่าง แต่รู้ตัวว่าบางอันไม่ควรรับ |
| 2 | ปฏิเสธงานได้อย่างน้อย 1 ครั้งในรอบ 6 เดือน และอธิบายเหตุผลได้ |
| 3 | มีเกณฑ์รับ/ไม่รับที่เขียนไว้ก่อนงานเข้ามา ไม่ใช่ตัดสินเป็นครั้งๆ |

## ข้อ 7 (เพิ่มใหม่) — สัดส่วน barter ต่อรายได้ทั้งหมด

ไม่ใช่เกณฑ์ของแบรนด์ แต่เป็นตัวชี้วัดสุขภาพธุรกิจของครีเอเตอร์ และเป็นข้อที่ Plan C ยืนข้างครีเอเตอร์ชัดที่สุด

| คะแนน | เกณฑ์ |
|---|---|
| 0 | รายได้หลักมาจาก barter / ของแลกงาน |
| 1 | barter เกินครึ่ง |
| 2 | barter ต่ำกว่า 25% และรับเฉพาะกรณีที่เลือกเอง |
| 3 | ไม่รับ barter เว้นแต่มีเหตุผลเชิงกลยุทธ์ที่เขียนไว้ได้ |

## รวมคะแนน (เต็ม 24)

| ช่วง | ความหมาย | สิ่งที่ควรทำต่อ |
|---|---|---|
| 0–8 | **ยังไม่พร้อมรับงานต่อเนื่อง** — ปัญหาอยู่ที่ชั้น 1 เป็นหลัก | แก้ชั้น 1 ก่อน ห้ามคุยเรื่องราคา |
| 9–15 | **ได้งานแต่ไม่ได้งานซ้ำ** — ช่องว่างอยู่ชั้น 2–3 | คือกลุ่มเป้าหมายหลักของ Plan C |
| 16–20 | **ได้งานซ้ำ แต่ราคายังต่ำกว่าที่ควรได้** | เน้นชั้น 3 + เอกสาร/สัญญา |
| 21–24 | **พร้อม "verified"** | เป็นเคสอ้างอิง / เป็นคนพูดแทนในเฟส 3 |

**ตัวเลข before/after ที่ควรเก็บ:** คะแนนวันแรก · คะแนนเดือนที่ 3 · จำนวนดีลที่ได้ซ้ำ · ราคาต่อดีลที่ปิดได้ · สัดส่วน barter — ทั้งหมดนี้คือวัตถุดิบของทั้ง testimonial จริง และฐานข้อมูลตลาดไทยที่ยังไม่มีใครมี

## 🛡️ ขอบเขตที่ห้ามหักคะแนน — มีอำนาจเหนือทุกข้อข้างบน

ถ้าแบรนด์บ่นเรื่องต่อไปนี้ **ห้ามตีเป็นข้อบกพร่อง และ Plan C ต้องยืนข้างครีเอเตอร์**

1. **ปฏิเสธค่าตอบแทนที่ต่ำกว่าเวลาและต้นทุนจริง** — การรู้ต้นทุนตัวเองคือความเป็นมืออาชีพ ไม่ใช่การเรื่องมาก
2. **ปฏิเสธประโยค/สคริปต์ที่ขัดกับสิ่งที่เคยพูดกับคนดูไว้** — นี่คือการรักษาสินทรัพย์เดียวที่เขามี
3. **ขอเวลาผลิตที่สมเหตุสมผล** — งานเร่งเป็นความต้องการของแบรนด์ ไม่ใช่มาตรฐานของอาชีพ
4. **ปฏิเสธการใช้งานเกินขอบเขตที่ตกลง** (เอาไปตัดใหม่ ยิงแอด ใช้เกินระยะเวลา โดยไม่จ่ายเพิ่ม)
5. **ปฏิเสธการทำงานฟรีเพื่อ "ทดลองก่อน"**
6. **ยืนยันให้มีสัญญาเป็นลายลักษณ์อักษร**

> **เส้นแบ่งที่ใช้ตัดสินเสมอ:** *ความเป็นมืออาชีพ* คือการทำตามที่ตกลงไว้อย่างน่าเชื่อถือ · *การยอมง่าย* คือการยอมสิ่งที่ไม่ได้ตกลงไว้ **เกณฑ์ทั้ง 7 ข้อวัดข้อแรก ไม่วัดข้อหลัง**

---

## ⚠️ ที่ต้องทำก่อนเอาไปใช้จริง

- คะแนนแต่ละข้อยังเป็น**ร่าง** — ควรลองให้คะแนนย้อนหลังกับครีเอเตอร์ที่รู้จักอยู่แล้ว 3–5 คน ที่รู้ผลลัพธ์จริงแล้ว เพื่อดูว่าคะแนนสูงสัมพันธ์กับการได้งานซ้ำจริงไหม ถ้าไม่สัมพันธ์ เกณฑ์ผิด ไม่ใช่คนผิด
- น้ำหนักคะแนนยังเท่ากันหมด ซึ่งเกือบแน่ว่าไม่ถูก — ชั้น 3 น่าจะควรถ่วงน้ำหนักมากกว่า แต่ต้องมีข้อมูลก่อนจะถ่วง
- ยังไม่มีข้อที่วัด "การวางตัว/มารยาท" ที่เจ้าของยกมา เพราะเป็นข้อที่**อัตวิสัยสูงและเสี่ยงกลายเป็นการวัดความนอบน้อม** — ต้องหาพฤติกรรมที่สังเกตได้จริงก่อนใส่เข้ามา
