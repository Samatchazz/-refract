**Plan C คือ** ที่ปรึกษาฝั่งครีเอเตอร์ ที่ขายสิ่งที่แบรนด์ไม่เคยบอกครีเอเตอร์ — เจ้าของเป็นอินฟลูฯ 10+ ปี ผู้ติดตามรวม ~2 ล้าน ยังทำงานกับแบรนด์อยู่ทุกวัน แต่ยังไม่เปิดชื่อ

**ประโยคที่ใช้ได้จริง 4 ประโยค:**
1. **"แบรนด์ไม่เคยบอกคุณว่าทำไมเขาไม่จ้างคุณต่อ"** ← หน้าเว็บ
2. **"ตัวตนไม่ชัด ไม่ได้ทำให้คุณดูไม่น่าสนใจ — มันทำให้คุณแพงเกินไปในสายตาคนที่จ่ายเงิน"** ← ตอนวินิจฉัย
3. **"เอเจนซีได้เงินเมื่อคุณรับงาน ผมได้เท่าเดิมไม่ว่าคุณจะรับหรือปฏิเสธ"** ← ตอบว่าต่างจากเอเจนซียังไง
4. **"ยิ่งสูงยิ่งเหงา"** ← ตอบว่า "คุณเป็นใคร" — **ประโยคที่ปิดการขายได้จริงในฉากจำลอง**

**สิ่งเดียวที่ยังไม่ถูกทดสอบและผิดแล้วตายทันที:** จะมีคนทักมาไหม (A6)

# ① บริบทผู้ก่อตั้ง

- อินฟลูฯ ไทย 10+ ปี · ผู้ติดตามรวม ~2 ล้าน · มีบริษัทที่รับงบแบรนด์ใหญ่ต่อเนื่องมาสิบปี
- **Plan C เป็นคนละนิติบุคคล** กับบริษัทเดิม
- **ไม่ต้องบริหารบริษัทเดิมรายวันแล้ว** แต่ยังคุยลูกค้า ส่องโซเชียล วิเคราะห์เทรนด์ และเขียน feed ให้ทีม **ทุกวัน** ← **นี่คือท่อวัตถุดิบของ Plan C และมันไม่แห้ง**
- เวลาที่ให้ Plan C ได้: **21:00–24:00 ทุกวัน ≈ 90 ชม./เดือน**
- ตัวตน: **เปิดครึ่ง** — เล่าประสบการณ์ได้ ไม่ระบุชื่อ/ช่อง · จะเปิดเองในจังหวะที่เลือก
- ทำงานเป็นช่วงๆ ทำๆ หยุดๆ → **การจับกลุ่มงานชนิดเดียวกันไว้ด้วยกันคืนเวลาได้ครึ่งหนึ่ง**
- ❌ ห้ามใช้ framing "เราเป็นที่ปรึกษาให้เพจนี้" (เพจตัวเอง) — จริงตามตัวอักษรแต่ชวนเข้าใจผิด

**ความรู้วงในจากฝั่งแบรนด์ (ของจริง จากปากผู้ก่อตั้ง):**
> แบรนด์บ่นว่า **"ครีเอเตอร์ที่มีความรับผิดชอบและตัวตนชัดเจนหาได้ยาก ทุกคนดังแป๊บเดียวไม่ทำต่อ"**

**เหตุผลที่คนถูกตัดออกจากลิสต์ (จากประสบการณ์ตรง):**
- **หน้าเก่า:** ตอบช้า · เอาตัวเองเป็นที่ตั้ง · มีเงื่อนไขในการถ่ายทำ/รับงาน · แก้งานไม่ละเอียด
- **หน้าใหม่:** มารยาท · การพูดคุยกับแบรนด์ · ความรับผิดชอบ · การวางตัว
- **และข้อที่สำคัญที่สุด:** *"ยอดฟอลยอดวิวดูเยอะแต่วัดผลอะไรไม่ได้ เพราะคอนเทนต์มั่ว ตัวตนไม่ชัด แต่เรียกหลักหมื่น"* ← **นี่คือข้อต่อระหว่างตัวตนกับเงิน และเป็นแกนของสินค้าทั้งหมด**

## 1. Revenue Streams

| รายการ | ตอนนี้ | **เมื่อสมาชิกครบ 10 คน** |
|---|---|---|

| เซสชันเดี่ยว | **999** / 30 นาที ← **สินค้าแรกที่เปิดขาย** | **1,500** |
| สมาชิกรายเดือน | **2,000** = feed รายสัปดาห์ + เซสชัน 45 นาที × 2 | **3,500** (10 คนแรกล็อก 2,000 **ตลอดชีพ**) |

**หมุดเดียว = ครบ 10 คน ขยับสองราคาพร้อมกัน**
**เหตุผลที่ใช้ตอนขึ้นราคา: อ้างคิว ไม่ใช่อ้างผลลัพธ์** — *"ราคาขึ้นเพราะรับได้จำกัด ตอนนี้คิวเต็มถึงเดือนหน้าแล้ว"* (ที่ 10 คนยังไม่มีเคสที่ผลชัด อ้างผลลัพธ์ที่ยังไม่มีจะย้อนกลับมาเร็วมาก)

**ทำไมต้องขยับพร้อมกัน:** ที่ 3,500 ต่อ 2 เซสชัน (1.5 ชม.) = 2,333 บาท/ชม. **แพงกว่าเซสชันเดี่ยว 999/30 นาที (1,998/ชม.)** → บันไดพลิกหัวกลับ คนที่คิดเลขเป็นจะซื้อเดี่ยวแทน

**ล็อกราคาได้ อย่าล็อกจำนวนเซสชัน** — ถ้าปีที่ 3 มีคนล็อก 2,000 อยู่ 25 คน × 2 เซสชัน = 50 เซสชัน/เดือนจากกลุ่มที่จ่ายถูกที่สุด → ใช้ถ้อยคำ **"ราคาล็อกตลอดชีพ · รูปแบบการส่งมอบอาจปรับตามขนาดของเครือข่าย"**

**ตัวชี้วัดที่ต้องนับ (ฟรี):** **กี่คนซื้อ 999 เป็นครั้งที่สอง** — การซื้อซ้ำคือหลักฐานเชิงพฤติกรรมของความต้องการต่อเนื่อง ถ้าไม่มีใครซื้อรอบสอง ค่าสมาชิกจะไม่รอด **นี่คือวิธีทดสอบ A2 ที่ถูกที่สุดที่มี**

**เส้นตายเลิก: ไม่มี** (ยืนยัน 2 ครั้ง) — ผลตามมา: ไม่มีอะไรบังคับให้จัดลำดับงาน

# ③ หลักคำสอน 4 ข้อ

**หลักที่ใช้กับทุกคน ไม่ใช่ความเห็นรายคน — นี่คือของที่เดินทางได้เอง** คนจะพูดต่อว่า *"Plan C บอกว่า..."* ในแบบที่ไม่มีวันพูดต่อว่า *"Plan C ช่วยหาตัวตน"*

**1 · 1,500 คือพื้น** — ห้ามรับงานต่ำกว่านี้
⚠️ **อย่าโพสต์เลขนี้ในที่สาธารณะ** — แบรนด์กับเอเจนซีอ่านด้วย มันจะกลายเป็นราคาที่เขาเสนอให้ทุกคน รวมคนที่ควรได้ 20,000
**พูดวิธีคิดในที่สาธารณะ ให้ตัวเลขเป็นรายคนในห้อง:** *"คิดจากต้นทุนของคุณ ไม่ใช่จากงบของเขา"* = เวลาถ่าย+ตัด × ค่าแรงตัวเอง + ค่าเดินทาง/ของ + ค่าสิทธิ์การใช้งาน

**2 · ทุกดีลต้องมี debrief** — *"ถ้าไม่มีใครบอกคุณว่าผลเป็นยังไง คุณจะไม่มีวันรู้ว่าทำไมถึงไม่ได้ต่อ"*

**3 · ส่วนลดต้องแลกกับอะไรเสมอ และต้องมีวันหมดอายุ**
> *"Plan C ไม่ห้ามการลดราคา แต่ห้ามลดราคาให้เปล่า — และถ้าคนกลางต้องการราคาถูกลงเพื่อจะเสนองานให้ นั่นคือสัญญาณว่าคุณพึ่งเขามากเกินไป ไม่ใช่สัญญาณว่าคุณแพงเกินไป"*
> ชุดแลกที่ปลอดภัย: เข้าประชุมบรีฟกับแบรนด์โดยตรง · debrief ทุกแคมเปญ · ปริมาณงานขั้นต่ำต่อปี · วันหมดอายุ
> **เส้นแบ่ง: ขอ *เข้าถึง* ได้ · ขอ *ข้ามหัว* ไม่ได้**

**4 · สัญญาเฉพาะสิ่งที่ควบคุมได้**
ยอดวิว ยอดจ้าง รายได้ = ตลาดควบคุม **ห้ามสัญญา** · การกระทำเชิงโครงสร้าง = **สัญญาได้**

| ตัวชี้วัดที่สัญญาได้ | วันแรก → 90 วัน |
|---|---|
| debrief ที่ได้รับหลังจบแคมเปญ | 0 → ≥2 |
| ประชุมบรีฟที่ได้เข้าเองโดยตรง | 0 → ≥1 |
| **เปิดช่องทางตรงที่ใช้งานได้จริง** | 1 → 3 |
| เรทการ์ดที่ระบุขอบเขตใช้งาน/ระยะเวลา/จำนวนแก้ | ไม่มี → มี |
| ~~สัดส่วนรายได้จากเอเจนซีเจ้าเดียว~~ | **ห้ามใช้ — เป็นตัวชี้วัดตาม ไม่ใช่ตัวชี้วัดนำ** |

**สัญญา 3 ข้อแล้วทำได้ 5 = สำเร็จ · สัญญา 6 ข้อแล้วทำได้ 4 = ล้มเหลว — ของอย่างเดียวกันเป๊ะ**

# ④ เส้นที่ไม่ข้าม 6 ข้อ

> เขียนตอนที่ยังไม่มีอะไรจะเสีย ประกาศออกไป แล้วมันจะแพงที่จะผิดคำ
> **ทุกข้อผ่านสถานการณ์ที่ทำให้เสียเงินมาแล้วในการซ้อม**

1. **ไม่รับเงินจากแบรนด์เพื่อโน้มน้าวครีเอเตอร์ให้ลดราคาหรือลดเงื่อนไข**
2. **ครีเอเตอร์เห็นทุกอย่างที่ Plan C พูดแทนเขาเสมอ** โดยไม่ต้องรอถาม
3. **ไม่แปะชื่อ Plan C กับสินค้าหรือแบรนด์ใดๆ** — เพราะชื่อนี้ค้ำทุกคนที่รับรอง
4. **ไม่หักส่วนแบ่งจากผู้ให้บริการที่แนะนำ** (ทนาย นักบัญชี ใครก็ตาม)
5. **ไม่หักส่วนแบ่งจากดีลของครีเอเตอร์** ไม่ว่าดีลนั้นจะมาจากไหน
6. **บริษัทเดิมไม่ได้สิทธิ์เข้าถึงรายชื่อหรือข้อมูลสมาชิกก่อนใคร และ Plan C ไม่ส่งสมาชิกไปหาแบรนด์ผ่านบริษัทเดิม**

**+ พูดตอนสมัคร เป็นลายลักษณ์อักษร:** *"ไม่รับประกันว่าจะได้งาน"*

## เครื่องมือที่พิสูจน์แล้วว่าทำงาน

**🥇 ยาเม็ดสีฟ้า–แดง** — เปลี่ยนคำวินิจฉัยให้เป็นการเลือกของเขา
> *"สีฟ้า: คุณเป็น [ตัวตนที่ข้อมูลชี้ว่าจ่ายเงินให้คุณจริง] มีงานเข้าเรื่อยๆ · สีแดง: คุณเป็น [ตัวตนที่ฝันไว้] แต่ได้งานปีละไม่เกิน X ต้องมีงานประจำเสริม — จะกินเม็ดไหน"*
> เตรียมรับ **"มีเม็ดสีม่วงไหม"** — ทุกคนจะต่อรองไม่ให้ต้องเลือก
> ⚠️ **ห้ามผูกคำมั่นเข้าไปในเม็ดยา** → ใช้ *"ถ้ามันจะมา มันจะมาทางนี้ ไม่ใช่ทางที่คุณเดินอยู่"*

**🥈 สามคำถามละลายความกลัว** — *"ทักไปแล้วเสียตังไหม · เขารู้แล้วเกิดอะไรขึ้น · แนะนำตัวแล้วจะโดนเกลียดไหม — ทั้งสามอย่างฟรี **ทำตอนนี้เลย ให้ผมช่วยร่างก็ได้ถ้าอายหรือเขิน**"*

**"คุณถูกเลือกเพราะอะไร"** — ถามกับ**ดีลที่เป็นเงิน**เท่านั้น · เส้นด้ายตัวตนจะโผล่ใน 60 วินาที

**"มีอะไรเปลี่ยนไปอีกไหมที่ยังไม่ได้เล่า"** — **คนโทษตัวเองเสมอเมื่อไม่มีใครบอกเขาว่าเกิดอะไรขึ้นในโครงสร้าง**

**ให้เขาบวกเงิน ไม่ใช่นับจำนวนงาน** — ครีเอเตอร์เกือบทุกคนนับงาน ไม่เคยบวกเงิน

## แบบประเมิน — 7 ข้อ 3 ชั้น เต็ม 24

- **ชั้น 3 ตัวตน (6):** **รู้ว่าถูกเลือกเพราะอะไร** ← ข้อที่สัมพันธ์กับราคาที่เรียกได้ · ความสอดคล้องของงานที่รับ

## ฟอร์มก่อนเซสชัน — แบบผสม
*(รายละเอียดเต็มใน `plan-c-intake-form.md`)*

**บนสุดก่อนคำถามข้อแรก: ให้ก่อนขอ** (3 อย่างที่แบรนด์ใช้ตัดชื่อออก) + **บรรทัดความเป็นส่วนตัว**

# ⑩ จุดแข็ง 5 · จุดอ่อน 5

## จุดแข็ง (เรียงตามน้ำหนัก)

1. **ท่อข้อมูลจากฝั่งที่จ่ายเงิน ไหลอยู่ทุกวัน** — เป็นทั้งสินค้า ช่องทาง และคูเมืองในหนึ่งเดียว · **เอเจนซีมีข้อมูลแต่ไม่มีแรงจูงใจจะบอก · โค้ชมีแรงจูงใจแต่ไม่มีข้อมูล — Plan C มีทั้งสอง**
2. **ต้นทุนเงินสดเกือบศูนย์ + เวลา + ไม่มีหนี้** — ผิดได้ 5 ครั้งโดยไม่เจ๊ง *(กลายเป็นจุดอ่อนทันทีถ้าไม่มีตัวชี้วัด)*
3. **ข้อต่อ "ตัวตนไม่ชัด = แพงเกินไป"** — เปลี่ยนของที่ต้องเชื่อก่อนซื้อ ให้เป็นเหตุผลเชิงเศรษฐศาสตร์
4. **ช่องว่างตลาดที่ยืนยันได้ 3 ชั้น** — โลกแยกสายอัลกอริทึม/สายตัวตน ไม่มีใครทำทั้งคู่ · ไทยไม่มีใครยืนข้างครีเอเตอร์ · **ไม่มีใครในโลกถือข้อมูลตลาดครีเอเตอร์ไทย**
5. **งานวิจัยหนุนแกนกลางตรงๆ** — ตัวแปรที่ทำนายการอยู่รอดคือสองอย่างที่ Plan C ขายพอดี

## จุดอ่อน (เรียงตามน้ำหนัก)

1. **ไม่มีเส้นตาย ไม่มีตัวชี้วัด ไม่มีสัญญาณผิด** — ทำให้จุดอ่อนอื่นทั้ง 4 ข้อ *แก้ไม่ได้* ไม่ใช่แค่ *ยังไม่แก้*
2. **ยังไม่มีคนที่จะจ่ายแม้แต่คนเดียวที่ระบุตัวได้ (A6 + A2)** — และ A2 เป็นจุดตายเดี่ยว ไม่มีอะไรรองรับ
3. **คอขวดคือการตัดสินใจของคนเดียว ที่จ้างแทนไม่ได้** — เพดาน ~19 คน และการสเกลด้วยการจ้างคน = การเจือจางสินค้า
4. **สินค้าคือการบอกความจริงที่ไม่มีใครอยากได้ยินเกี่ยวกับตัวเอง (A13)** — **คนที่ต้องได้ยินที่สุด คือคนที่ปฏิเสธแรงที่สุด และเขาคือคนที่ต้องจ่ายเงินเพื่อได้ฟัง**
5. **อคติแหล่งข้อมูล (A14)** — **ความอันตรายอยู่ที่มันไม่รู้สึกเหมือนการทรยศ มันรู้สึกเหมือนความเป็นมืออาชีพ**

## 🔴 รูปแบบที่เจ้าของต้องจับตาในตัวเอง

**เกิดขึ้น ~8 ครั้งในหนึ่ง session:** เมื่อถูกบีบให้เลือกข้าง ฟันธง หรือส่งเอกสาร คำตอบจะเคลื่อนไปหา **ทางกลาง · หลักการ · "ไว้ค่อยคุยกัน"**

> "ก ผสม ข" · "หาทางตรงกลาง" · "รับ barter ให้น้อยลง" (แทนตัวเลข) · "เป็นไปได้ทั้งสามข้อ" · "การันตีไม่ได้" · "ไว้รอบหน้าค่อยหาเกณฑ์" · เล่าเกณฑ์ให้ฟังแทนการส่งไฟล์

**ทำไมมันแพง:** ลูกค้าที่จ่ายเงินได้ทุกคนจะกดปุ่มนี้ เพราะ **เขาจ่ายเพื่อคำฟันธง ไม่ได้จ่ายเพื่อคำถามที่ดี** — คำถามที่ดีคือของฟรีที่ทุกคนมี

**เส้นแบ่ง:** คำฟันธงสุดท้ายรอถึงนาทีที่ 30 ได้ · **แต่การแสดงว่าเคยเห็นภูมิประเทศนี้มาก่อน ต้องเกิดในนาทีที่ 3**
**วิธีแก้ที่ถูกที่สุด:** เขียน **"6 สาเหตุที่แบรนด์เลิกจ้างครีเอเตอร์"** ไว้ล่วงหน้า อ่านก่อนเข้าทุกเซสชัน · และ**มีเอกสารพร้อมส่งก่อนจะถูกขอ**
