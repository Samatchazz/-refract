# PLAN C — Test Cards (ฉบับเคาะแล้ว)

> สร้าง: สิงหาคม 2026 · ต่อจาก BMC-plan-c-v2.md · **อัปเดตหลังเจ้าของตอบครบ 8 ข้อ (12 ส.ค. 2026)**
> เกณฑ์ทุกตัวในไฟล์นี้เคาะโดยเจ้าของแล้ว `[เจ้าของ]` — เหลือข้อเล็ก 2 จุดท้ายไฟล์
> หลักการเดิมจาก BMC: ของที่ปลดล็อกอย่างอื่นทดสอบก่อน · ของที่ตายทันทีถ้าผิดทดสอบเร็วสุด · ทุกความรู้ใหม่จากนี้มาจากสนามเท่านั้น

## ภาพรวม — อะไรทดสอบได้ อะไรทดสอบไม่ได้

| กลุ่ม | รายการ | วิธีจัดการ |
|---|---|---|
| ทดสอบด้วยการทดลองได้ | A6, A11, A16, A2, A3, A4, A1 | การ์ด 1–7 ข้างล่าง |
| คุมด้วยกติกา ไม่ใช่การทดลอง | A14, A15, A12, A8, A13, A9 | มีมาตรการใน BMC แล้ว — ทบทวนทุกไตรมาสว่ากติกายังถูกใช้จริง |
| ปิด/คลี่คลายแล้ว | A7 (ตัดหักส่วนแบ่ง), A10 (ท่อข้อมูลยังไหล) | ไม่ต้องทำอะไร · A10 มีงานกันเหนียว: สร้างท่อที่สอง (ฐานข้อมูลดีลสมาชิก) |
| เป็นการตัดสินใจ ไม่ใช่สมมติฐาน | A5 (วันเปิดตัวตน) | อยู่ในรายการค้างตัดสินใจอยู่แล้ว — กำหนดวันล่วงหน้า `[เจ้าของ]` |

**ลำดับการยิง:** เตรียมเพจ/โปรไฟล์ → การ์ด 1+2 พร้อมกัน (การทดลองเดียวตอบสองข้อ) → การ์ด 3 (นัดคุยได้ทันที ไม่ต้องรอ) → การ์ด 4 → การ์ด 5 → การ์ด 6, 7 หลังมีสมาชิกจริง

| | |
|---|---|
| **สมมติฐาน** | ช่องทางนิรนามของ Plan C เข้าถึงครีเอเตอร์กลุ่มเป้าหมาย (มีดีลแล้ว ยอดนิ่ง) ได้จริง |
| **ถ้าผิดแล้วเจ็บแค่ไหน** | ตายทันที — ทุกอย่างที่เหลือไม่มีความหมายถ้าไม่มีใครเดินเข้ามา |
| **เมื่อไหร่เริ่ม** | `[เจ้าของ]` **หลังเตรียมเพจ/โปรไฟล์ Plan C ให้ดูน่าเชื่อก่อน** — กันคนกด DM มาแล้วเจอเพจว่างเปล่า → งานที่มาก่อนการ์ดนี้: เพจพร้อม (โยงกับ Data Block 3 ก้อนที่ค้างเลือกอยู่) |
| **การทดลอง** | ตอบคอมเมนต์คนที่เจ็บเรื่องเงิน 3 อัน ภายใน 2 สัปดาห์ `[เจ้าของ]` |
| **ตัววัด** | จำนวน DM ที่มาจากคนที่ **มีดีลแล้ว** (ไม่นับมือใหม่ที่ยังไม่เคยรับงาน) |
| **เกณฑ์** | DM = 0 → **A6 พัง หยุดทุกอย่าง รื้อช่องทางก่อน** `[เจ้าของ]` · DM ≥ 1 = ผ่านขั้นต่ำ ไปต่อได้ |
| **ต้นทุน** | ~0 บาท · เวลา 2 สัปดาห์ |
| **บันทึกผล** | วันที่โพสต์ · โพสต์ไหน · DM กี่อัน · กี่อันมีดีลแล้ว · คำที่เขาใช้ทักมา (เก็บ verbatim — เป็นวัตถุดิบ copy ฟรี) |

## การ์ด 2 — A11: มีคนยอมคุยกับคนที่ไม่เปิดชื่อ 🔴

| | |
|---|---|
| **สมมติฐาน** | ครีเอเตอร์ยอมเปิดข้อมูลจริง (เรท/ยอด/ดีล) กับที่ปรึกษานิรนาม |
| **ถ้าผิดแล้วเจ็บแค่ไหน** | ตายทันที — โมเดลนิรนามคือเงื่อนไขตั้งต้นของธุรกิจ |
| **การทดลอง** | ขี่ไปกับการ์ด 1 — นับต่อจาก DM: กี่คนยอมคุยจริง กี่คนถามว่า "คุณเป็นใคร" แล้วหายไป `[เจ้าของ]` |
| **ตัววัด** | อัตรา DM → ยอมคุยลึก (เล่าตัวเลขจริงของตัวเอง) |
| **เกณฑ์** | `[เจ้าของ]` **อย่างน้อย 1 ใน 3 ของคนที่ DM มา ยอมคุยถึงขั้นเล่าตัวเลขจริง** · ถ้าทุกคนหายตอนรู้ว่าไม่เปิดชื่อ = ต้องสร้าง "หลักฐานความน่าเชื่อแบบไม่เปิดหน้า" ก่อน (แบบ Doomberg: ให้ผลงานพูดแทนชื่อ) |
| **ต้นทุน** | 0 บาท — ใช้ข้อมูลจากการ์ด 1 |
| **บันทึกผล** | คำถามแรกที่แต่ละคนถาม (คนแรกๆ จะบอกเลยว่าตลาดทดสอบเราด้วยอะไร — ฉากบอสทำนายไว้ว่า "คนที่จ่ายได้จะทดสอบคุณก่อน") |

## การ์ด 3 — A16: เอเจนซีคัดคนผ่านเครื่องมือจริง

| | |
|---|---|
| **สมมติฐาน** | เอเจนซีไทยใช้เครื่องมือ (Wisesight/Tellscore) คัดคนจริง — และชั้นถัดไปคือ human layer (ความคุ้นเคย/เรตที่เคยคุย/ตัวเก็งของแบรนด์) ตามคำตอบ Q12 |
| **ถ้าผิดแล้วเจ็บแค่ไหน** | เจ็บปานกลาง — ถ้าจริงๆ ทุกอย่างอยู่ที่ความสัมพันธ์ล้วนๆ แกนเซสชัน "ทำโปรไฟล์ให้อ่านออกใน 30 วินาที" ต้องปรับน้ำหนัก |
| **การทดลอง** | F4 เดิม — คุยกับ อจซ/ลูกค้าที่สนิท ถาม 4 ข้อที่เขียนไว้ใน BMC v2 (ลิสต์กี่ชื่อเหลือกี่ชื่อใครเคาะ · คำจริงตอนปัดชื่อทิ้ง · ใช้เครื่องมืออะไรหาคน · "ตัวตนชัด" ดูจากอะไรตอนยังไม่เคยร่วมงาน) `[เจ้าของ]` |
| **ตัววัด** | `[เจ้าของ]` **คุยกับคนสนิท 2 คน — ความลึกสำคัญกว่าจำนวน คนสนิทตอบตรงกว่า** |

## การ์ด 4 — A2: ครีเอเตอร์ไทยจ่าย 999/2,000 ไหว 🔴

| | |
|---|---|
| **สมมติฐาน** | กลุ่มเป้าหมายยอมจ่าย 999 (และต่อเนื่อง 2,000) — **ไม่มีข้อมูล WTP ที่ไหนในโลก นี่คือการวัดครั้งแรก ไม่ใช่การยืนยัน** |
| **ถ้าผิดแล้วเจ็บแค่ไหน** | ตายทันที (ช้ากว่า A6) — โมเดลรายได้ทั้งหมดตั้งอยู่บนตัวเลขนี้ |
| **การทดลอง** | เสนอ 999 กับคนที่ผ่านเซสชันฟรี `[เจ้าของ]` — เงินจริง ไม่ใช่แบบสอบถาม |
| **ตัววัด** | **การซื้อครั้งที่สอง** ไม่ใช่ครั้งแรก `[เจ้าของ]` (ครั้งแรกอาจซื้อเพราะเกรงใจ/อยากลอง — ครั้งที่สองคือของจริง) |
| **เกณฑ์** | 2 ใน 10 ของคนที่ผ่านเซสชันฟรีแล้วซื้อซ้ำ = สัญญาณไปต่อ `[เจ้าของ]` |
| **ราคา 599** | `[เจ้าของ]` **เก็บไว้เป็นไพ่สำรอง — ยังไม่เปิด** จะเปิดก็ต่อเมื่อ 999 เงียบเกินจำนวนคนแรกที่กำหนด *(ยังไม่เคาะจำนวน — ดูข้อเปิดท้ายไฟล์)* |
| **ต้นทุน** | เวลาเซสชันฟรี ~10 ชม. · ระวังต้นทุนแฝง: เพดานคุณคือ ~19 คน/เดือน |

## การ์ด 5 — A3: รูปแบบไหนเปลี่ยนพฤติกรรม/รักษาสมาชิกได้จริง

| | |
|---|---|
| **สมมติฐาน** | เซสชันเดียวไม่พอ — โมเดลรายเดือน + การตามดูต่อเนื่อง จึงรักษาสมาชิกได้ (งานวิจัย churn: มี community touch = 6.06% vs ไม่มี = 10.46%) |
| **ถ้าผิดแล้วเจ็บแค่ไหน** | เจ็บหนัก — churn 6.8%/เดือน = อายุสมาชิกเฉลี่ย ~12 เดือน ถ้าแย่กว่านั้นเพดานรายได้หดทันที |
| **การทดลอง** | `[เจ้าของ]` **เช็คอินสั้นกลางเดือนให้สมาชิกทุกคน — ไม่แบ่งกลุ่ม** วัดเทียบ benchmark ตลาด (churn 6.8%/เดือน) แทนการเทียบกลุ่ม |
| **ตัววัด** | อัตราต่ออายุเดือนที่ 2 และ 3 (หน้าผาอยู่เดือน 1–3: 61.7%→53.4% แล้วค่อยนิ่ง 77%+) |
| **เกณฑ์** | `[เจ้าของ]` **ต่ออายุเดือนที่ 2 ≥ 50% = รับได้ในรุ่นแรก** (รุ่นแรกคือช่วงลองผิดลองถูก ไม่ตัดสินแรง) *(เส้น "ต่ำกว่าเท่าไหร่ = รื้อ" ยังไม่เคาะ — ดูข้อเปิดท้ายไฟล์)* |
| **ต้นทุน** | เวลาเช็คอิน ~15 นาที/คน/เดือน · เต็มเพดาน 19 คน ≈ 5 ชม./เดือน |

## การ์ด 6 — A4: การบ้านบังคับกรองคนแบบไหนออก

| | |
|---|---|
| **สมมติฐาน** | การบ้านบังคับก่อนเซสชัน = ตัวกรองคนจริงจัง |
| **จุดยืนที่เคาะ** | `[เจ้าของ]` **ไม่มีเพดาน — การบ้านคือตัวกรอง ใครหายคือไม่ใช่ลูกค้า** ยืนกติกาเดิมเต็มๆ |
| **สิ่งที่ยังเก็บ** | ยังบันทึกอัตราส่งการบ้านไว้เป็นข้อมูลเฉยๆ (ไม่มี trigger อัตโนมัติ) — ถ้าวันหนึ่งอยากทบทวนเอง ข้อมูลจะมีพร้อม · ทางแก้ที่เตรียมไว้แล้วถ้าเปลี่ยนใจ: แยกการบ้าน 2 ระดับ (ของกึ่งสาธารณะถามก่อน · ตัวเลขอ่อนไหวถามในห้อง) |
| **ต้นทุน** | 0 — เก็บ data ไปพร้อมการทำงานปกติ |

## การ์ด 7 — A1: แบรนด์จะจ่ายเพื่อ verified/benchmark (เฟส 3)

## บันทึกการเคาะ (12 ส.ค. 2026) `[เจ้าของ]`

| ข้อ | คำตอบ |
|---|---|
| 1. เริ่มยิงนัดแรก | หลังเตรียมเพจ/โปรไฟล์ให้ดูน่าเชื่อก่อน |
| 2. เกณฑ์นิรนามไปรอด | 1 ใน 3 ของคนที่ทักมา ยอมคุยลึก |
| 3. ถามกี่คน (A16) | 2 คนสนิทพอ |
| 4. ราคา 599 | เก็บไว้เป็นไพ่สำรอง ยังไม่เปิด |
| 5. เช็คอินระหว่างเดือน | มีทุกคน |
| 6. เส้นต่ออายุเดือน 2 | ≥ 50% รับได้ในรุ่นแรก |
| 7. เพดานคนหายตอนเจอการบ้าน | ไม่มีเพดาน — การบ้านคือตัวกรอง |
| 8. เกณฑ์เริ่มคิดเฟส 3 | 15 ดีล |

## ข้อเล็กที่ยังเปิดอยู่ (ไม่รีบ — เคาะตอนใกล้ใช้ก็ทัน)

1. **ไพ่สำรอง 599:** "999 เงียบเกิน ___ คนแรก" ถึงหยิบไพ่ — ตัวเลขช่องว่างยังไม่เคาะ (เคาะตอนเริ่มเสนอ 999 จริงก็ทัน)
2. **เส้นรื้อของการ์ด 5:** ≥50% = รับได้ แต่ต่ำกว่าเท่าไหร่ = "รื้อรูปแบบเซสชัน ไม่ใช่แค่ปรับ" ยังไม่ได้กำหนด (เคาะตอนมีสมาชิกรุ่นแรกก็ทัน)

**งานที่โผล่มาใหม่จากการเคาะข้อ 1:** "เตรียมเพจ/โปรไฟล์ให้ดูน่าเชื่อ" กลายเป็นด่านแรกสุดของทุกอย่าง — ซึ่งวนกลับไปหางานที่ค้างอยู่พอดี: เลือก Data Block 3 จาก 5 ก้อน (ร่างอยู่ใน PLAN-C-หลังคำตอบ-และก้าวต่อไป.md)
