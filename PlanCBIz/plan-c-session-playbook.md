# Plan C — คู่มือเซสชัน (จากการจำลอง 5 ฉาก)

> ตัวละครที่ซ้อมด้วย:
> **โบว์** 41k ฟอล · barter เกือบทั้งหมด · เงินเก็บเหลือ 4 เดือน · **จ่ายไม่ได้**
> **บอส** 80k ฟอล · 27 ดีลเป็นเงิน/ปี · **ซื้อรายเดือนเอง** → ฉาก 3 (เดือนที่ 3 ตัวเลขไม่ขยับ) → ฉาก 5 (เดือนที่ 8 เงียบหาย)
> **เจ** 480k ฟอล · มีแบรนด์ตัวเอง ยอด 800k/เดือน · **จ่ายรายปีล่วงหน้าได้ แต่โจทย์ที่เอามาใช้ไม่ได้**

# ผลลัพธ์สองฉาก และสาเหตุ

| | โบว์ | บอส |
|---|---|---|

> ถ้าเซสชันจบด้วย A อย่างเดียว ลูกค้าไม่รู้ด้วยซ้ำว่ามีอะไรให้ซื้อ

# โครงเซสชันฟรี 30–45 นาที

**เงื่อนไข:** 1 ครั้งต่อคน ห้ามซ้ำ · ต้องส่งการบ้านก่อน · เซสชันถัดไปเสียเงิน

| นาที | ทำอะไร |
|---|---|
| 0–3 | **เปิดด้วยสมมติฐาน ไม่ใช่คำถามเปิด** — ห้ามถาม "อยากเริ่มเรื่องไหนดี" เพราะเขาบอกเองว่าไม่รู้ว่าปัญหาตัวเองคืออะไร นั่นคือเหตุผลที่เขามา · **กางแผนที่ก่อนเดิน**: "สาเหตุที่เจอบ่อยมี X แบบ ผมสงสัยข้อ 2 กับ 5 ขอถามเพื่อยืนยัน" |
| 3–12 | เจาะ**เหตุการณ์จริงหนึ่งเรื่อง** (ดีลล่าสุดที่ไม่คุ้ม / ครั้งที่ไม่ถูกเรียกกลับ) — ตัวเลขที่อ่อนไหวจะไหลออกมาเองตรงนี้ ดีกว่าให้กรอกฟอร์ม |
| 12–22 | **บอกสิ่งที่แบรนด์เห็นแต่ไม่เคยบอกเขา** (ส่งมอบ B) + **ให้เขาให้คะแนนตัวเองตามเกณฑ์ 6 ข้อ** ← สะพานจาก A ไป B ถ้าไม่มีตรงนี้ เขาจะไม่รู้ว่ามีอะไรให้ซื้อ |
| 22–35 | **ยาเม็ดสีฟ้า–แดง** (ดูด้านล่าง) → เขาเลือกเอง → **เขาเขียนกฎ + ตัวเลข + วันที่ ด้วยมือตัวเอง** |
| 35–40 | **ให้เขาลงมือทำหนึ่งอย่างในห้องเลย** ← ตัวทำนายการเปลี่ยนพฤติกรรมที่แข็งที่สุดที่มี · บอกตรงๆ ว่าเขาอยู่กลุ่มไหน และมีอะไรต่อ |

# เครื่องมือที่พิสูจน์แล้วว่าทำงาน

## 1. ยาเม็ดสีฟ้า–สีแดง 🥇 การเคลื่อนไหวที่ดีที่สุดในทั้งสามฉาก

เปลี่ยน **คำวินิจฉัย** ให้กลายเป็น **การเลือกของเขา**

> *"ถ้ามียาสองเม็ด — สีฟ้า: คุณกลายเป็น [ตัวตนที่ข้อมูลชี้ว่าจ่ายเงินให้คุณจริง] มีงานเข้าเรื่อยๆ ทำอาชีพนี้ต่อได้ · สีแดง: คุณได้เป็น [ตัวตนที่คุณฝันไว้] ตัวตนแน่นมาก แต่ได้งานปีละไม่เกิน X ต้องกลับไปทำงานประจำเสริม — จะกินเม็ดไหน"*

**ทำไมมันทำงาน:** เขาไม่ต้องป้องกันตัว (ไม่มีใครตัดสินเขา) · ตรงกับจุดยืน "ทำให้คุณเป็นตัวเอง" เป๊ะ · และ**สิ่งที่เขาพูดหลังเลือก คือของจริง** — ในฉากโบว์ แรงต้านไม่ใช่เรื่องเงิน แต่คือ **สถานะในสายตาเพื่อนร่วมวงการ** ซึ่งไม่มีทางโผล่มาจากแบบสอบถาม

**เตรียมรับ "มีเม็ดสีม่วงไหม"** — ทุกคนจะต่อรองไม่ให้ต้องเลือก งานคือไม่ยอมให้มีเม็ดสีม่วง แต่รีเฟรมได้: *"สีม่วงจะทำให้ไม่ได้ทั้งสองสี — แต่ถ้าตั้งใจจริง เราเปลี่ยนสีฟ้าให้เป็นสีม่วงได้ ความสำเร็จอยู่ที่เส้นทางที่ใช้ไป"*
**⚠️ ห้ามผูกคำมั่นเข้าไปในเม็ดยา** — "โอมากาเสะต้องมา ทริปต่างประเทศต้องมี" คือการขายความหวัง · เวอร์ชันที่จริงและแรงเท่ากัน: **"ถ้ามันจะมา มันจะมาทางนี้ ไม่ใช่ทางที่คุณเดินอยู่"**

## 2. สามคำถามละลายความกลัว 🥈

ใช้กับคนที่มีโอกาสกองอยู่ตรงหน้าแต่ไม่กล้าแตะ:

> *"ทักไปแล้วเสียตังไหม · เขารู้แล้วเกิดอะไรขึ้น · แนะนำตัวแล้วจะโดนเกลียดไหม*
> *ทั้งสามอย่างฟรีนะครับ **ทำได้เลย ทำตอนนี้ ทำระหว่างคุยกับผมก็ได้ ให้ผมช่วยร่างก็ได้ถ้าอายหรือเขิน**"*

**สองอย่างเกิดพร้อมกัน:** เอาการกระทำเข้ามาไว้ในห้องแทนที่จะฝากเป็นการบ้าน · และเรียกอารมณ์ออกมาโดยไม่ประจาน ("ถ้าอายหรือเขิน") ทำให้เขาไม่ต้องแกล้งกล้า
**⚠️ ก่อนใช้กับเรื่องเอเจนซี: ตรวจสัญญาก่อนว่ามีข้อผูกขาดไหม** — ความกล้าที่ตรวจเอกสารมาแล้ว กับความกล้าเปล่าๆ ต่างกันตรงนี้ และนี่คือจุดที่สินค้า B โผล่มาเองโดยไม่ต้องขาย

## 3. "คุณถูกเลือกเพราะอะไร" — ใช้กับดีลที่**เป็นเงิน**เท่านั้น

ในฉากโบว์ คำถามนี้ทำให้เธอส่งเส้นด้ายตัวตนมาให้ใน 60 วินาที: **3 ใน 4 ดีลที่เป็นเงิน เป็นร้านที่ต้องการลูกค้าครอบครัว** และเธอเลิกทำคอนเทนต์แนวนั้นเพราะยอดไม่ดี → **เก็บเงินได้จากตัวตนหนึ่ง แต่ไล่ยอดวิวจากอีกตัวตน**

## 4. "มีอะไรเปลี่ยนไปอีกไหมที่ยังไม่ได้เล่า"

ในฉากที่ 3 คำถามนี้พลิกทั้งฉากใน 30 วินาที — เรื่องที่ลูกค้าเล่าตอนเปิด ("ผมขอเยอะเลยโดนลดงาน") เป็นเรื่องที่เขาแต่งขึ้นเอง ความจริงคือเอเจนซีเสียลูกค้าไปทั้งเจ้า ครีเอเตอร์ทุกคนงานน้อยลงเหมือนกัน
**คนโทษตัวเองเสมอ เมื่อไม่มีใครบอกเขาว่าเกิดอะไรขึ้นในโครงสร้าง** — และนั่นคือสินค้าของ Plan C

## 5. ให้เขาบวกเงิน ไม่ใช่นับจำนวนงาน

บอสนอนไม่หลับสองอาทิตย์เพราะ "7 ดีลเหลือ 5" — พอบวกจริง รายได้ต่างกัน 2,500 บาท (2.6%)
**ครีเอเตอร์เกือบทุกคนนับจำนวนงาน ไม่เคยบวกเงิน** — การให้เขาบวกครั้งแรกในชีวิตคือของที่จำไปตลอด และมันฟรี

# ข้อผิดพลาดที่เกิดขึ้นจริงในการซ้อม (อย่าทำซ้ำ)

| ผิดพลาด | ผลที่ตามมา | แก้ยังไง |

| เปิดด้วย "อยากเริ่มเรื่องไหนดีครับ" | ยกพวงมาลัยให้คนที่มองไม่เห็นถนน · เขาเลือกหัวข้อที่ปลอดภัยและผิดที่สุด (ยอดวิว) และไม่พูดเรื่องเงินเลย | เปิดด้วยสมมติฐาน |
| ถาม "ทำแบบสอบถามมาแล้วใช่ไหม" | เขาไม่แน่ใจว่าคุณอ่านหรือยัง เลยเล่าซ้ำสิ่งที่คุณรู้แล้ว | แสดงว่าอ่านแล้วด้วยการอ้างรายละเอียดในฟอร์ม |
| ตอบว่า "เป็นไปได้ทั้งสามข้อ" | = รูปแบบหมอดู (เขาให้ข้อมูล คุณทวนกลับ) ไม่มีข้อมูลใหม่ไหลไปหาเขาเลย · ลูกค้าถอนข้อเสนอที่จะเปิดเผยทุกอย่าง | **บอกก่อน แล้วค่อยถามเพื่อชี้ชัด** |
| "เราไม่พูดเรื่องตัวเลขก็ได้" | ยกวัตถุดิบทั้งหมดทิ้งในนาทีแรก · เขาไม่ได้กลัวบอกตัวเลข เขากลัวไม่รู้ว่าตัวเลขจะไปไหน | **"ข้อมูลนี้ไม่ถูกส่งต่อให้แบรนด์ และไม่ถูกใช้ประกอบการเลือกใครไปเสนองาน"** |
| "อยากเอาความรู้มาใช้ประโยชน์" | คนขี้สงสัยสงสัยหนักขึ้น — ไม่มีใครทำงานฟรีให้คนแปลกหน้าโดยไม่มีเหตุผล | **ประกาศผลประโยชน์ตรงๆ:** *"ผมกำลังสร้างบริการนี้ และผมต้องการเคสจริง 24 เคสก่อนเริ่มเก็บเงิน คุณคือหนึ่งในนั้น"* |
| "ไม่แฟร์กับท่านอื่น" (เหตุผลไม่เปิดตัว) | ไม่ได้อธิบายอะไร คนคิดเป็นสะดุดทันที | เหตุผลจริงที่ฟังไม่สวย น่าเชื่อกว่าเหตุผลสวยที่อธิบายไม่ได้ |
| แนะนำให้ลดราคา 15% ให้เอเจนซี | **ลูกค้าเสีย 15,150 บาทในไตรมาสเดียว โดยไม่ได้อะไรกลับ** · ถ้าไม่มีส่วนลดนี้ เขาโตขึ้น ~9,600 ในไตรมาสที่ตลาดหด | หลักคำสอนข้อ 3 |
| ไม่รับผิดเรื่องคำแนะนำที่ผิด (ข้ามไป 4 ครั้ง) | ลูกค้าเปิดช่องให้ 3 ครั้ง · **มันจะกลายเป็นสิ่งที่เขาเล่าให้คนอื่นฟังเวลามีคนถามถึงคุณ** | *"ส่วนลดคือคำแนะนำผมและมันผิด — ผมสับสนระหว่างการสร้างความสัมพันธ์กับการซื้อความสัมพันธ์ ความสัมพันธ์ที่ดีขึ้นมาจากมื้อข้าว 1,800 ไม่ใช่ส่วนลด 15,150"* |
| ตอบ "การันตีอะไรไม่ได้" ตอนลูกค้าขอ**เป้า** | เขาไม่ได้ขอการันตี เขาขอตัวเลขที่นับได้ · ถามซ้ำ 2 รอบ | ให้**ตัวชี้วัดนำ** (หลักคำสอนข้อ 4) |

# รูปแบบที่ต้องจับตาในตัวเอง

**เกิดขึ้น 7 ครั้งในหนึ่ง session:** เมื่อถูกบีบให้เลือกข้างหรือฟันธง คำตอบจะเคลื่อนไปหาทางกลางหรือความเป็นนามธรรม

> "ก ผสม ข" · "หาทางตรงกลาง" · "ให้พอทำได้ 3 โพสต์" · "รับ barter ให้น้อยลง" (แทนที่จะเป็นตัวเลข) · "เป็นไปได้ทั้งสามข้อ" · "การันตีไม่ได้" · "ถูกและผิด"

**ทำไมมันแพง:** ลูกค้าที่จ่ายเงินได้ทุกคนจะกดปุ่มนี้ เพราะ**เขาจ่ายเพื่อคำฟันธง ไม่ได้จ่ายเพื่อคำถามที่ดี** — คำถามที่ดีคือของฟรีที่ทุกคนมี

**เส้นแบ่งที่ถูกต้อง:**
- **คำฟันธงสุดท้าย** → รอถึงนาทีที่ 30 ถูกแล้ว ไม่ต้องรีบ
- **การแสดงว่าเคยเห็นภูมิประเทศนี้มาก่อน** → **ต้องเกิดในนาทีที่ 3** และไม่ใช่การฟันธง มันคือการกางแผนที่

**วิธีแก้ที่ถูกที่สุด:** เขียน **"6 สาเหตุที่แบรนด์เลิกจ้างครีเอเตอร์"** ไว้ล่วงหน้า อ่านก่อนเข้าทุกเซสชัน — ใช้เวลาทำหนึ่งชั่วโมง แก้ปัญหาไปตลอด

*(รายการตั้งต้นจากที่คุยกัน: งบถูกจัดใหม่/เปลี่ยนเอเจนซีหลัก · คนที่ดูแลในแบรนด์ลาออก · แบรนด์เปลี่ยนไปใช้นาโนหลายคนแทนคนเดียว · เปลี่ยนตัวชี้วัดจาก reach เป็น conversion · คนดูของครีเอเตอร์เลื่อนออกจากกลุ่มเป้าหมาย · เรทข้ามเพดานของ tier)*

# ตัวอย่างคำวินิจฉัยระดับ "ขนลุก" (จากฉากบอส)

ข้อมูลที่มี: คอนเทนต์เปลี่ยนไปสายพ่อลูกอ่อน · คนที่ดูแลที่เอเจนซีลาออก · ปรับเรทขึ้น 30% · เอเจนซีเจ้าเดียวถือทั้งสองแบรนด์ · ไม่เคยเจอคนใหม่ตัวจริง

> *"ทั้งสามข้อไม่ใช่สามเหตุผลครับ มันคือเหตุผลเดียวที่เดินมาบรรจบกัน*
>
> *คุณเปลี่ยนคอนเทนต์ → คนดูคุณเปลี่ยนจากคนซื้อ gadget เป็นพ่อแม่ลูกอ่อน ซึ่งดีสำหรับยอด แต่แบรนด์สองเจ้านั้นซื้อคุณเพราะคนดูชุดเก่า ตอนนี้คุณยังคนเดิม แต่คนดูคุณไม่ใช่ลูกค้าเขาแล้ว*
>
> *ปกติเรื่องแบบนี้มีคนในแบรนด์อธิบายให้ที่ประชุมฟังได้ว่า 'ไม่เป็นไร เดี๋ยวมันกลับมา' — คนคนนั้นคือพี่ที่ลาออกไป เขาไม่ได้แค่ดูแลคุณ เขาคือคนที่พูดแทนคุณในห้องที่คุณไม่ได้อยู่ พอเขาไป ความสัมพันธ์สามปีของคุณกลายเป็นแถวหนึ่งในตาราง*
>
> *แล้วเรทใหม่ +30% ก็ไปวางบนโต๊ะของคนใหม่ที่ไม่เคยเจอคุณ เห็นแค่ว่าปีนี้แพงขึ้น 30% และตรงบรีฟน้อยลง เขาไม่ได้เกลียดคุณ เขาแค่ไม่มีเหตุผลจะสู้เพื่อคุณ*
>
> *คุณไม่ได้ถูกตัดเพราะข้อใดข้อหนึ่ง คุณถูกตัดเพราะทั้งสามมาถึงโต๊ะเดียวกันในไตรมาสเดียวกัน โดยไม่มีใครในห้องนั้นพูดแทนคุณ"*

**ไม่มีชื่อแบรนด์ ไม่มีตัวเลขดีล ไม่ผิด NDA — เป็นรูปแบบล้วนๆ** และมันขายไปในตัวโดยไม่ต้องขาย เพราะข้อสรุปคือ *"คุณไม่มีใครพูดแทนคุณในห้องนั้น"* ซึ่งคือสิ่งที่ Plan C ขายพอดี

# ฉากที่ 4 — คนที่จ่ายได้สบาย แต่โจทย์ใช้ไม่ได้

**เจ:** ขอให้ช่วยสร้างภาพลักษณ์ "โค้ชเจ" ให้ทันก่อนเปิดตัวอาหารเสริมลดน้ำหนักตัวใหม่ที่ **อย. ยังไม่ออก** · มีประวัติร้องเรียนโฆษณาเกินจริงเมื่อปีก่อน · จะเปิดพรีออเดอร์เอาเงินลูกค้าไปจ่ายค่าผลิต · เสนอจ่าย 24,000 รายปีทันที + โปรโมทให้ในกลุ่มแม่ค้าออนไลน์เป็นร้อยคน

## บทเรียนหลัก

> ## **ไม่ได้ต้องปฏิเสธเงิน ต้องปฏิเสธโจทย์ — พอโจทย์เปลี่ยน เงินก้อนเดิมก็รับได้อย่างสบายใจ**
> ปฏิเสธคนทิ้งไปเลย = เสียทั้งเงินและเสียโอกาสเปลี่ยนอะไรจริงๆ
> รับโจทย์เดิม = ได้เงินแล้วเสียชื่อในอีกหกเดือน
> **ทางที่สาม: รับคน ปฏิเสธโจทย์**

## เครื่องมือ: "ทำไมอยากเป็น X ทำไมไม่อยากเป็น Y" 🥇

> *"ทำไมอยากเป็นโค้ชเจ ทำไมไม่อยากเป็นเจ้เจครีมคุณภาพ หรือพี่เจบูสความสวย"*

- **ตีกรอบใหม่โดยไม่ปฏิเสธตัวคน** ไม่ต้องบอกว่าเธอผิด ไม่ต้องพูดถึง อย. ตรงๆ ด้วยซ้ำ
- พาไปเจอของจริงที่ไม่เคยพูดกับใคร: **เธอกลัวทุกครั้งที่ต้องตอบคำถามสุขภาพในอินบ็อกซ์** → คำว่า "โค้ช" ไม่ได้ให้อำนาจ มันให้ **ความรับผิดชอบที่เธอแบกไม่ไหว**ทุกวัน
- แรงต้านคือ **สถานะ** (เหมือนโบว์เป๊ะ) — "แม่ค้า" ฟังดูต่ำ "โค้ช" ได้รับเชิญไปพูด

## ของแถมที่ทรงพลังที่สุด: ตัวตนที่จริงเปลี่ยนภาระให้เป็นคอนเทนต์

พอตัวตนคือ **"คนที่หมกมุ่นกับคุณภาพสินค้า"** → **การรอ อย. ไม่ใช่ความเสียหายอีกต่อไป มันคือคอนเทนต์ที่ดีที่สุดที่เธอมี**
และเธอพูดเอง: *"ไม่มีใครในวงการกล้าเล่า เพราะทุกคนมีอะไรต้องปิด"* — ความได้เปรียบที่คู่แข่งลอกไม่ได้ เพราะลอกแล้วต้องซื่อสัตย์ตาม

## 🛡️ ข้อเสนอที่อันตรายที่สุด มาในวันที่ลูกค้าตัดสินใจถูกต้องที่สุด

หลังเธอยอมเลื่อนเปิดตัวและยอมเสียมัดจำ KOL เธอขอ **"แปะชื่อ Plan C เป็นที่ปรึกษาบนเว็บและเพจ"** ฟรี พร้อมคนตาม 4 แสน

**→ ต้องเป็นข้อหนึ่งใน "เส้นที่ไม่ข้าม":**
> **"Plan C ไม่แปะชื่อกับสินค้าหรือแบรนด์ใดๆ เป็นนโยบาย เพราะชื่อผมค้ำทุกคนที่ผมรับรอง"**

ความเสี่ยงไม่ได้อยู่ที่วันนี้ **มันอยู่ที่สิ่งที่ลูกค้าจะทำในวันที่คุณไม่ได้อยู่ในห้อง**
*(เหตุผลเพื่อประโยชน์ลูกค้า — "คู่แข่งจะแซะว่าคุณไม่ได้คิดเอง" — ใช้ได้และจริง แต่เหตุผลของตัวเองแข็งกว่า และทำให้เขารู้ว่าคุณจะปกป้องเขาด้วยมาตรฐานเดียวกัน)*

## ⚠️ เส้นที่เกือบข้าม

**"หาหมอมารองรับ ไม่ยากหรอกครับ"** — **หมอที่ร่วมพัฒนาสูตร ≠ หมอที่มารับรองสินค้าที่ทำเสร็จแล้ว**
อย่างแรกคือคุณภาพจริง อย่างหลังคือการยืมความน่าเชื่อถือแบบเดียวกับคำว่า "โค้ช" แค่ใส่เสื้อกาวน์ — และไม่ใช่ของที่สัญญาแทนลูกค้าได้

## 🚩 สัญญาณที่ควรคัดตั้งแต่ฟอร์ม

รายได้หลักไม่ได้มาจากงานจ้างแบรนด์ แต่มาจาก **สินค้าของตัวเองที่กินหรือทาผิว** + ยังไม่มีใบอนุญาต + มีประวัติร้องเรียน → **โจทย์ที่เขาจะเอามาคือการสร้างความน่าเชื่อถือให้ทันก่อนเปิดตัว** ซึ่งเป็นโจทย์ที่ต้องปฏิเสธเสมอ

# 🧑‍⚖️ ทนาย/นักบัญชี — กฎการใช้ (ล็อกไว้ก่อนเคสแรก)

3. **ต้องมีอย่างน้อย 2 ราย ให้ลูกค้าเลือกเอง** — ทนายของบริษัทเดิมทำงานกับแบรนด์ ถ้านายจ้าง/คู่กรณีของสมาชิกเป็นลูกค้าบริษัทเดิม นั่นคือความขัดแย้งจริง
4. **ราคาต้องเป็นราคาจริง ไม่ใช่ค่าน้ำใจ** — 1,500–2,000 สำหรับงานด่วนวันศุกร์บ่ายคือการช่วยเหลือส่วนตัว ใช้ได้กับเคสแรกๆ แต่ถ้าจะเป็นของที่สมาชิกทุกคนใช้ ต้องเป็นราคาที่ทนายอยากรับ ไม่งั้นมันพังเงียบๆ ตอนเคสที่ 5

> *"หนูไม่ต้องการให้มันสมบูรณ์ หนูต้องการแค่ให้มันมีอยู่จริง"*

**และเรื่องที่ประชุมไม่ได้ตัดสินเรื่องคนที่ทำพัง — มันตัดสินว่าใครจะเป็นประตู** ต่อไปจะรับครีเอเตอร์จาก Plan C ตรงๆ ได้อีกไหม

## ท่าที่ได้ผลในฉากนี้

| ท่า | ทำไมได้ผล |
|---|---|
| **แยกผลงานออกจากตัวเลข** — "ถ้าตัดเรื่องฟอลออก ทีมชอบผลงานไหม" | ได้คำยืนยันเรื่องผลลัพธ์บันทึกไว้ก่อน แล้วค่อยคุยเรื่องตัวเลข |
| **รับตรงๆ ว่าไม่คาดคิดมาก่อน** | ไม่แก้ตัว ไม่โทษใคร — ทำให้ฝ่ายตรงข้ามโต๊ะยังอยู่ข้างเดียวกัน |
| **ถามว่า "เอเจนซีต้องการเน้นจุดไหน"** | เปิดเจตนาที่แท้จริงของคู่กรณี (เขาไม่ได้ห่วงฟอล เขาห่วงว่าถูกข้าม) |
| **"สองตะกร้า"** | แก้เกมโดยไม่แตะใคร → ดูภาคผนวก 3 ใน BMC |

## ❌ ท่าที่เกือบพลาด

| พลาด | ผลที่ตามมา |
|---|---|
| **"ยอดฟอลทุกคนปั๊มได้"** | ในห้องประชุมมันแปลว่า "ใครๆ ก็ทำกัน รู้แล้วปล่อย" — คนที่ช่วยคุณเอาไปพูดไม่ได้ |
| **"เรื่องฟอลไม่ใช่หน้าที่ผม"** | ยื่นเหตุผลให้เอเจนซีเอง → "งั้นให้เอเจนซีตรวจสิ" คือสิ่งที่เขาขอมาพอดี |
| **"tool มันแพง เราไม่ใช่ media agency"** | ฟังเหมือนตัดต้นทุน บั่นทอนตำแหน่งพรีเมียม · ใช้เหตุผล "คนละหน้าที่" แทน |
| **"ไว้รอบหน้าค่อยหาเกณฑ์ตรงกลาง"** | **รอบหน้าคือหลังจากที่ประชุมตัดสินไปแล้ว** และมติจะกลายเป็นนโยบายที่แก้ยากกว่าเดิม |
| **เล่าเกณฑ์ให้ฟัง แต่ไม่ส่งไฟล์** | ถูกขอไฟล์ 2 รอบก่อนจะส่ง — เอกสารที่มีอยู่แล้ว (แบบประเมิน) ใช้ได้ทันทีตั้งแต่รอบแรก |

## รูปแบบเดิมที่โผล่ซ้ำ

**เมื่อสถานการณ์ต้องการ "เอกสาร/กฎ/ตัวเลข" คำตอบจะเคลื่อนไปหา "หลักการ" และ "ไว้ค่อยคุยกัน"** — ฉากนี้เกิด 3 ครั้งในบทสนทนาเดียว (เกณฑ์ตรงกลาง · เกณฑ์คัดคน · เกณฑ์ถอดออก)
**วิธีแก้ที่ถูกที่สุด: มีเอกสารพร้อมส่งอยู่แล้วก่อนจะถูกขอ** — แบบประเมิน · เส้นที่ไม่ข้าม · เกณฑ์ถอดออก · ทั้งสามอย่างเขียนเสร็จแล้วในโฟลเดอร์นี้ เหลือแค่ทำให้ส่งได้ในสิบวินาที
