## ลิสต์ 1 — Section ที่ไม่มีเนื้อหาลง (และทำไม)

เทียบกับรายการต้องห้าม 🔴 ท้ายไฟล์ copy (testimonial ปลอม / ตาราง before-after / เปอร์เซ็นต์ผลลัพธ์ /
จำนวนสมาชิก / โลโก้แบรนด์) — ธีมเอเจนซี่มี section ที่สร้างมาเพื่อของพวกนี้ตรงๆ:

| Section | สร้างมาเพื่อ | ทำไมว่าง |
|---|---|---|
| **S05** proof + counter | ตัวเลขผลลัพธ์ (นับ 0→92%) | 🔴 "การอ้างผลลัพธ์ที่ยังไม่มี" ต้องห้ามตรงตัว — จนกว่าจะวัดได้จริง |
| **S09** before/after slider | ตารางเทียบก่อน-หลัง | 🔴 ต้องห้ามจนมีสมาชิกครบ 1 ไตรมาส |
| **S23** กำแพงโลโก้ 24 ช่อง | โลโก้ลูกค้า/พาร์ทเนอร์ | 🔴 "ไม่ควรใส่เลย" (ของบริษัทเดิม + เสี่ยง NDA) |
| **S07 / S19** carousel ผลงาน ×2 | ภาพผลงาน ≥5 ชิ้นต่ออัน | ยังไม่มีเคส Plan C แม้ชิ้นเดียว (และ testimonial ปลอมต้องลบ) |
| **S02** โชว์เคส 3 การ์ดใหญ่ | ตัวอย่างงาน 3 ชิ้น | ไม่มีเนื้อหาคู่; ถ้าอยากใช้ เอา 3 เสา EXTRACT/ENGINEER/ESTABLISH มาลงได้แต่ไฟล์ copy ยังไม่มีก้อนนั้น |
| **S03** bento 12 ช่อง | จุดขายย่อยจำนวนมาก | ไฟล์ copy ไม่มีลิสต์ 12 หัวข้อ — ใส่ครึ่งเดียวจะโหวง |
| **S06** กริดไอคอน 9 ช่อง | ฟีเจอร์ 9 ข้อ | ใกล้เคียงสุดคือหมวด "ไม่หักคะแนน" 6 ข้อใน C09 แต่ใช้ที่ S11 แล้ว |
| **S08** marquee showcase | โชว์ widget | เนื้อหาเป็นของหน้าขายธีม; เก็บกลไก marquee ไว้ใช้กับวลีแบรนด์ได้ภายหลัง |
| **S13** เช็คลิสต์ 3 คอลัมน์ | สเปคของแถม | ไม่มีก้อน 3 หมวด (ใกล้สุดคือ C10 สิทธิ์สมาชิก — ใช้ที่ S20 แล้ว) |
| **S15 / S21** sticky ตัวที่ 2–3 | โชว์เคสยาว | โครงซ้ำ S11 — เนื้อหามีพอเลี้ยง sticky เดียว (C09) |
| **S17** media feature | screenshot เครื่องมือ | ไม่มี counterpart |
| **S18** multiblock ยาว | ฟีเจอร์หลายชุด | ไม่มี counterpart |
