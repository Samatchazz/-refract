# PlanC Console v3

หน้าเดียวสำหรับทุกการตัดสินใจ แล้วกดปุ่มเดียวได้ prompt ที่สร้างเว็บใหม่ได้ทั้งหน้า

```bash
node research/console/serve.cjs
```

เปิด <http://localhost:5800>

## ทำไมต้องรันเซิร์ฟเวอร์

ตัวอย่างสดทางขวาเป็น **`planc/` ตัวจริงใน iframe** ไม่ใช่ภาพจำลอง คอนโซลฉีด CSS custom property
เข้าไปในนั้นตอนคุณกดเลือก ซึ่งทำได้ก็ต่อเมื่อทั้งสองหน้าอยู่ origin เดียวกัน เปิดไฟล์ตรง ๆ ด้วย
`file://` จะไม่ทำงาน

## ปุ่ม

- **GEN PROMPT** — prompt สร้างเว็บใหม่ทั้งหน้า **สมบูรณ์ในตัวเอง** ไม่ต้องมีไฟล์เดิม
  ประกอบด้วย: กฎจาก north star ที่เลือก · theme block ครบทุก token พร้อมคอมเมนต์ว่าเปลี่ยนจากอะไร ·
  สเปกของทุกคอมโพเนนต์ที่เลือก · โครงหน้า 8 section · กฎภาษาไทย · กฎเหล็ก · สถาปัตยกรรม · SEO ·
  Definition of Done · รายการ placeholder ที่ห้ามแต่งเอง
  คอมโพเนนต์ที่ยังไม่ได้เลือกจะถูกลิสต์ไว้พร้อมตัวที่คะแนนสูงสุด และสั่งให้ผู้บิลด์เลือกเองแล้วบอกเหตุผล
- **บันทึก SELECTION.json** — บัตรลงคะแนน + token ที่ได้ + diff ไว้ที่เดียว จบปัญหา state กระจาย
- **คืนค่า** — กลับไปเป็นสิ่งที่ `planc/` เป็นอยู่ตอนนี้

## เมื่อ `planc/` เปลี่ยน

```bash
node research/console/build-data.mjs
```

อ่านใหม่ทั้งหมด: token จาก `planc/style.css` · 94 ตัวเลือกจาก `planc0/research/console2-data.js` ·
ตัวเลข north star จาก `research/northstar/measurements.json` · บล็อกที่ไม่ขึ้นกับตัวเลือกจาก
`planc0/research/BUILD-BRIEF-FINAL.md`

## สิ่งที่คอนโซลนี้ไม่ทำ

**ไม่เขียนอะไรลง `planc/` เลย** อ่านอย่างเดียว การเปลี่ยนจริงเกิดตอนคุณเอา prompt ไปสั่งให้บิลด์
